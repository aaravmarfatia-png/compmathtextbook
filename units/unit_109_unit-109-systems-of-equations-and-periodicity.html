Reading

1. Solving systems

Solve a system by elimination (add or subtract equations), substitution, or by recognising symmetry. For symmetric systems like x + y = 7, xy = 10, the numbers x and y are the roots of t² − 7t + 10 = 0, so {x, y} = {2, 5}.

Worked example. Solve x + y + z = 6, x² + y² + z² = 14, xyz = 6. The elementary symmetric sums are e₁ = 6, e₂ = (36 − 14)/2 = 11, e₃ = 6. The numbers are roots of t³ − 6t² + 11t − 6 = (t − 1)(t − 2)(t − 3), so {x, y, z} = {1, 2, 3}.

Counting equations. n independent linear equations determine n unknowns; dependent or contradictory systems have infinitely many or no solutions.

2. Recurrences and periodicity

A sequence is periodic if a_{n+p} = a_n for all n. If a_{n+1} depends only on a_n then once a value repeats, the sequence cycles. Find the period by computing a few terms.

Worked example 1. a₁ = 2, a_{n+1} = 1/(1 − a_n). Then a₂ = −1, a₃ = 1/2, a₄ = 2: period 3. Since 2024 = 3 × 674 + 2, a₂₀₂₄ = a₂ = −1.

Worked example 2. a_{n+1} = a_n − a_{n−1} with a₁ = a, a₂ = b gives a, b, b − a, −a, −b, a − b, a, b, …: period 6. So a₂₀₂₄ = a₂ (2024 mod 6 = 2) = b.

Functions. If f(x + 2) = −f(x) for all x then f(x + 4) = f(x): period 4.

3. Cycles of equations

A cyclic system like x₂ = f(x₁), x₃ = f(x₂), …, x₁ = f(xₙ) is often solved by monotonicity: if f is increasing then x₁ ≥ x₂ forces the chain x₂ ≥ x₃ ≥ … ≥ x₁, so all are equal. If f is decreasing, apply f twice.

Worked example. If x, y, z are positive and satisfy x = y² − 1, y = z² − 1, z = x² − 1, the symmetric solution x = y = z satisfies x = x² − 1, giving x = (1 + √5)/2 ≈ 1.618.

Fixed points. A fixed point of a recurrence a_{n+1} = f(a_n) satisfies L = f(L); if the sequence converges, the limit is a fixed point.

4. Mistakes, checks and how to practise

Common mistakes. Assuming a solution of a cyclic system must have all variables equal without proof. Miscounting the position in the cycle (off-by-one in the remainder). Dividing by an expression that could be zero.

Checks. Substitute the solution into every equation.

Practice. Compute at least two full periods before predicting.

Worked examples with Try-its: Periodic sequences

Compute the first few terms and look for repetition. If x₁ = 2 and xₙ₊₁ = 1/(1 − xₙ), then x₂ = −1, x₃ = 1/2, x₄ = 2: the sequence repeats with period 3. Since 2024 = 3 · 674 + 2, x₂₀₂₄ = x₂ = −1. Whenever xₙ₊₁ depends only on xₙ, the first repeated value starts a cycle.

Try it

If a₁ = 3 and aₙ₊₁ = 1 − 1/aₙ, find a₁₀₀.

Answer. a₂ = 2/3, a₃ = −1/2, a₄ = 3, period 3; 100 ≡ 1 (mod 3), so a₁₀₀ = a₁ = 3.

Worked examples with Try-its: Systems of equations

For 2x + 3y = 12 and x − y = 1, substitute x = y + 1 to get 5y + 2 = 12, so y = 2 and x = 3. A system is solved by elimination, substitution, or by noticing symmetric structure. Count unknowns and equations; a nonlinear system can have several solutions and each must be checked.

Try it

Solve x + y = 7 and x − y = 3.

Answer. x = 5, y = 2.

Worked examples with Try-its: A longer problem

Problem. The sequence satisfies aₙ₊₂ = aₙ₊₁ − aₙ with a₁ = 1 and a₂ = 3. Find a₂₀₂₄. Solution. The terms are 1, 3, 2, −1, −3, −2, 1, 3, …, period 6. Since 2024 = 6 · 337 + 2, a₂₀₂₄ = a₂ = 3.

Reflection. A recurrence of this type is periodic whenever its characteristic roots are roots of unity (here e^{±iπ/3}).

More worked examples: Worked examples

Period 2. If aₙ₊₁ = (aₙ + 1)/(aₙ − 1) and a₁ = 3 then a₂ = 2, a₃ = 3, so the sequence alternates 3, 2, 3, 2, … and a₁₀₁ = 3. System. From 3x + 2y = 16 and x − y = 2 substitute x = y + 2: 5y + 6 = 16, y = 2, x = 4.

Try it

If a₁ = 5 and aₙ₊₁ = (aₙ + 1)/(aₙ − 1), find a₅₀.

Answer. a₂ = 3/2, a₃ = 5; period 2, so a₅₀ = a₂ = 3/2.

Try it

Solve x + 2y = 8 and 3x − y = 3.

Answer. x = 2, y = 3.

More worked examples: A second longer problem

Problem. A sequence has x₁ = 2, x₂ = 5 and xₙ₊₂ = xₙ₊₁ − xₙ. Find the sum of the first 100 terms. Solution. The terms are 2, 5, 3, −2, −5, −3, then repeat with period 6, and each period sums to 0. Since 100 = 6 · 16 + 4 the sum is that of the first four terms: 2 + 5 + 3 − 2 = 8.

Check. Computed by a program the sum is 8.

Answer-5
