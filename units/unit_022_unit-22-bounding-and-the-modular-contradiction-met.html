1. The modular contradiction method

To prove that an equation has no integer solutions, choose a modulus m and look at both sides modulo m. If the left side can only take residues from one set and the right side from a disjoint set, the equation is impossible. This is the method of modular contradiction. The skill lies in choosing m and tabulating the possible residues of the expressions involved.

The table of squares. Modulo 3 a square is 0 or 1. Modulo 4 it is 0 or 1. Modulo 5 it is 0, 1 or 4. Modulo 8 it is 0, 1 or 4. Modulo 16 it is 0, 1, 4 or 9. Each of these tables is found by squaring 0, 1, 2, … up to m − 1 (I confirmed them by computer). Learn them: they solve a surprisingly large share of Diophantine problems.

Example 1. Show that x² + y² = 2023 has no integer solutions. Since 2023 = 4 · 505 + 3, we have 2023 ≡ 3 mod 4. But sums of two squares modulo 4 are 0 + 0, 0 + 1, 1 + 1, i.e. 0, 1 or 2, never 3. A search over all x, y up to 45 finds no solutions, as the proof predicts.

Example 2. Show that x² − 3y² = 2 has no solution. Modulo 3 the left side is x², which is 0 or 1, but 2 is neither. Example 3. x² − 5y² = 3 has no solution since modulo 5 the left side is a square (0, 1 or 4) but 3 is not.

Try it

Show that x² + y² = 4z + 3 has no integer solutions.

Answer. The right side is 3 modulo 4. Sums of two squares are 0, 1 or 2 modulo 4. Contradiction.

2. Cubes, fourth powers and the right modulus

Cubes. Modulo 7 a cube is 0, 1 or 6. Modulo 9 a cube is 0, 1 or 8. Therefore a sum of three cubes modulo 9 can be 0, 1, 2, 3, 6, 7 or 8 — never 4 or 5. So x³ + y³ + z³ = 9k + 4 has no integer solutions. For instance 4 and 13 and 22 cannot be written as a sum of three cubes of integers (the table is verified by computer).

Fourth powers. Modulo 16 a fourth power is 0 or 1. So the sum of 3 fourth powers is 0, 1, 2 or 3 modulo 16 so x⁴ + y⁴ + z⁴ = 16k + 7 (or any residue from 4 to 15) is impossible; for example 2023 = 16 · 126 + 7 is not a sum of three fourth powers.

Sums of three squares. Modulo 8 squares are 0, 1, 4, so a sum of three squares modulo 8 takes the values 0, 1, 2, 3, 4, 5, 6 — never 7. Hence no integer of the form 8k + 7 is a sum of three squares (e.g. 7, 15, 23, 31).

How to choose the modulus. Try 3, 4, 5, 7, 8, 9 in turn. Squares suggest 3, 4, 5, 8; cubes suggest 7, 9; fourth powers suggest 5, 16; powers of 2 suggest 3 or 7; factorials suggest 5 or 7. A modulus that is itself a prime power appearing in the equation (like 3 in 3ˣ) is a good bet.

Try it

Show that x³ + y³ + z³ = 2030 has no integer solutions.

Answer. 2030 = 9 · 225 + 5, so 2030 ≡ 5 mod 9, but sums of three cubes are never 4 or 5 modulo 9.

3. Bounding between consecutive squares

If an integer lies strictly between two consecutive squares, it is not a square. Example 1. n² < n² + n < (n + 1)², since n < 2n + 1. So n² + n is never a perfect square for positive n. A check of n up to 2000 confirms. Example 2. n² + n + 1 lies between n² and (n + 1)² for n ≥ 1, so it is never a square either. Example 3. n² + 3n + 1 lies between (n + 1)² = n² + 2n + 1 and (n + 2)² = n² + 4n + 4 when n ≥ 1, so it is not a square.

The method. To show that f(n) is never a square, find an integer m (depending on n) with m² < f(n) < (m + 1)². To find all n for which f(n) is a square, bound f(n) between two neighbouring squares of the same shape except for a few small n, then check those.

Example (n² + 4n). For which positive integers n is n² + 4n a perfect square? For n ≥ 1 we have (n + 1)² = n² + 2n + 1 < n² + 4n < n² + 4n + 4 = (n + 2)², because 2n + 1 < 4n exactly when n ≥ 1. So n² + 4n lies strictly between consecutive squares and is never a square: there are no solutions for n ≥ 1.

Try it

Show that 4n² + 4n + 2 is never a perfect square.

Answer. 4n² + 4n + 1 = (2n + 1)², so 4n² + 4n + 2 = (2n + 1)² + 1, which lies strictly between (2n + 1)² and (2n + 2)² for n ≥ 1 (indeed for n ≥ 0).

4. Combining modular and size arguments

Hard problems use both. Example (factorial sums). For which n is 1! + 2! + … + n! a perfect square? The sums are 1, 3, 9, 33, 153, … For n ≥ 4 the sum ends in 3 modulo 5 (since 1 + 2 + 6 + 24 = 33 ≡ 3 and every later factorial is divisible by 5), but squares modulo 5 are 0, 1, 4, never 3. So only n = 1 (sum 1) and n = 3 (sum 9) work, and a computer check up to n = 29 agrees.

Example (exponential). Solve 2ˣ − 3ʸ = 1 in non-negative integers. A search finds (x, y) = (1, 0) and (2, 1). Proof sketch: if y ≥ 1 then 2ˣ ≡ 1 mod 3, so x is even, x = 2k, and (2ᵏ − 1)(2ᵏ + 1) = 3ʸ; both factors are powers of 3 differing by 2, so they are 1 and 3, giving k = 1.

Example (3ˣ + 4ʸ = 5ᶻ). Modulo 4, 3ˣ + 4ʸ ≡ 3ˣ ≡ (−1)ˣ and 5ᶻ ≡ 1, so x is even. Modulo 3, 4ʸ ≡ 1 and 5ᶻ ≡ (−1)ᶻ, so z is even. Then a difference-of-squares factorisation finishes the proof: the only solution is (2, 2, 2) (a search over exponents up to 9 finds no other).

Try it

Show that 1! + 2! + 3! + … + 10! is not a perfect square.

Answer. From 5! on, every factorial is a multiple of 5, so the sum is congruent to 1 + 2 + 6 + 24 = 33 ≡ 3 mod 5. Squares are 0, 1 or 4 modulo 5.

5. Factoring to bound solutions

Many Diophantine equations can be rewritten as a product equal to a constant, which has finitely many factorisations. Example 1. xy = x + y + 3. Rearranging gives xy − x − y + 1 = 4, i.e. (x − 1)(y − 1) = 4. The factor pairs of 4 (including negative ones) give, with x ≤ y, the solutions (−3, 0), (−1, −1), (2, 5) and (3, 3), which a computer search over a range of integers confirms. Check one: 2 · 5 = 10 = 2 + 5 + 3 ✓.

Example 2. 1/x + 1/y = 1/3 in positive integers. Multiply out: 3(x + y) = xy, so (x − 3)(y − 3) = 9, with factor pairs (1, 9), (3, 3), giving (x, y) = (4, 12) and (6, 6) (a search confirms these are the only solutions with x ≤ y).

Example 3. 1/x + 1/y + 1/z = 1 with x ≤ y ≤ z: since x is the smallest, 1/x ≥ 1/3, so x ≤ 3, and each case leaves a two-variable equation. The solutions are (2, 3, 6), (2, 4, 4), (3, 3, 3), as a search confirms. This is the bounding method: order the variables, bound the smallest, then solve the rest.

Try it

Find all positive integer solutions of 1/x + 1/y = 1/2 with x ≤ y.

Answer. (x − 2)(y − 2) = 4: (1, 4) gives (3, 6), (2, 2) gives (4, 4). So (3, 6) and (4, 4).

6. A longer problem

Problem. Show that the equation x² + y² + z² = 8w + 7 has no integer solutions, and find all positive integer solutions of 1/x + 1/y = 1/6 with x ≤ y.

Solution. First part: squares modulo 8 are 0, 1, 4. Any sum of three of them is 0, 1, 2, 3, 4, 5 or 6 modulo 8, and 7 is not among them. So no solution exists. Second part: 6(x + y) = xy gives (x − 6)(y − 6) = 36, with factor pairs (1, 36), (2, 18), (3, 12), (4, 9), (6, 6). So (x, y) = (7, 42), (8, 24), (9, 18), (10, 15), (12, 12).

Reflection. The first problem used a 'no solutions' proof by tabulating residues, and the second a 'find all solutions' proof by factoring. Notice that nothing in either needed deep theory, only careful organisation.

7. Mistakes, checks and how to practise

Common mistakes. (1) Choosing a modulus that allows the residue you want to exclude. (2) Making an arithmetic slip in the table of residues: recompute the table, do not trust memory. (3) Forgetting the case where the variable is 0 or negative. (4) Bounding with an inequality that fails for small n. (5) Listing only the solutions with x ≤ y when the question asks for ordered pairs.

Checks. For a claimed solution set, substitute each solution. For a claimed impossibility, test a few values: the residues you computed must really occur. For bounding arguments, test the first few n.

How to practise. Memorise the residue tables for squares mod 3, 4, 5, 8 and cubes mod 7, 9, and run the modular-contradiction families in Unlimited practice until choosing the modulus is routine.

Problem p1. Find the natural-number pair (x, y) with x³ − y³ = xy + 61. Answer as x, y.

HintFactor x³ − y³ and show x² + y² ≤ 61.
Answer6, 5
Method: Bounding

x³ − y³ = (x − y)(x² + xy + y²). Since the right side is positive, x > y, so x − y ≥ 1 and x² + xy + y² ≤ (x − y)(x² + xy + y²) = xy + 61. That gives x² + y² ≤ 61. Because x > y we have 2y² < x² + y² ≤ 61, so y ≤ 5. Try y = 1…5 and solve for x: only y = 5 gives a whole number, x = 6 (216 − 125 = 91 = 30 + 61).

Method: Brute-force check

With y ≤ 5 and x² ≤ 61 we have x ≤ 7. Testing all pairs with 1 ≤ y < x ≤ 7 finds only (6, 5).

Source: Stevens, AoPS Olympiad Number Theory, ch. 4 Example 4.1.1 (Russia)

Problem p2. How many integer pairs (x, y) with y ≥ 0 satisfy x² − y! = 2001?

HintLook mod 7: y! ≡ 0 once y ≥ 7.
Answer2
Method: Modular contradiction

If y ≥ 7 then 7 divides y!, so x² ≡ 2001 (mod 7). Now 2001 = 7·285 + 6, so x² ≡ 6 (mod 7). Squares mod 7 are only 0, 1, 2, 4, so this is impossible. Hence y ≤ 6. Check y = 0…6: x² = 2002, 2002, 2003, 2007, 2025, 2121, 2721. Only 2025 = 45² is a square (y = 4), giving x = ±45: two pairs.

Method: Computer check

Searching x from −3000 to 3000 and y from 0 to 14 finds only (45, 4) and (−45, 4).

Source: Stevens, AoPS Olympiad Number Theory, ch. 4 Example 4.2.1

Problem p5. How many triples x ≤ y ≤ z of positive integers satisfy 1/x + 1/y + 1/z = 1?

Hintx cannot be 1, and x ≤ 3.
Answer3

Problem p6. How many positive integer pairs (x, y) satisfy 2ˣ + 1 = 3ʸ?

HintMod 8 forces y even when x ≥ 3.

Problem p8. How many different values does x² take mod 13 (including 0)?

HintSquare 0 through 12 mod 13.
Answer7
Method: Square them

0, 1, 4, 9, 3, 12, 10, 10, 12, 3, 9, 4, 1. The values: 0, 1, 3, 4, 9, 10, 12 — seven. (x and 13 − x share a square, giving (13 − 1)/2 = 6 non-zero squares, plus 0.)

Method: Pairing argument

x² ≡ y² means 13 | (x − y)(x + y), so y ≡ ±x. Non-zero residues pair up: 12/2 = 6 values, plus 0 = 7.

Problem p10. How many positive integers n make n⁴ + 4 prime?

Hintn⁴ + 4 = (n² + 2n + 2)(n² − 2n + 2).
Answer1
Method: Sophie Germain factorisation

n⁴ + 4 = (n² + 2n + 2)(n² − 2n + 2). The second factor is (n − 1)² + 1, which equals 1 only when n = 1; for n ≥ 2 both factors exceed 1, so n⁴ + 4 is composite. n = 1 gives 5, prime. Exactly one n.

Method: Computer check

Testing n up to 3000 finds only n = 1.

Problem p11. How many positive integer pairs (x, y) with x < y satisfy 1/x − 1/y = 1/12?

HintMultiply out and use Simon's trick.
Answer7
Method: Factor

Multiply by 12xy: 12y − 12x = xy, so y(12 − x) = 12x, i.e. y = 12x/(12 − x). We need 12 − x > 0, so x < 12. Also y = 12x/(12 − x) = −12 + 144/(12 − x), so 12 − x must divide 144. The values x = 3, 4, 6, 8, 9, 10, 11 (12 − x = 9, 8, 6, 4, 3, 2, 1) give y = 4, 6, 12, 24, 36, 60, 132. Seven pairs.

Method: Computer check

Testing x up to 99 and y up to 2000 with exact fractions finds the same seven.

Source: Stevens, AoPS Olympiad Number Theory, ch. 4 (bounding; chosen by me)

Problem x20. What is the remainder when 3^100 is divided by 7?

HintFind the pattern of remainders of successive powers.
Answer4
Method: Cycle of remainders

The remainders of 3, 3², 3³, … are 3, 2, 6, 4, 5, 1, and then they repeat from position 1 with period 6. Exponent 100 lands on 4.

Method: Repeated squaring

Write 100 = 1100100 in binary. The squares 3^(2^i) mod 7 are 3, 2, 4, 2, 4, 2, 4; multiplying the ones for the 1-bits gives 4.
