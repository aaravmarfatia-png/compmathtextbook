1. Setting up a recursion

To count objects of size n, relate them to smaller objects of size n − 1, n − 2, …. The method: look at the last step (the last digit, the last tile, the last move) and count the ways to complete each case.

Worked example 1: compositions. The number of ways to write n as an ordered sum of 1s and 2s satisfies cₙ = cₙ₋₁ + cₙ₋₂ (the last part is 1 or 2), with c₁ = 1, c₂ = 2: 1, 2, 3, 5, 8, 13, a Fibonacci sequence. The number of compositions of n into any positive parts is 2ⁿ⁻¹ (each of the n − 1 gaps either has a plus sign or not).

Worked example 2: strings. Count binary strings of length n with no three consecutive 1s. Let sₙ be the count. If the string ends in 0, any good string of length n − 1 precedes it; if it ends in 01, good of length n − 2; if it ends in 011, good of length n − 3. So sₙ = sₙ₋₁ + sₙ₋₂ + sₙ₋₃ with s₁ = 2, s₂ = 4, s₃ = 7: then s₄ = 13, s₅ = 24, s₆ = 44.

2. Tilings

Dominoes on a 2 × n board: tₙ = tₙ₋₁ + tₙ₋₂ (Unit 25), values 1, 2, 3, 5, 8. Dominoes on a 3 × n board: there are none for odd n. For even n: 3, 11, 41, 153 for n = 2, 4, 6, 8. The recurrence is tₙ = 4tₙ₋₂ − tₙ₋₄: with t₀ = 1, t₂ = 3: t₄ = 12 − 1 = 11, t₆ = 44 − 3 = 41, t₈ = 164 − 11 = 153.

Worked example. How many ways to tile a 2 × 10 board with 1 × 2 and 2 × 1 dominoes? Using t₁ = 1, t₂ = 2: t₃ = 3, t₄ = 5, t₅ = 8, t₆ = 13, t₇ = 21, t₈ = 34, t₉ = 55, t₁₀ = 89.

3. Counting set partitions and paths

Stirling numbers of the second kind. S(n, k) counts ways to split n objects into k non-empty unlabelled groups. Recurrence: S(n, k) = k S(n − 1, k) + S(n − 1, k − 1) (the last object joins an existing group, or forms its own). S(4, 2) = 2 × S(3, 2) + S(3, 1) = 2 × 3 + 1 = 7. S(5, 3) = 3 × 6 + 7 = 25.

Lattice paths with a barrier. The number of paths from (0, 0) to (n, n) with steps right and up that never go above the diagonal is the Catalan number Cₙ = C(2n, n)/(n + 1): 1, 2, 5, 14, 42.

Worked example. A frog hops 1 or 3 steps. In how many ways can it reach step 8? Let fₙ = fₙ₋₁ + fₙ₋₃ with f₀ = 1, f₁ = 1, f₂ = 1: f₃ = 2, f₄ = 3, f₅ = 4, f₆ = 6, f₇ = 9, f₈ = 13.

4. Mistakes, checks and how to practise

Common mistakes. Wrong initial values. Overcounting because two cases overlap. Missing a case for the last step. Using a recurrence of the wrong order.

Checks. Count the first few values by listing.

Practice. Always list n = 1, 2, 3 by hand before setting up the recurrence.

Worked examples with Try-its: Recurrences for counting

Count by the last step. Tiling a 2 × n strip with 1 × 2 dominoes: the last column is either one vertical domino (leaving a 2 × (n − 1) strip) or two horizontal ones (leaving 2 × (n − 2)), so fₙ = fₙ₋₁ + fₙ₋₂ with f₁ = 1, f₂ = 2, giving 1, 2, 3, 5, 8 for n = 1 to 5. The same recurrence counts binary strings of length 6 with no two adjacent 1s (21, confirmed by listing all 64 strings) and ways to climb 7 stairs using steps of 1 or 2 (21).

Try it

How many ways can you climb 5 stairs using steps of 1 or 2?

Answer. 8.

Worked examples with Try-its: Compositions and Catalan numbers

The number of ways to write n as an ordered sum of positive integers is 2ⁿ⁻¹ (each of the n − 1 gaps between units is either a plus or a break): for n = 5 that is 16. The Catalan number Cₙ = C(2n, n)/(n + 1) counts balanced bracket sequences with n pairs: C₄ = 70/5 = 14. It also counts triangulations of a convex (n + 2)-gon and lattice paths that stay on one side of a diagonal.

Try it

How many balanced sequences of 3 pairs of brackets are there?

Answer. C₃ = 5: ((())), (()()), (())(), ()(()), ()()().

Worked examples with Try-its: A longer problem

Problem. Let aₙ be the number of binary strings of length n with no three consecutive 1s. Find a₅. Solution. Condition on how the string ends: 0, 01 or 011 (preceded by anything valid), so aₙ = aₙ₋₁ + aₙ₋₂ + aₙ₋₃ with a₁ = 2, a₂ = 4, a₃ = 7, giving a₄ = 13 and a₅ = 24.

Reflection. Always compute small cases by hand to check the recurrence.

More worked examples: Worked examples

Tower of Hanoi. Moving n discs takes Tₙ = 2Tₙ₋₁ + 1 moves with T₁ = 1, so Tₙ = 2ⁿ − 1: 15 moves for 4 discs, 31 for 5. Subsets with no two consecutive numbers. From {1, …, n} there are Fₙ₊₂ such subsets: for n = 5 that is 13 (confirmed by listing all 32 subsets).

Try it

How many moves does the Tower of Hanoi with 6 discs need?

Answer. 63.

Try it

How many binary strings of length 4 have no two adjacent 1s?

Answer. 8.

More worked examples: A second longer problem

Problem. Let bₙ be the number of ways to write n as an ordered sum of 1s and 3s. Find b₇. Solution. bₙ = bₙ₋₁ + bₙ₋₃ with b₀ = 1, b₁ = 1, b₂ = 1. Then b₃ = 2, b₄ = 3, b₅ = 4, b₆ = 6, b₇ = 9.

Check. Counting compositions of 7 by the number of 3s: no 3s gives 1 way, one 3 gives 5 ways (4 ones and one 3 arranged), two 3s gives 3 ways (one 1 and two 3s): 1 + 5 + 3 = 9 ✓.

Problem p1. How many moves does the Tower of Hanoi need for 7 disks?

HintT(n) = 2T(n − 1) + 1.
Answer127
Method: Recurrence

T(n) = 2T(n − 1) + 1 with T(0) = 0 gives 2ⁿ − 1 = 127.

Method: Reason

Move n − 1 disks away, move the biggest, move the n − 1 back: 2T(n − 1) + 1 moves.

Source: Zeitz, ch. 6 (induction and recursion) and Engel ch. 8
