Reading

1. The Cauchy–Schwarz inequality

For real numbers a₁, …, aₙ and b₁, …, bₙ: (Σaᵢ²)(Σbᵢ²) ≥ (Σaᵢbᵢ)², with equality exactly when the vectors are proportional. For (1, 2, 3) and (4, 5, 6): 14 · 77 = 1078 ≥ 32² = 1024. A useful variant (Titu/Engel form): Σ aᵢ²/bᵢ ≥ (Σaᵢ)²/Σbᵢ for positive bᵢ, which gives 1/a + 1/b + 1/c ≥ 9/(a + b + c). A random test of 500 triples confirmed this and Nesbitt's inequality a/(b + c) + b/(c + a) + c/(a + b) ≥ 3/2.

Optimisation. Minimise x² + y² given x + y = 10: by Cauchy (1 + 1)(x² + y²) ≥ (x + y)² = 100, so x² + y² ≥ 50, with equality at x = y = 5. Maximise xy given 2x + 3y = 12: AM–GM on 2x and 3y gives 12 = 2x + 3y ≥ 2√(6xy), so xy ≤ 6, equality at 2x = 3y = 6, x = 3, y = 2.

Try it

If a + b + c = 6, find the minimum of a² + b² + c².

Answer. (1 + 1 + 1)(a² + b² + c²) ≥ 36, so at least 12 at a = b = c = 2.

2. The rearrangement inequality and means

If a₁ ≤ a₂ ≤ … ≤ aₙ and b₁ ≤ … ≤ bₙ, then the sum a₁b₁ + … + aₙbₙ (same order) is the largest over all pairings and the oppositely ordered pairing is the smallest. For (1, 2, 3) and (4, 5, 6): same order 32, opposite order 28, and every one of the six pairings lies between (confirmed by listing). It proves a² + b² + c² ≥ ab + bc + ca.

The mean inequalities. For positive numbers: HM ≤ GM ≤ AM ≤ QM. For 2 and 8: HM = 3.2, GM = 4, AM = 5, QM = √34 ≈ 5.83. The AM–GM inequality for three numbers: (a + b + c)/3 ≥ ∛(abc), equality iff a = b = c.

Try it

Prove a/b + b/c + c/a ≥ 3 for positive a, b, c.

Answer. By AM–GM the sum is at least 3 · ∛((a/b)(b/c)(c/a)) = 3.

3. A longer problem

Problem. Let a, b, c > 0 with a + b + c = 1. Show that 1/a + 1/b + 1/c ≥ 9 and find the minimum of a² + b² + c².

Solution. By Titu, 1/a + 1/b + 1/c ≥ 9/(a + b + c) = 9. By Cauchy, (1 + 1 + 1)(a² + b² + c²) ≥ 1, so a² + b² + c² ≥ 1/3, equality at a = b = c = 1/3.

Reflection. Both used equality at a = b = c, the typical situation for symmetric constraints.

4. Mistakes, checks and how to practise

Common mistakes. (1) Using AM–GM with negative numbers. (2) Forgetting to state when equality holds and whether it is reachable. (3) Using the wrong form of Cauchy. (4) Assuming a minimum exists at an interior point without checking.

Checks. Test equality case numerically and a nearby point.

How to practise. Always check the equality case first. In Unlimited practice, rotate the inequality families.

More worked examples: Worked examples

Cauchy–Schwarz. (a² + b²)(c² + d²) ≥ (ac + bd)². With (a, b) = (1, 3) and (c, d) = (2, 4): (1 + 9)(4 + 16) = 200 ≥ (2 + 12)² = 196. Rearrangement. Pairing the sequences 1, 2, 3 and 4, 5, 6 in the same order gives 1 · 4 + 2 · 5 + 3 · 6 = 32, the maximum, and in opposite order 1 · 6 + 2 · 5 + 3 · 4 = 28, the minimum. AM-GM. If abc = 8 for positive a, b, c then a + b + c ≥ 3 · ∛8 = 6.

Try it

If x + y = 6, what is the smallest value of x² + y²?

Answer. By Cauchy–Schwarz (x² + y²)(1 + 1) ≥ 36, so 18, at x = y = 3.

Try it

Find the largest value of 2x + 3y if x² + y² = 13.

Answer. √(13 · 13) = 13, at (2, 3).

More worked examples: A second longer problem

Problem. For positive a, b, c with a + b + c = 1 show that 1/a + 1/b + 1/c ≥ 9. Solution. By Cauchy–Schwarz, (a + b + c)(1/a + 1/b + 1/c) ≥ (1 + 1 + 1)² = 9, with equality at a = b = c = 1/3.

Check. At a = b = c = 1/3 the sum is 9, so the bound is attained.

Problem p1. Real numbers satisfy x + 2y + 3z = 14. What is the smallest possible value of x² + y² + z²?

HintCauchy–Schwarz with (1, 2, 3).
Answer14
Method: Cauchy–Schwarz

(x² + y² + z²)(1 + 4 + 9) ≥ 14² = 196, so x² + y² + z² ≥ 14, with equality at (1, 2, 3).

Method: Check

x = 1, y = 2, z = 3 gives 1 + 4 + 9 = 14 and 1 + 4 + 9 = 14.

Problem p2. Positive numbers satisfy 2x + 3y = 12. What is the largest possible value of xy?

HintAM–GM on 2x and 3y.
Answer6
Method: AM–GM

√(2x·3y) ≤ (2x + 3y)/2 = 6, so 6xy ≤ 36 and xy ≤ 6, with equality at 2x = 3y = 6, i.e. x = 3, y = 2.

Method: Substitute

xy = x(12 − 2x)/3 = (12x − 2x²)/3, largest at x = 3 with value 6.

Source: Engel, Problem-Solving Strategies, ch. 7

Problem p7. For positive a, b, c with a + b + c = 6, what is the largest possible value of abc?

HintAM–GM.
Answer8
Method: AM–GM

abc ≤ ((a + b + c)/3)³ = 8, equality at a = b = c = 2.

Method: Smoothing

If two numbers differ, replacing them by their average raises the product, so the maximum is at equal values.

Problem p9. What is the largest possible value of 3x + 4y if x² + y² = 25?

HintCauchy–Schwarz.
Answer25
Method: Cauchy–Schwarz

(3x + 4y)² ≤ (9 + 16)(x² + y²) = 625, so 3x + 4y ≤ 25, achieved at (3, 4).

Method: Geometry

3x + 4y = 5·(cos of the angle between (x, y) and (3, 4))·|(x, y)|, at most 5·5 = 25.

Problem p14. Positive x and y satisfy x + y = 6. What is the largest possible value of x²y?

HintSplit x into two halves.
Answer32
Method: AM-GM

x²y = 4 · (x/2)(x/2)y ≤ 4((x/2 + x/2 + y)/3)³ = 4 · 8 = 32, with x/2 = y, so x = 4, y = 2.

x²(6 − x) = 6x² − x³ has derivative 12x − 3x² = 0 at x = 4, giving 16 · 2 = 32.

Problem x19. If x + 1/x = 12, find x² + 1/x².

HintSquare both sides.
Answer142
Method: Square

(x + 1/x)² = x² + 2 + 1/x², so x² + 1/x² = 144 − 2 = 142.

Method: Recurrence

With pₙ = xⁿ + x⁻ⁿ we have p₀ = 2, p₁ = 12 and p₂ = 12 · p₁ − p₀ = 142.

Source: Engel, Problem-Solving Strategies, ch. 7

Problem x20. The roots of x² − 11x + 5 = 0 are r and s. Find r² + s².

HintUse r + s and rs.
Answer111
Method: Vieta

r + s = 11 and rs = 5, so r² + s² = (r + s)² − 2rs = 121 − 10 = 111.

Method: Recurrence

Let pₙ = rⁿ + sⁿ. Then p₀ = 2, p₁ = 11 and p₂ = 11 · p₁ − 5 · p₀ = 121 − 10 = 111.

Source: Engel, Problem-Solving Strategies, ch. 7
