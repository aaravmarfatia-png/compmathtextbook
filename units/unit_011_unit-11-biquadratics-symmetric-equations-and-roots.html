1. Biquadratic equations: a quadratic in disguise

A biquadratic equation has the form ax⁴ + bx² + c = 0: only even powers appear. The trick is the substitution u = x², which turns it into the quadratic au² + bu + c = 0. Solve for u, then go back: x² = u gives x = ±√u, but only when u ≥ 0. A negative u gives no real x.

Worked example 1. x⁴ − 5x² + 4 = 0. Let u = x²: u² − 5u + 4 = 0, so (u − 1)(u − 4) = 0 and u = 1 or u = 4. Then x = ±1 or x = ±2, four real solutions. Check x = 2: 16 − 20 + 4 = 0 ✓. Example 2. x⁴ − 13x² + 36 = 0 gives u = 4 or u = 9 and x = ±2, ±3. Example 3. x⁴ + 3x² − 4 = 0: (u + 4)(u − 1) = 0, so u = 1 or u = −4. The value u = −4 is impossible for a real x, so the only real solutions are x = ±1. (With complex numbers x² = −4 gives x = ±2i, but over the real numbers there are just two roots.)

How many real solutions? Each positive root u produces two values of x, a root u = 0 produces one (x = 0), and a negative u produces none. So a biquadratic can have 0, 1 (only if u = 0 alone), 2, 3 or 4 real solutions. For x⁴ − 2x² = 0 we get u(u − 2) = 0: u = 0 and u = 2, so x = 0, ±√2: three solutions.

Spotting disguised versions. Anything of the form a·f(x)² + b·f(x) + c = 0 is handled the same way with u = f(x). For example, 2^(2x) − 5·2^x + 4 = 0 is a quadratic in u = 2^x, with u = 1 or 4, so x = 0 or x = 2.

Try it

Solve x⁴ − 10x² + 9 = 0.

Answer. u² − 10u + 9 = 0 gives u = 1 or 9, so x = ±1, ±3.

2. Factoring biquadratics

Even when a quadratic in u does not factor nicely, the biquadratic may still factor over the integers as a product of two quadratics in x. Two identities are worth remembering. Sophie Germain's identity: x⁴ + 4 = (x² + 2x + 2)(x² − 2x + 2). And x⁴ + x² + 1 = (x² + x + 1)(x² − x + 1). Both come from the trick of making a perfect square and then using a difference of squares: x⁴ + 4 = (x² + 2)² − 4x² = (x² + 2 − 2x)(x² + 2 + 2x).

Worked example (a composite number). For n = 3, n⁴ + 4 = 85 = 5 × 17, matching (9 − 6 + 2)(9 + 6 + 2) = 5 × 17. In fact n⁴ + 4 is composite for every integer n > 1 because both factors exceed 1: for n = 2 we get 20 = (4 − 4 + 2)(4 + 4 + 2) = 2 × 10. This is a famous trick in olympiad problems asking whether numbers like n⁴ + 4 can be prime.

Worked example (solving). Solve x⁴ + x² − 6 = 0. With u = x²: (u + 3)(u − 2) = 0, so u = 2 and x = ±√2 (the other root u = −3 is rejected). But x⁴ + 4x² + 1 = 0 would need u² + 4u + 1 = 0 with u = −2 ± √3, both negative, so there are no real roots at all.

Completing the square in the middle. To factor x⁴ + 4x² + 16, note that 16 = 4², so x⁴ + 8x² + 16 would be a perfect square. We have (x² + 4)² − 4x² = (x² + 2x + 4)(x² − 2x + 4). Adding and subtracting a term to complete a square is a valuable technique in all of algebra.

Try it

Factor x⁴ + 64.

Answer. x⁴ + 64 = (x² + 8)² − 16x² = (x² + 4x + 8)(x² − 4x + 8).

3. Symmetric equations and systems

An expression is symmetric in x and y if swapping them leaves it unchanged. x + y, xy and x² + y² are symmetric. A key theorem (the 'fundamental theorem of symmetric polynomials') says every symmetric polynomial in two variables can be written using just s = x + y and p = xy. So a symmetric system can be reduced to two equations in s and p, and then x, y are the roots of t² − st + p = 0.

Worked example 1. Solve x + y = 7, x² + y² = 25. Since x² + y² = s² − 2p, we get 25 = 49 − 2p, so p = 12. Now x and y are the roots of t² − 7t + 12 = 0, namely 3 and 4. The solutions are (3, 4) and (4, 3). Check: 9 + 16 = 25 ✓.

Worked example 2. Solve x² + xy + y² = 7 and x + y = 3. Use x² + xy + y² = s² − p: 9 − p = 7 gives p = 2, so x, y are roots of t² − 3t + 2 = 0, i.e. 1 and 2. Check: 1 + 2 + 4 = 7 ✓. Example 3 (cubes). x³ + y³ = s³ − 3ps. For s = 5 and p = 6 this is 125 − 90 = 35, and indeed x, y = 2, 3 give 8 + 27 = 35.

Useful expressions in s and p: x² + y² = s² − 2p; (x − y)² = s² − 4p; x³ + y³ = s³ − 3ps; 1/x + 1/y = s/p; x⁴ + y⁴ = (s² − 2p)² − 2p². Memorise the first three; the others follow quickly.

Try it

If x + y = 6 and xy = 4, find x² + y² and x³ + y³.

Answer. x² + y² = 36 − 8 = 28. x³ + y³ = 216 − 3 × 4 × 6 = 216 − 72 = 144.

4. Reciprocal (palindromic) equations

An equation like 2x⁴ − 9x³ + 14x² − 9x + 2 = 0, whose coefficients read the same forwards and backwards, is called reciprocal. If r is a root then so is 1/r, because the equation is unchanged when x is replaced by 1/x (after multiplying by x⁴). Since x = 0 is not a root, divide through by x²: 2x² − 9x + 14 − 9/x + 2/x² = 0, group as 2(x² + 1/x²) − 9(x + 1/x) + 14 = 0 and use t = x + 1/x, so that x² + 1/x² = t² − 2.

Worked example. The equation becomes 2(t² − 2) − 9t + 14 = 2t² − 9t + 10 = 0, so t = (9 ± 1)/4 = 5/2 or 2. Now solve x + 1/x = t. For t = 2: x² − 2x + 1 = 0, x = 1 (double root). For t = 5/2: 2x² − 5x + 2 = 0, so x = 2 or ½. The four roots are 1, 1, 2, ½. Check using Vieta for the quartic: the product of the roots should be 2/2 = 1: 1 × 1 × 2 × ½ = 1 ✓; the sum should be 9/2: 1 + 1 + 2 + ½ = 4.5 ✓.

Reminder about t. For real x we have |t| ≥ 2 (Unit 30 and 128), so a solution t with |t| < 2 produces no real x: for example t = 1 gives x² − x + 1 = 0, which has D = −3 < 0. Always check this before turning back to x.

Odd degree. A reciprocal equation of odd degree always has the root x = −1 (for coefficients that read the same forwards) or x = 1 (for antisymmetric ones). Divide that factor out and a reciprocal equation of even degree is left.

Try it

Solve x⁴ − 3x³ + 4x² − 3x + 1 = 0 (coefficients 1, −3, 4, −3, 1) over the real numbers.

Answer. Divide by x²: (x² + 1/x²) − 3(x + 1/x) + 4 = 0, i.e. t² − 2 − 3t + 4 = t² − 3t + 2 = 0, so t = 1 or 2. For t = 1 there is no real x (|t| < 2). For t = 2, x = 1. So x = 1 is the only real root (double).

5. Other substitutions

The idea behind the biquadratic works whenever the same chunk appears several times. Choose the chunk, name it u, solve for u, then solve for x. Worked example 1. (x² + x)² − 8(x² + x) + 12 = 0. Let u = x² + x: u² − 8u + 12 = 0 so u = 2 or u = 6. Then x² + x − 2 = 0 gives x = 1 or −2, and x² + x − 6 = 0 gives x = 2 or −3. All four solutions: 1, −2, 2, −3. Check x = 2: (4 + 2)² − 8 × 6 + 12 = 36 − 48 + 12 = 0 ✓.

Worked example 2 (product of consecutive terms). (x − 1)(x − 2)(x − 3)(x − 4) = 24. Pair the outer and the inner factors: (x² − 5x + 4)(x² − 5x + 6) = 24. With u = x² − 5x + 5: (u − 1)(u + 1) = u² − 1 = 24, so u² = 25 and u = ±5. For u = 5: x² − 5x = 0, x = 0 or 5. For u = −5: x² − 5x + 10 = 0, D = 25 − 40 < 0, no real solution. So x = 0 or x = 5. Check x = 5: 4 × 3 × 2 × 1 = 24 ✓; x = 0: (−1)(−2)(−3)(−4) = 24 ✓.

Worked example 3 (a radical equation). x² + √(x² + 7) = 13. Put u = √(x² + 7), so u² = x² + 7 and x² = u² − 7. The equation becomes u² − 7 + u = 13, u² + u − 20 = 0, (u + 5)(u − 4) = 0, so u = 4 (u = −5 is impossible for a square root). Then x² + 7 = 16, x = ±3. Check: 9 + √16 = 13 ✓.

Try it

Solve (x² − 3x)² − 2(x² − 3x) − 8 = 0.

Answer. With u = x² − 3x: u² − 2u − 8 = 0, u = 4 or −2. x² − 3x − 4 = 0 gives x = 4 or −1; x² − 3x + 2 = 0 gives x = 1 or 2. So x = −1, 1, 2, 4.

6. Roots and their relations

For a polynomial with roots r₁, …, rₙ the coefficients encode sums and products of the roots (Vieta). For a biquadratic ax⁴ + bx² + c = 0 the four roots come in pairs ±p, ±q, so their sum is 0 (as there is no x³ term) and the product of all four is c/a. For x⁴ − 5x² + 4 = 0 the roots are 1, −1, 2, −2: product 4 = c/a ✓, and the sum of squares is 1 + 1 + 4 + 4 = 10 = 2 × 5, which equals −2b/a.

Worked example. The equation x⁴ − 10x² + 1 = 0 has the root √2 + √3. Check: (√2 + √3)² = 5 + 2√6; squaring again, (5 + 2√6)² = 25 + 20√6 + 24 = 49 + 20√6, and 10 × (5 + 2√6) = 50 + 20√6, so (x²)² − 10x² + 1 = 49 + 20√6 − 50 − 20√6 + 1 = 0 ✓. The four roots are ±√2 ± √3. This is how algebraic numbers with nested roots are handled: they are roots of equations with whole-number coefficients.

Finding such an equation. If x = √2 + √3, then x² = 5 + 2√6, so x² − 5 = 2√6, and squaring gives x⁴ − 10x² + 25 = 24, i.e. x⁴ − 10x² + 1 = 0. The technique 'isolate the root, then square' removes one square root per round.

7. Mistakes, checks and how to practise

Common mistakes. (1) Forgetting to go back from u to x, or taking only the positive square root (x = ±√u). (2) Accepting a negative u as giving real solutions. (3) Dividing by x² and not noting that x = 0 is not a root (for a reciprocal equation x = 0 is not a root since the constant is non-zero). (4) After solving for t = x + 1/x, forgetting the condition |t| ≥ 2. (5) Losing solutions when using symmetric s and p: both (a, b) and (b, a) are solutions.

Checks. Substitute every claimed root. Count the roots: a degree-4 equation can have at most 4. Check Vieta: sum and product of all roots including complex ones.

How to practise. For each equation write a one-line plan before computing: 'let u = …'. In Unlimited practice, use the symmetric-system and substitution families repeatedly until the plan comes automatically.

Answer6

Problem 272. Compute √0.999 to three decimal places.

HintSquares: 0.9995² and 0.9985².
Answer0.999
Method: Sandwich

0.9995² = 0.99900025, a bit more than 0.999, so √0.999 < 0.9995. And 0.9985² = 0.99700225 < 0.999, so √0.999 > 0.9985. The root lies between 0.9985 and 0.9995 so it rounds to 0.999. (Really √0.999 ≈ 0.99950.)
