Reading

1. Standard substitutions

To solve a functional equation try: set variables to 0, 1 or each other; swap x with 1/x to produce a second equation; telescope a recurrence; prove the guess works. Example: f(x) + 2f(1/x) = x. Replacing x by 1/x gives f(1/x) + 2f(x) = 1/x; eliminating f(1/x) gives f(x) = (2/x − x)/3. Check at x = 1: f(1) + 2f(1) = 1 ✓ and f(1) = 1/3 ✓.

Cauchy. If f(x + y) = f(x) + f(y) on the rationals then f(x) = f(1)x. Exponential. A positive solution of f(x + y) = f(x)f(y) is f(x) = a^x. Involutions. f(f(x)) = x on {1,…,n} counts involutions: 1, 2, 4, 10, 26, 76, 232, …

Try it

f(x) + 3f(1/x) = x. What is f(1)?

Answer. f(1) = 1/4.

Try it

f(x + 1) = f(x) + 2x + 1 and f(0) = 0: find f(6).

Answer. 36.

2. Proving that a guess works

A candidate such as f(x) = ax + b must be substituted back. If f(f(x)) = 4x + 3 and f is linear with a > 0 then a² = 4, (a + 1)b = 3, so f(x) = 2x + 1; check f(f(x)) = 2(2x + 1) + 1 = 4x + 3 ✓. A solution found by elimination is a candidate only until it is verified.

Try it

Linear f with a > 0 and f(f(x)) = 9x + 8: find f(1).

Answer. a = 3, b = 2: f(1) = 5.

3. A worked problem

Problem. A completely multiplicative f has f(2) = 3 and f(3) = 2. Find f(72). Solution. 72 = 2³ · 3², so f(72) = 3³ · 2² = 108.

Check. f(72) = f(8)f(9) = 27 · 4 = 108 ✓.

4. In the books

Small, ch. 2 (two variables). 2.1 Cauchy's equation f(x + y) = f(x) + f(y) and 2.2 its applications; 2.3 Jensen's equation; 2.4 the linear equation; 2.5 Cauchy's exponential equation f(x + y) = f(x)f(y); 2.6 Pexider's equation; 2.7 Vincze's equation; 2.8 Cauchy's inequality; 2.9 equations in two variables. The book stresses that over the reals one needs an extra condition such as continuity or monotonicity, while over the rationals the solution is f(x) = cx.

Ch. 3 (one variable). Linearisation (3.2), basic families (3.3), conjugacy equations (3.4 to 3.5), iterative roots (3.7) and nested radicals (3.8). Ch. 4. Polynomial equations (4.1), power series (4.2) and equations involving arithmetic functions (4.3), which is where completely multiplicative functions appear.

Honest note. The unit only touches the basics (Cauchy over the rationals, substitution x → 1/x, recurrences, multiplicativity, a counting problem on involutions). The pathological solutions over the reals (Hamel bases, an appendix in the book) are not covered.

Problem p1. A function f on the rationals satisfies f(x + y) = f(x) + f(y) and f(1) = 3. Find f(5/2).

HintShow first that f(n) = n·f(1) for integers, then f(1/q) = f(1)/q.
Answer15/2
Method: Integers then fractions

f(n) = nf(1); q·f(1/q) = f(1) so f(1/q) = 3/2, and f(5/2) = 15/2.

Method: Subtract the line

g(x) = f(x) − 3x is additive and zero at every integer, so 2·g(5/2) = g(5) = 0 and f(5/2) = 15/2.

Source: Technique from Small ch. 2–4 (original problem)

Problem p4. f satisfies f(x) + 2·f(1/x) = x for every non-zero real x. Find f(2). (fraction)

HintSubstitute x → 1/x to get a second equation.
Answer-1/3
Method: Solve the system

With a = f(2), b = f(1/2): a + 2b = 2 and b + 2a = 1/2, so a = -1/3.

Method: General formula

f(x) = (x − 2/x)/(1 − 4) = -1/3 at x = 2.

Source: Technique from Small ch. 2–4 (original problem)

Problem p8. f(x + 1) = f(x) + 2x + 1 for integers x and f(0) = 5. Find f(10).

HintAdd up the differences f(k + 1) − f(k).
Answer105
Method: Telescoping

f(10) = 5 + Σ_{k=0}^{9}(2k + 1) = 5 + 100 = 105.

Method: Guess and verify

f(x) = x² + 5 satisfies both conditions, so f(10) = 105.

Source: Technique from Small ch. 2–4 (original problem)

Problem p11. f is completely multiplicative on the positive integers (f(mn) = f(m)f(n)) with f(2) = 3 and f(3) = 2. Find f(72).

HintFactor the number into primes.
Answer108
Method: Factorise

72 = 2·2·2·3·3, so f(72) = 108.

Method: Split

Break 72 into products of smaller numbers and use f(mn) = f(m)f(n); the result is 108.

Problem p15. f(x) = ax + b with a > 0 satisfies f(f(x)) = 4x + 9 for all x. Find f(10).

HintCompare coefficients of f(f(x)) = a²x + (a + 1)b.
Answer23
Method: Coefficients

a² = 4 gives a = 2, and (a + 1)b = 9 gives b = 3, so f(10) = 23.

Method: Test a value

f(f(0)) = (a + 1)b = 9 and f(f(1)) − f(f(0)) = a² = 4; so a = 2, b = 3, f(10) = 23.

Source: Technique from Small ch. 2–4 (original problem)

Problem p19. How many functions f from {1,…,4} to itself satisfy f(f(x)) = x for every x?

HintThese are the involutions; count by the number of 2-cycles.
Answer10
Method: Recurrence

a_n = a_(n−1) + (n − 1)a_(n−2) with a₁ = 1, a₂ = 2 gives a_4 = 10.

Method: Cycle counting

Σ over j pairs of n!/(2^j j! (n − 2j)!) = 10.

Source: Technique from Small ch. 2–4 (original problem)
