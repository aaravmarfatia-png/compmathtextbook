1. Rational expressions: fractions with letters

A rational expression is one polynomial divided by another, such as (x² − 9)/(x + 3). It behaves exactly like an ordinary fraction, with one extra rule: the denominator may never be zero, so some values of x are forbidden. For (x² − 9)/(x + 3) the value x = −3 is not allowed. Every statement you make about the expression holds only for the allowed values.

Simplifying. A fraction is simplified by cancelling a factor that appears in both numerator and denominator. You can only cancel factors (things multiplied), never terms (things added). In (x² − 9)/(x + 3), factor the top as (x − 3)(x + 3). The factor (x + 3) cancels, leaving x − 3, valid for x ≠ −3. The common error is to cancel the x in (x + 2)/x to get “2”; that is wrong, since x is added to 2, not multiplied.

Worked example 1. Simplify (x² − 5x + 6)/(x² − 4). Factor the top: (x − 2)(x − 3). Factor the bottom: (x − 2)(x + 2). Cancel (x − 2) to get (x − 3)/(x + 2), valid for x ≠ 2 and x ≠ −2. Test with x = 5: the original is (25 − 25 + 6)/(25 − 4) = 6/21 = 2/7 and the simplified form gives 2/7. ✓

Multiplying and dividing. Multiply fractions by multiplying tops and bottoms, but factor first so you can cancel. Divide by multiplying by the reciprocal. For ((x + 1)/(x − 2)) × ((x² − 4)/(x² − 1)): factor to get ((x + 1)/(x − 2)) × ((x − 2)(x + 2)/((x − 1)(x + 1))), and everything cancels except (x + 2)/(x − 1).

Why bother? Rational expressions appear in sums of fractions, in equations, and in inequalities. Fluency with factoring, from the last unit, is what makes them short.

2. Adding and subtracting fractions with letters

To add fractions you need a common denominator. With numbers, 1/6 + 1/4 uses 12, the least common multiple of 6 and 4, to give 2/12 + 3/12 = 5/12. With letters the method is the same: factor each denominator, take each factor to its highest power, and use that as the common denominator.

Worked example 1. Compute 1/(x − 1) + 1/(x + 1). The common denominator is (x − 1)(x + 1). The sum is ((x + 1) + (x − 1))/((x − 1)(x + 1)) = 2x/(x² − 1).

Worked example 2. Compute 1/(x² − x) − 1/(x² − 1). Factor: x² − x = x(x − 1) and x² − 1 = (x − 1)(x + 1). The least common denominator is x(x − 1)(x + 1). The numerators become (x + 1) and x, so the difference is (x + 1 − x)/(x(x − 1)(x + 1)) = 1/(x(x² − 1)). Be careful with the minus sign: it applies to the entire second numerator.

Worked example 3: partial fractions, a preview. Show that 1/(n(n + 1)) = 1/n − 1/(n + 1). The right side equals ((n + 1) − n)/(n(n + 1)) = 1/(n(n + 1)). ✓ This simple identity allows sums like 1/(1·2) + 1/(2·3) + … + 1/(9·10) to collapse: it equals (1 − 1/2) + (1/2 − 1/3) + … + (1/9 − 1/10) = 1 − 1/10 = 9/10. This is called telescoping, and Unit 20 returns to it.

Complex fractions. A fraction inside a fraction is simplified by multiplying the top and bottom by the common denominator of the little fractions. For (1 + 1/x)/(1 − 1/x), multiply top and bottom by x: (x + 1)/(x − 1).

3. Degrees and the shape of a polynomial

Recall that the degree is the highest power of x. Degrees tell you what to expect. A polynomial of degree n has at most n real roots, and it can be described completely by n + 1 numbers (its coefficients). The degree rules are: deg(P × Q) = deg P + deg Q, and deg(P + Q) ≤ max(deg P, deg Q), with strict inequality only when the leading terms cancel.

Worked example 1. If P has degree 4 and Q has degree 3, then P × Q has degree 7 and P + Q has degree 4. And what about P² − Q²? The degree of P² is 8, of Q² is 6, so P² − Q² has degree 8. Note that P² − Q² = (P − Q)(P + Q) has degree 4 + 4 = 8, which agrees.

Worked example 2: leading terms cancel. P = x³ + 2x and Q = x³ − x² have the same degree, but P − Q = x² + 2x has degree only 2, because the x³ terms cancel. Whenever you subtract polynomials of equal degree you must check whether the degree drops.

Using degrees to solve problems. Suppose a polynomial P satisfies P(x)² = x⁴ + 6x³ + 11x² + 6x + 1 for all x. Since the right side has degree 4, P has degree 2, say P = x² + bx + c (with leading coefficient 1 since the square gives 1 × x⁴). Compare coefficients: 2b = 6 so b = 3; b² + 2c = 11 so 9 + 2c = 11 and c = 1. Check the x coefficient: 2bc = 6 ✓ and c² = 1 ✓. So P = x² + 3x + 1 (or its negative).

Counting degrees of freedom. A polynomial of degree at most 2 has three free coefficients, so three conditions are needed to fix it. This is the idea behind interpolation, which comes in the next unit.

4. Polynomial long division

When you divide 17 by 5 you get a quotient 3 and remainder 2, since 17 = 5 × 3 + 2. Polynomials work the same way. To divide a polynomial A by a polynomial B, you find a quotient Q and a remainder R such that A = B × Q + R, where the degree of R is smaller than the degree of B. The method mirrors long division with numbers.

Worked example 1. Divide x³ + 2x² − 5x + 1 by x − 2. Step 1: divide the leading term x³ by x to get x². Multiply x² by (x − 2) to get x³ − 2x². Subtract: the remainder so far is 4x² − 5x + 1. Step 2: divide 4x² by x to get 4x. Multiply 4x by (x − 2): 4x² − 8x. Subtract: 3x + 1. Step 3: divide 3x by x to get 3. Multiply 3 by (x − 2): 3x − 6. Subtract: 7. So the quotient is x² + 4x + 3 and the remainder is 7. Check: (x − 2)(x² + 4x + 3) + 7 = x³ + 4x² + 3x − 2x² − 8x − 6 + 7 = x³ + 2x² − 5x + 1. ✓

Worked example 2: missing terms. Divide x⁴ − 1 by x² + 1. Write x⁴ + 0x³ + 0x² + 0x − 1 to keep columns lined up. x⁴ ÷ x² = x². Subtract x²(x² + 1) = x⁴ + x²: the remainder is −x² − 1. Next, −x² ÷ x² = −1. Subtract −1(x² + 1): remainder 0. So the quotient is x² − 1 exactly, which matches the difference-of-squares factorisation x⁴ − 1 = (x² − 1)(x² + 1).

Synthetic division. For a divisor x − r there is a shortcut that keeps only the coefficients. For the first example, write 1, 2, −5, 1 and r = 2. Bring down 1. Multiply by 2 and add to the next: 2 + 2 = 4. Multiply 4 by 2 and add to −5: 3. Multiply 3 by 2 and add to 1: 7. The last number, 7, is the remainder and the others (1, 4, 3) are the quotient's coefficients.

Why it works. Each step removes the leading term, which lowers the degree, so the process must stop. At the end what is left has degree lower than the divisor, and that is the remainder.

5. Dividing to simplify and to solve

Division is also a way to simplify a fraction whose top has higher degree than the bottom. By division, (x² + 3x + 5)/(x + 1): divide to get x + 2 with remainder 3, since (x + 1)(x + 2) = x² + 3x + 2. So the fraction is x + 2 + 3/(x + 1). This form shows how the fraction behaves for large x.

Whole-number values. For which whole numbers n is (n² + 3n + 5)/(n + 1) a whole number? From the division above, the fraction equals n + 2 + 3/(n + 1), so we need (n + 1) to divide 3. The divisors of 3 are ±1, ±3, giving n + 1 = 1, −1, 3 or −3, so n = 0, −2, 2 or −4. Test n = 2: 15/3 = 5 ✓. This approach, division and then divisors of the remainder, is a standard number theory technique.

Worked example: a proof by division. Show that n³ + 2n is divisible by 3 for every whole number n. Rewrite it as n³ − n + 3n = (n − 1)n(n + 1) + 3n. The product of three consecutive numbers is divisible by 3, and so is 3n. So the sum is. This uses factoring (earlier), consecutive-number divisibility, and splitting an expression into pieces we understand.

An identity to remember. For any whole number n, a − b divides aⁿ − bⁿ, because aⁿ − bⁿ = (a − b)(aⁿ⁻¹ + aⁿ⁻²b + … + bⁿ⁻¹). For example 7 − 4 = 3 divides 7ⁿ − 4ⁿ, so 7⁵ − 4⁵ = 16,807 − 1,024 = 15,783 = 3 × 5,261.

6. Mistakes, checks and how to practise

Common mistakes. Cancelling terms instead of factors. Forgetting the forbidden values (denominator zero). Sign slips when subtracting a fraction with several terms on top. Leaving out zero coefficients in long division so that columns do not line up. Stopping division when the degree of the remainder is still at least the degree of the divisor.

Checks. Substitute a number: a simplified fraction must give the same value as the original (for allowed x). After division, multiply back: B × Q + R must equal A. Compare degrees: the quotient has degree deg A − deg B.

Practice. Work the 25 problems, then try the generator for this unit. The ideas here return in Unit 6 (remainder theorem) and again in number theory, where division with remainder is the basic tool.

Problem 130. A pool is split into two equal sections, each with its own pipe. One pipe alone fills its section in 3 hours; the other fills its section in 6 hours. How many hours does it take both pipes together to fill the whole pool once the wall is removed?

HintFind how much of the whole pool each pipe fills per hour.
Answer4
Method: Rates per hour

Pipe 1 fills half the pool in 3 hours, so it fills 1/6 of the pool per hour. Pipe 2 fills half the pool in 6 hours: 1/12 of the pool per hour. Together 1/6 + 1/12 = 3/12 = 1/4 of the pool per hour, so the whole pool takes 4 hours.

Method: General formula

With times a and b the pool needs 2ab/(a + b) hours (derived the same way, with rates 1/(2a) and 1/(2b)). For a = 3, b = 6: 2 · 18/9 = 4.

Method: Fix the size of the pool

Say the pool holds 12 units. Each section holds 6. Pipe 1 gives 6/3 = 2 units per hour, pipe 2 gives 6/6 = 1 unit per hour, together 3 per hour. 12/3 = 4 hours.

Source: Gelfand & Shen, Algebra, Problem 130 (numbers chosen by me)

Problem 131. A motor boat needs 2 hours to go from A to B down the river and 3 hours to go from B to A up the river. How many hours would it need to go from A to B if there were no current? Answer as a fraction or decimal.

HintLet the distance be d. The speed with the current is d/2 and against it is d/3.
Answer12/5
Method: Average the speeds

Downstream speed is d/2 and upstream d/3. The current adds the same amount going down as it subtracts going up, so still-water speed is the average: (d/2 + d/3)/2 = (5d/6)/2 = 5d/12. Time = d ÷ (5d/12) = 12/5 hours.

Method: General formula

The answer is 2ab/(a + b) with a = 2, b = 3: 12/5 = 2.4.

Method: Choose a distance

Let d = 6 km. Downstream speed 3 km/h, upstream 2 km/h, so still-water speed 2.5 km/h. Time = 6/2.5 = 2.4 hours.

Source: Gelfand & Shen, Algebra, Problem 131 (numbers chosen by me)

Problem 132. For the first half of a trip a car goes 30 km/h, and for the second half (of the distance) it goes 60 km/h. What is its mean velocity in km/h?

HintMean velocity = total distance ÷ total time.
Answer40
Method: Pick a distance

Let the whole trip be 120 km. The first 60 km takes 60/30 = 2 hours. The second 60 km takes 60/60 = 1 hour. Total 120 km in 3 hours: 40 km/h.

Method: Formula

For half-distances the mean velocity is 2v₁v₂/(v₁ + v₂) = 2 · 30 · 60/90 = 40.

Method: Why not 45?

The simple average (30 + 60)/2 = 45 is wrong because the car spends twice as long at 30 km/h as at 60 km/h. The harmonic mean 40 is closer to the slow speed.

Source: Gelfand & Shen, Algebra, Problem 132 (numbers chosen by me) (numbers chosen by me)

Problem 133a. You know that x + 1/x = 7. Compute x² + 1/x².

HintSquare both sides.
Answer47
Method: Square

(x + 1/x)² = x² + 2 + 1/x² = 49, so x² + 1/x² = 47.

Method: Solve for x

From x + 1/x = 7 we get x² − 7x + 1 = 0. This does not need to be solved: squaring is faster. (Numerically x ≈ 6.854, and 6.854² + 1/6.854² ≈ 46.98 + 0.021 ≈ 47.)

Source: Gelfand & Shen, Algebra, Problem 133(a)

Problem 133b. You know that x + 1/x = 7. Compute x³ + 1/x³.

HintMultiply (x + 1/x) by (x² + 1/x²).
Answer322
Method: Multiply

(x + 1/x)(x² + 1/x²) = x³ + 1/x + x + 1/x³ = (x³ + 1/x³) + (x + 1/x). So 7 · 47 = (x³ + 1/x³) + 7 and x³ + 1/x³ = 329 − 7 = 322.

Method: Cube the sum

(x + 1/x)³ = x³ + 3x + 3/x + 1/x³ = (x³ + 1/x³) + 3(x + 1/x). So 343 = (x³ + 1/x³) + 21 and the answer is 322.

Source: Gelfand & Shen, Algebra, Problem 133(b)

Problem 136. What is the coefficient of the first (highest-degree) term of (2x + 1)⁵?

HintOnly the top term of each bracket matters.
Answer32
Method: Top terms

The highest power comes from multiplying 2x from each of the five brackets: (2x)⁵ = 32x⁵. The coefficient is 32.

Method: Binomial formula

(a + b)⁵ has the term a⁵ with coefficient 1 (first entry of the row). With a = 2x this is 32x⁵.

Problem 137. A polynomial P has degree 3 and a polynomial Q has degree 4. What is the degree of P · Q?

HintMultiply the top terms.
Answer7
Method: Top terms

The top terms are cx³ and dx⁴; their product cd·x⁷ has degree 7, and nothing else has degree 7, so nothing cancels it.

Method: Example

(x³ + 1)(x⁴ + x) = x⁷ + x⁴ + x⁴ + x = x⁷ + 2x⁴ + x. Degree 7.

Problem 138a. What is the degree of the sum of two polynomials with degrees 7 and 9?

HintWhich top term can the other not cancel?
Answer9
Method: Top term survives

Only the polynomial of degree 9 has an x⁹ term, so nothing cancels it. The degree of the sum is 9.

Method: Example

(x⁹ + 1) + (x⁷ + 2x) = x⁹ + x⁷ + 2x + 1. Degree 9.

Source: Gelfand & Shen, Algebra, Problem 138(a)

Problem 138b. Two polynomials both have degree 7. What is the largest degree their sum could have?

HintCan the top terms cancel? Can they stay?
Answer7
Method: Reason

Both polynomials have no terms above x⁷, so the sum has none either. The degree is at most 7, and it equals 7 unless the x⁷ terms cancel.

Method: Examples

(x⁷ + 1) + (x⁷ + 2) = 2x⁷ + 3 has degree 7. (x⁷ + x) + (−x⁷ + 1) = x + 1 has degree 1. So any degree up to 7 is possible, and 7 is the largest.

Source: Gelfand & Shen, Algebra, Problem 138(b)

Problem 139. A polynomial in x has degree 10. Replace x by y⁷ + 5y² − y − 4 (a polynomial of degree 7). What is the degree of the resulting polynomial in y?

HintThe top term of the result comes from (y⁷)¹⁰.
Answer70
Method: Top term

The top term of the polynomial is cx¹⁰. After substitution it becomes c(y⁷ + …)¹⁰ whose top term is c·y⁷⁰. Nothing else reaches degree 70, so the degree is 70.

Method: Simple example

Take x² with x = y³ + 1: (y³ + 1)² = y⁶ + 2y³ + 1 has degree 6 = 2 · 3. The same product rule (degree of a product = sum of degrees) gives 10 · 7 = 70.

Source: Gelfand & Shen, Algebra, Problem 139

Problem 140a. A polynomial of degree 7 is divided by a polynomial of degree 3. What is the degree of the quotient?

Hintdividend = quotient · divisor + remainder.
Answer4
Method: Degrees add

The product (quotient)(divisor) has degree 7, because the remainder has lower degree. The degrees of the quotient and divisor add to 7, so the quotient has degree 7 − 3 = 4.

Method: Example

x⁷ ÷ x³ = x⁴ with remainder 0. A different dividend of degree 7 gives a quotient with leading term cx⁴.

Source: Gelfand & Shen, Algebra, Problem 140

Problem 140b. A polynomial of degree 7 is divided by a polynomial of degree 3. What is the largest possible degree of the remainder?

HintThe remainder must have a smaller degree than the divisor.
Answer2
Method: Definition

By definition, the remainder has degree less than the divisor's degree, 3. So the largest possible degree is 2 (a remainder like 5x² + 1).

Method: Example

x⁷ + x² = x⁴(x³) + x², so dividing by x³ gives remainder x², which has degree 2.

Source: Gelfand & Shen, Algebra, Problem 140 (remainder part, using the definition of division)

Problem div1. Divide x⁴ by x − 2 as polynomials. What is the remainder?

HintUse long division: x³, 2x², 4x, 8 …
Answer16
Method: Long division

x⁴ ÷ x = x³; subtract x⁴ − 2x³, leaving 2x³. 2x³ ÷ x = 2x²; subtract 2x³ − 4x², leaving 4x². 4x² ÷ x = 4x; subtract 4x² − 8x, leaving 8x. 8x ÷ x = 8; subtract 8x − 16, leaving 16. The remainder is 16 and the quotient is x³ + 2x² + 4x + 8.

Method: Plug in x = 2

When x = 2 the divisor x − 2 is 0, so x⁴ = (quotient)(0) + remainder gives remainder = 2⁴ = 16. (This is the remainder idea Gelfand returns to later.)

Source: Gelfand & Shen, Algebra, section 36 (worked example)

Problem div2. Divide x³ + 2x² + 3x + 4 by x² + x + 2. What is the remainder? (The quotient is x + 1.)

HintMultiply (x + 1) by the divisor and see what is left.
Answer2
Method: Multiply back

(x + 1)(x² + x + 2) = x³ + 2x² + 3x + 2. Subtract from the dividend: (x³ + 2x² + 3x + 4) − (x³ + 2x² + 3x + 2) = 2. The remainder is 2 (degree 0, less than the divisor's degree 2).

Method: Long division

x³ ÷ x² = x; subtract x³ + x² + 2x, leaving x² + x + 4. Then x² ÷ x² = 1; subtract x² + x + 2, leaving 2.

Method: Substitute x = 10

Plugging in x = 10 gives 1234 = (112)(11) + 2, matching the long-division of numbers: 1234 = 112 · 11 + 2.

Source: Gelfand & Shen, Algebra, section 36 (worked example)

Problem div3. Divide x³ + 2x² + 3x + 4 by x − 1. What is the remainder?

HintUse long division, or see what the dividend equals at x = 1.
Answer10
Method: Long division

x³ ÷ x = x²; subtract x³ − x², leaving 3x² + 3x + 4. Then 3x; subtract 3x² − 3x, leaving 6x + 4. Then 6; subtract 6x − 6, leaving 10. The quotient is x² + 3x + 6 and the remainder is 10.

Method: Plug in x = 1

At x = 1 the divisor is 0, so the dividend equals the remainder: 1 + 2 + 3 + 4 = 10.

Problem 128. Gelfand proves (x−a)(x−b)/((c−a)(c−b)) + (x−a)(x−c)/((b−a)(b−c)) + (x−b)(x−c)/((a−b)(a−c)) is the same for all x. Compute it for a = 1, b = 2, c = 3, x = 5.

HintSubstitute and add the three fractions.
Answer1
Method: Substitute

First: (4)(3)/((2)(1)) = 6. Second: (4)(2)/((1)(−1)) = −8. Third: (3)(2)/((−1)(−2)) = 3. Sum: 6 − 8 + 3 = 1.

Method: Special case x = a

At x = a the first two fractions contain (x − a) = 0, so only the third survives: (a − b)(a − c)/((a − b)(a − c)) = 1. The same happens at x = b and x = c, which is why the whole expression is the constant 1.
