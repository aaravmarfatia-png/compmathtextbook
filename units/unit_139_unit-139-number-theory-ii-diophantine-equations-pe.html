Reading

1. Linear and Pell equations

ax + by = c has integer solutions iff gcd(a,b) divides c; once one is found the rest differ by multiples of (b, −a). For 3x + 5y = 100 with positive solutions: x = 5 + 5t... (x, y) = (5,17), (10,14), (15,11), (20,8), (25,5), (30,2): 6 solutions. The Frobenius number for coprime a, b is ab − a − b: for 3 and 5 it is 7. Pell. x² − 2y² = 1 has smallest solution (3,2); all others come from (3 + 2√2)ⁿ.

Try it

Smallest solution of x² − 5y² = 1?

Answer. (9, 4).

Try it

Largest amount not payable with 4- and 7-cent stamps?

Answer. 17.

2. Factoring and Vieta jumping

x² − y² = n becomes (x − y)(x + y) = n; for 45 the factor pairs 1·45, 3·15, 5·9 each have matching parity, giving 3 solutions. Vieta jumping. For x² + y² + 1 = 3xy, if (x, y) is a solution then so is (y, 3y − x), since both are roots of t² − 3yt + y² + 1 = 0. The solutions run (1,1), (1,2), (2,5), (5,13), (13,34), …

Try it

Next pair after (13, 34)?

Answer. (34, 89).

Try it

How many positive solutions to x² − y² = 15?

Answer. 2: (4,1), (8,7).

3. A worked problem

Problem. How many right triangles with integer sides have a leg of 15? Solution. c² − b² = 225 with factor pairs (1,225), (3,75), (5,45), (9,25) each with equal parity, so there are 4 triangles: 15-112-113, 15-36-39, 15-20-25, 8-15-17.

Check. 112² + 15² = 12544 + 225 = 12769 = 113² ✓; 36² + 15² = 1521 = 39² ✓; 8² + 15² = 289 = 17² ✓.

Example 4.7.1 is IMO 1988/6 (if ab + 1 divides a² + b² then the quotient is a perfect square); Example 4.7.2 shows that if ab divides a² + b² + 1 then the quotient is exactly 3, which is the equation x² + y² + 1 = 3xy I count solutions of. For Pell, solutions come from a fundamental solution and the multiplicative norm N(x + y√d) = x² − dy²; Examples 4.8.1 to 4.8.3 treat d = 3, d = 28 and a negative-Pell case.

Problem p1. Find the smallest positive integer x for which x² − 2y² = 1 has a positive integer solution y.

HintSearch small y, or use the continued fraction of √2.
Answer3
Method: Search

Test y = 1, 2, 3, … until 2·y² + 1 is a square; the first square gives x = 3.

Method: Continued fraction

The convergents of √2 produce the fundamental solution with x = 3.

Source: Technique from Khurmi ch. 4 and Gelca & Andreescu 5.3 (original problem)

Problem p5. How many ordered pairs of positive integers (x, y) satisfy 3x + 5y = 100?

HintFind one solution and add multiples of 5 to x.
Answer6
Method: General solution

One solution plus the step (x, y) → (x + 5, y − 3) gives all; counting those with both positive gives 6.

Method: Enumerate

For each x, check whether (100 − 3x) is a positive multiple of 5: 6 values of x work.

Source: Technique from Khurmi ch. 4 and Gelca & Andreescu 5.3 (original problem)

Problem p12. How many right triangles with integer sides have one leg of length 15? (The other leg may be any positive integer; triangles are counted once.)

HintWrite c² − b² = 15² and factor.
Answer4
Method: Factor

(c − b)(c + b) = 15²; the pairs of factors d < e of the same parity give 4 triangles.

Method: Search

Test b from 1 up to (15² − 1)/2 and count the b for which 15² + b² is a square: 4.

Source: Technique from Khurmi ch. 4 and Gelca & Andreescu 5.3 (original problem)

Problem p16. How many pairs of positive integers (x, y) with x ≤ y ≤ 10 satisfy x² + y² + 1 = 3xy?

HintIf (x, y) is a solution then so is (y, 3y − x) — Vieta jumping.
Answer3
Method: Vieta jumping

Starting from (1,1), (1,2): the chain is (1,1),(1,2),(2,5),(5,13),(13,34),…; counting pairs with y ≤ 10 gives 3.

Method: Brute force

Test every pair with x ≤ y ≤ 10: exactly 3 satisfy the equation.

Source: Technique from Khurmi ch. 4 and Gelca & Andreescu 5.3 (original problem)

Problem p20. How many ordered pairs of integers (x, y) satisfy x² + y² = 25?

HintJacobi's formula: r₂(n) = 4(d₁ − d₃).
Answer12
Method: Jacobi

d₁ = 3 divisors ≡ 1 mod 4 and d₃ = 0 divisors ≡ 3 mod 4, so 4(3 − 0) = 12.

Method: List

Run through x from −5 to 5 and test whether 25 − x² is a square: 12 pairs.

Source: Technique from Khurmi ch. 4 and Gelca & Andreescu 5.3 (original problem)
