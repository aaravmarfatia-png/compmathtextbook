Reading

1. Cauchy–Schwarz in three forms

For real numbers, (Σ aᵢ²)(Σ bᵢ²) ≥ (Σ aᵢbᵢ)², with equality exactly when the two lists are proportional. The Engel (Titu) form says Σ aᵢ²/xᵢ ≥ (Σ aᵢ)²/Σ xᵢ for positive xᵢ. Example: for x + y + z = 6, the sum 1/x + 4/y + 9/z is at least (1 + 2 + 3)²/6 = 6, at x : y : z = 1 : 2 : 3, that is (1, 2, 3).

The same inequality gives a constrained minimum: if x + 2y + 2z = 9 then x² + y² + z² ≥ 81/9 = 9, at (1, 2, 2). And a maximum: if x² + y² = 4 then 3x + 4y ≤ 5 · 2 = 10.

Try it

Minimum of 1/x + 1/y for x + y = 4, x, y > 0?

Answer. (1 + 1)²/4 = 1.

Try it

If x² + y² = 1, the maximum of 5x + 12y?

Answer. 13.

2. Rearrangement, Chebyshev, Hölder and Abel

Rearrangement. For two lists, the sum of products of matched pairs is largest when both are sorted the same way and smallest when sorted oppositely. For (1, 3, 4) and (2, 5, 6): the maximum is 1·2 + 3·5 + 4·6 = 41 and the minimum is 1·6 + 3·5 + 4·2 = 29. Chebyshev. For two similarly ordered lists, Σ aᵢbᵢ ≥ (1/n)(Σ aᵢ)(Σ bᵢ). Hölder extends Cauchy–Schwarz to more lists; a consequence is the power mean bound Σ xᵢᵏ ≥ (Σ xᵢ)ᵏ / nᵏ⁻¹. Abel summation turns Σ aᵢbᵢ into a sum of partial sums of one list times differences of the other: 1·2 + 2·4 + 3·8 = 34 = (3 − 1)·2³ + 2.

Try it

Largest sum of matched products for (1, 2, 3) and (4, 5, 6)?

Answer. 4 + 10 + 18 = 32.

Try it

Minimum of x³ + y³ for x + y = 4?

Answer. (4)³/2 = 32.

3. A worked problem

Problem. Positive reals a, b, c have a + b + c = 3. Find the minimum of a/(b + c) + b/(c + a) + c/(a + b) using Cauchy–Schwarz. Solution. By the Engel form, Σ a²/(a(b + c)) ≥ (a + b + c)²/(2(ab + bc + ca)) = 9/(2(ab + bc + ca)), and ab + bc + ca ≤ (a + b + c)²/3 = 3, so the sum is at least 9/6 = 3/2, at a = b = c = 1 (Nesbitt).

Check. At a = b = c = 1 each fraction is 1/2, sum 3/2 ✓.

Problem p1. Real numbers x, y, z satisfy 1x + 2y + 2z = 9. What is the minimum value of x² + y² + z²? (fraction if needed)

HintApply Cauchy–Schwarz to (p, q, r) and (x, y, z).
Answer9
Method: Cauchy–Schwarz

(1² + 2² + 2²)(x² + y² + z²) ≥ (1x + 2y + 2z)² = 81, so x² + y² + z² ≥ 81/9 = 9, with equality when (x, y, z) is proportional to (1, 2, 2).

Method: Foot of the perpendicular

The point of the plane 1x + 2y + 2z = 9 closest to the origin is t(1, 2, 2) with t = 1; its squared distance is 9.

Source: Technique from Pham Kim Hung ch. 2, 3, 5 and Straight from the Book ch. 2 (original problem)

Problem p12. Positive reals x₁, …, x_4. What is the minimum value of (x₁ + … + x_4)(1/x₁ + … + 1/x_4)?

HintCauchy–Schwarz with the vectors (√xᵢ) and (1/√xᵢ).
Answer16
Method: Cauchy–Schwarz

(Σ xᵢ)(Σ 1/xᵢ) ≥ (Σ 1)² = 4²= 16, with equality when all xᵢ are equal.

Method: AM-HM

The arithmetic mean is at least the harmonic mean, so the product is at least 16.

Problem p15. The numbers 1, 3, 4, 7 are matched one-to-one with the numbers 2, 5, 6, 9. What is the largest possible value of the sum of the products of matched pairs?

HintRearrangement inequality: match large with large.
Answer104
Method: Rearrangement

Sort both lists increasingly and pair equal positions: 1·2, 3·5, 4·6, 7·9, sum 104.

Method: Exchange argument

If a larger a were matched to a smaller b while a smaller a had the larger b, swapping would not decrease the sum; so the sorted matching is optimal, giving 104.

Source: Technique from Pham Kim Hung ch. 2, 3, 5 and Straight from the Book ch. 2 (original problem)

Problem p20. Positive reals x₁, …, x_4 have sum 8. What is the minimum of x₁^3 + … + x_4^3? (fraction if needed)

HintUse the power mean inequality or Hölder.
Answer32
Method: Power mean

(Σ xᵢ^3 / 4)^(1/3) ≥ Σ xᵢ/4, so Σ xᵢ^3 ≥ 8^3/4^2 = 32.

Method: Hölder

(Σ xᵢ^3)(4)^2 ≥ (Σ xᵢ)^3 gives Σ xᵢ^3 ≥ 32.

Problem p23. Compute 1·2 + 2·2² + 3·2³ + … + 6·2^6.

HintUse Abel summation (summation by parts), or differentiate a geometric series.
Answer642
Method: Abel summation

Σ k rᵏ = r(1 − (n + 1)rⁿ + n rⁿ⁺¹)/(1 − r)²; with n = 6, r = 2 this equals 642.

Method: Direct

Add the 6 terms 2, 8, 24, 64, 160, 384: 642.
