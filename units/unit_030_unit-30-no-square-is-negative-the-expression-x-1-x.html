Reading

1. No square is negative

The fact that every real number squared is at least zero, and equals zero only for zero, is a source of many beautiful inequalities. The basic one is (x − y)² ≥ 0, which expands to x² − 2xy + y² ≥ 0, i.e. x² + y² ≥ 2xy, with equality exactly when x = y. Every argument in this unit is a variation on this single idea: rewrite an expression as a sum of squares plus a constant.

Completing the square. x² − 6x + 11 = (x − 3)² + 2 ≥ 2, so the smallest value is 2, reached when x = 3. And −x² + 4x + 1 = 5 − (x − 2)², so the largest value is 5, at x = 2. For a general quadratic ax² + bx + c with a > 0, the minimum is at x = −b/(2a); for 3x² − 12x + 7 = 3(x − 2)² − 5 the minimum is −5 at x = 2. The identities were confirmed by algebra software.

Products with a fixed sum. If x + y = 10, then xy = x(10 − x) = 25 − (x − 5)² ≤ 25, so the product is at most 25 and the maximum occurs when x = y = 5. The general rule: among all rectangles of the same perimeter, the square has the greatest area.

A sum of squares equal to zero. If x² + y² − 4x + 6y + 13 = 0, then (x − 2)² + (y + 3)² = 0. Each square is non-negative and their sum is zero, so each is zero: x = 2 and y = −3. This 'sum of squares' trick turns one equation into two.

Try it

Find the minimum of x² + 4x + 9 and where it occurs.

Answer. (x + 2)² + 5, so the minimum is 5, at x = −2.

2. The expression x + 1/x

For x > 0 we have x + 1/x ≥ 2, with equality only at x = 1. Proof: x + 1/x − 2 = (x − 1)²/x ≥ 0, or (√x − 1/√x)² ≥ 0. For x < 0 the sum is at most −2 (apply the result to −x). So x + 1/x never takes values strictly between −2 and 2 for real x. Similarly, x + 4/x ≥ 4 for x > 0, with equality at x = 2: a computer scan agrees that the smallest value is exactly 4.

Ratios. For positive a and b, a/b + b/a ≥ 2; and (a + b)(1/a + 1/b) ≥ 4, because expanding gives 2 + a/b + b/a. Both were tested on a thousand random positive pairs.

The idea of a substitution. Put t = x + 1/x. Then x² + 1/x² = t² − 2, because t² = x² + 2 + 1/x². For example, if x + 1/x = 3, then x² + 1/x² = 7, and x³ + 1/x³ = t³ − 3t = 27 − 9 = 18, and x⁴ + 1/x⁴ = 7² − 2 = 47. Numerically, with x = (3 + √5)/2 all of these hold. Each new power follows from the recurrence pₙ = t pₙ₋₁ − pₙ₋₂ with p₀ = 2, p₁ = t: for t = 3 the sequence is 2, 3, 7, 18, 47, 123.

Differences. If x − 1/x = 2, then x² + 1/x² = (x − 1/x)² + 2 = 6 and x³ − 1/x³ = (x − 1/x)³ + 3(x − 1/x) = 8 + 6 = 14, checked at x = 1 + √2.

Try it

If x + 1/x = 5, find x² + 1/x².

Answer. 25 − 2 = 23.

3. Solving equations with x + 1/x

Reciprocal equations. A polynomial whose coefficients read the same forwards and backwards can be solved by dividing by a power of x and substituting t = x + 1/x. Consider x⁴ − 5x³ + 8x² − 5x + 1 = 0. Divide by x²: x² + 1/x² − 5(x + 1/x) + 8 = 0. With t = x + 1/x this becomes (t² − 2) − 5t + 8 = t² − 5t + 6 = 0, so t = 2 or t = 3. Then x + 1/x = 2 gives x = 1 (a double root), and x + 1/x = 3 gives x = (3 ± √5)/2. Check by factoring: the quartic equals (x − 1)²(x² − 3x + 1).

Direct use. x + 1/x = 5/2 means 2x² − 5x + 2 = 0, so x = 2 or x = 1/2: the two solutions are reciprocals of each other, as they always are for equations in x + 1/x.

Which values of t are possible? For real x, t = x + 1/x requires |t| ≥ 2. If your substitution yields a value of t with |t| < 2, the original equation has no real root from that branch (it has complex ones).

Try it

Solve x + 1/x = 10/3.

Answer. 3x² − 10x + 3 = 0, so x = 3 or x = 1/3.

4. Inequalities from squares

Three variables. a² + b² + c² − ab − bc − ca = ½[(a − b)² + (b − c)² + (c − a)²] ≥ 0, so a² + b² + c² ≥ ab + bc + ca. Adding 2(ab + bc + ca) to both sides: (a + b + c)² ≥ 3(ab + bc + ca). Both identities were checked algebraically.

Averages. From (a − b)² ≥ 0 we get (a + b)² ≤ 2(a² + b²): the square of the sum is at most twice the sum of the squares. So if a² + b² = 1, then a + b ≤ √2, with equality when a = b = 1/√2.

Cauchy in two variables. The identity (x² + 1)(1 + y²) = (x + y)² + (xy − 1)² shows that (x² + 1)(y² + 1) ≥ (x + y)², with equality exactly when xy = 1. It is the two-variable case of the Cauchy–Schwarz inequality from Unit 14.

A bounded fraction. x/(x² + 1) ≤ 1/2 for every real x, because (x − 1)² ≥ 0 gives x² + 1 ≥ 2x. Equality at x = 1. When a fraction involves x and 1/x, divide top and bottom by x.

Try it

Prove that a² + b² + 1 ≥ ab + a + b.

Answer. Multiply by 2: (a − b)² + (a − 1)² + (b − 1)² ≥ 0.

5. Optimisation problems

The method. To find the greatest or least value of an expression: (1) rewrite it as a perfect square (or sum of squares) plus a constant, or use x + 1/x ≥ 2; (2) read off the extreme value; (3) say when equality holds and check that such values of the variables are allowed.

Example 1. Minimise x² + 1/x² + x + 1/x for x > 0. With t = x + 1/x ≥ 2, the expression is t² − 2 + t, increasing for t ≥ 2, so the minimum is 4 − 2 + 2 = 4, at x = 1. Example 2. A rectangle has perimeter 20. Its area is x(10 − x) = 25 − (x − 5)² ≤ 25: the maximum area is 25. Example 3. Find the minimum of 3x² − 12x + 7: it is −5 at x = 2.

Common trap. Making sure that equality can actually be achieved. The inequality x + 1/x ≥ 2 gives the minimum of (x + 1/x) + something only when the other terms can also be minimised at x = 1.

Try it

Find the maximum of x(12 − 2x) for real x.

Answer. 2x(6 − x) = 2(9 − (x − 3)²) = 18 − 2(x − 3)², maximum 18 at x = 3.

6. A longer problem

Problem. Let x be a positive real number with x + 1/x = 4. Find x² + 1/x², x⁴ + 1/x⁴ and x³ + 1/x³. Then find the smallest possible value of (x + 1/x)² + (x² + 1/x²) over all positive real x, and say when it occurs.

Solution. x² + 1/x² = 16 − 2 = 14. x⁴ + 1/x⁴ = 14² − 2 = 194. x³ + 1/x³ = 4³ − 3 · 4 = 52. For the optimisation, put t = x + 1/x ≥ 2: then the expression is t² + (t² − 2) = 2t² − 2 ≥ 2 · 4 − 2 = 6, with equality at t = 2, i.e. x = 1.

Reflection. The substitution t = x + 1/x lets one function of x serve every power, and the range t ≥ 2 gives the optimisation for free. Always ask what restriction the new variable obeys.

7. Mistakes, checks and how to practise

Common mistakes. (1) Using x + 1/x ≥ 2 for negative x. (2) Forgetting to state when equality holds. (3) Taking the square root of both sides without ±. (4) Believing a minimum is attained when the equality case is impossible. (5) Substituting t = x + 1/x and forgetting that t must satisfy |t| ≥ 2.

Checks. Test your extreme value by trying numbers on either side of the claimed minimiser. Substitute the claimed equality case. Check the identity you used by expanding both sides.

How to practise. Complete the square on every quadratic you meet. In Unlimited practice, rotate the x + 1/x and sum-of-squares families.
