Reading

1. Roots of unity

The solutions of zⁿ = 1 are z = cos(2πk/n) + i sin(2πk/n) for k = 0, 1, …, n − 1, the n-th roots of unity, which are the vertices of a regular n-gon on the unit circle. If ω is a primitive root (for example ω = e^(2πi/n)) they are 1, ω, ω², …, ωⁿ⁻¹. Factorisation: xⁿ − 1 = (x − 1)(x − ω)⋯(x − ωⁿ⁻¹).

The sum is zero. 1 + ω + … + ωⁿ⁻¹ = (ωⁿ − 1)/(ω − 1) = 0. Taking real parts: Σ cos(2πk/n) = 0. For n = 5: 1 + 2 cos 72° + 2 cos 144° = 0, so cos 72° + cos 144° = −1/2 (check: 0.309 − 0.809 = −0.5 ✓).

The product of distances. Dividing xⁿ − 1 by x − 1 and setting x = 1: Π_{k=1}^{n−1}(1 − ωᵏ) = n. For n = 4: (1 − i)(1 − (−1))(1 + i) = (1 − i)(1 + i) × 2 = 2 × 2 = 4 ✓. So the product of the distances from one vertex of a regular n-gon (inscribed in a unit circle) to the other vertices is n.

2. Computing with complex numbers

Powers of i: i²⁰²⁵ = i (2025 = 4 × 506 + 1). Powers of 1 + i: (1 + i)² = 2i so (1 + i)²⁰ = (2i)¹⁰ = 1,024 × i¹⁰ = 1,024 × (−1) = −1,024.

Using the cube roots of unity. If ω = (−1 + i√3)/2 then ω³ = 1 and 1 + ω + ω² = 0. So (1 + ω)(1 + ω²) = 1 + ω + ω² + ω³ = 1 and 1/(1 + ω) = 1 + ω² = −ω. Also, a³ + b³ = (a + b)(a + ωb)(a + ω²b), which factors a sum of cubes over the complex numbers.

Worked example. Evaluate (1 + ω)⁶. Since 1 + ω = −ω², (1 + ω)⁶ = ω¹² = 1.

Worked example 2. Find Σ_{k=0}^{5} ωᵏ for ω a primitive 6th root of unity: 0. And for ω a primitive cube root, Σ_{k=0}^{8} ωᵏ = 3 × 0 = 0.

3. Roots of unity filters

To find the sum of the binomial coefficients C(n, k) with k divisible by 3, use ω a primitive cube root of unity: (1 + 1)ⁿ + (1 + ω)ⁿ + (1 + ω²)ⁿ = 3 Σ_{3 | k} C(n, k). For n = 6: 64 + (−ω²)⁶ + (−ω)⁶ = 64 + 1 + 1 = 66, so the sum is 22. Direct check: C(6, 0) + C(6, 3) + C(6, 6) = 1 + 20 + 1 = 22 ✓.

Geometry. A triangle with vertices a, b, c is equilateral iff a² + b² + c² = ab + bc + ca.

Worked example. The points 0, 1, and (1 + i√3)/2 form an equilateral triangle: a² + b² + c² = 0 + 1 + (1 + i√3)²/4 = 1 + (−2 + 2i√3)/4 = 1/2 + i√3/2, and ab + bc + ca = 0 + (1 + i√3)/2 + 0 = 1/2 + i√3/2 ✓.

4. Mistakes, checks and how to practise

Common mistakes. Forgetting that Σωᵏ = 0 requires ω ≠ 1. Taking the wrong power cycle. Mixing degrees and radians. Forgetting the factor 3 in a filter.

Checks. Check small n explicitly.

Practice. Plot roots of unity on the unit circle.

Worked examples with Try-its: Arithmetic and polar form

With i² = −1 the powers of i cycle through i, −1, −i, 1. The modulus |a + bi| = √(a² + b²), so |3 + 4i| = 5. In polar form z = r(cos θ + i sin θ) = re^{iθ}, multiplying adds angles and multiplies moduli. Since (1 + i)² = 2i, we get (1 + i)⁸ = (2i)⁴ = 16 and |(1 + i)¹⁰| = (√2)¹⁰ = 32.

Try it

Compute i²⁰²⁶.

Answer. 2026 = 4 · 506 + 2, so i²⁰²⁶ = i² = −1.

Worked examples with Try-its: Roots of unity

The n-th roots of unity are e^{2πik/n} for k = 0, …, n − 1, spaced 360/n degrees apart on the unit circle, and they add to zero. With ω = e^{2πi/3}: ω³ = 1, 1 + ω + ω² = 0, and (1 − ω)(1 − ω²) = 3. This last product is the derivative-at-1 trick: xⁿ − 1 = ∏(x − ωᵏ), so ∏(1 − ωᵏ) over k = 1 to n − 1 equals n.

Try it

What is 1 + ω + ω² + ω³ + ω⁴ + ω⁵?

Answer. 0 (two full cycles).

Worked examples with Try-its: A longer problem

Problem. Find the real part of (1 + i√3)⁶. Solution. 1 + i√3 = 2e^{iπ/3}, so the sixth power is 2⁶e^{2πi} = 64.

Reflection. Convert to polar before taking a power.

More worked examples: Worked examples

Square root. (1 + 2i)² = 1 − 4 + 4i = −3 + 4i, so the square roots of −3 + 4i are ±(1 + 2i). Fourth roots of −1. They are e^{i(π/4 + kπ/2)}, namely (±1 ± i)/√2; their sum is 0 and their product is 1 (the constant term of z⁴ + 1). The conjugate of a product is the product of the conjugates, and |zw| = |z||w|.

Try it

Find (1 + i)(1 − 2i).

Answer. 3 − i.

Try it

What is the modulus of (3 + 4i)/(1 − i)?

Answer. 5/√2.

More worked examples: A second longer problem

Problem. Solve z² + 2z + 5 = 0. Solution. z = (−2 ± √(4 − 20))/2 = −1 ± 2i. The roots are conjugates, as for any real polynomial.

Check. (−1 + 2i)² = 1 − 4i − 4 = −3 − 4i and −3 − 4i − 2 + 4i + 5 = 0 ✓.

Problem p1. Find the product (1 − ω)(1 − ω²)(1 − ω³)(1 − ω⁴), where ω is a primitive 5th root of unity.

HintEvaluate (x⁵ − 1)/(x − 1) at x = 1.
Answer5
Method: Polynomial identity

Π(x − ωᵏ) = 1 + x + x² + x³ + x⁴, and at x = 1 this is 5.

Method: Numeric

The product of |1 − ωᵏ| = 2 sin(πk/5) over k = 1..4 has value 5.

Problem p2. Let ω = cos 120° + i sin 120°. Find |ω − 1|².

HintUse coordinates.
Answer3
Method: Coordinates

ω = (−1/2, √3/2) so ω − 1 = (−3/2, √3/2) and |ω − 1|² = 9/4 + 3/4 = 3.

Method: Identity

|ω − 1|² = (ω − 1)(ω̄ − 1) = 1 − ω − ω̄ + 1 = 2 + 1 = 3 since ω + ω̄ = −1.

Problem x18. What is the remainder when 9^50 is divided by 11?

HintFind the pattern of remainders of successive powers.
Answer1
Method: Cycle of remainders

The remainders of 9, 9², 9³, … are 9, 4, 3, 5, 1, and then they repeat from position 1 with period 5. Exponent 50 lands on 1.

Method: Repeated squaring

Write 50 = 110010 in binary. The squares 9^(2^i) mod 11 are 9, 4, 5, 3, 9, 4; multiplying the ones for the 1-bits gives 1.
