Reading

1. Series and sigma notation

The symbol Σ means 'add up': Σₖ₌₁ⁿ aₖ = a₁ + … + aₙ. Useful facts: Σ k = n(n + 1)/2; Σ k² = n(n + 1)(2n + 1)/6; Σ k³ = (n(n + 1)/2)². For n = 10: 55, 385 and 3,025. The sum of a constant c over n terms is nc, and constants and sums can be pulled out: Σ (3k² + 2k) = 3Σk² + 2Σk.

Worked example 1. Compute 1² + 2² + … + 20². 20 × 21 × 41/6 = 17,220/6 = 2,870.

Worked example 2. Compute Σₖ₌₁¹⁰ (2k − 1)² = 4Σk² − 4Σk + 10 = 4 × 385 − 4 × 55 + 10 = 1,540 − 220 + 10 = 1,330. Check directly: 1 + 9 + 25 + 49 + 81 + 121 + 169 + 225 + 289 + 361 = 1,330 ✓.

Why Σk² works. Telescoping: (k + 1)³ − k³ = 3k² + 3k + 1. Adding for k = 1 … n: (n + 1)³ − 1 = 3Σk² + 3Σk + n. Solve for Σk².

2. Arithmetic–geometric series and infinite series

A sum such as Σ k xᵏ (an arithmetic factor times a geometric one) can be found by the 'multiply and subtract' trick, as for geometric series. For |x| < 1, Σₖ₌₁^∞ k xᵏ = x/(1 − x)². With x = 1/2: 2 ✓ (1/2 + 2/4 + 3/8 + 4/16 + … = 2).

Worked example. Compute 1/3 + 2/9 + 3/27 + … = Σ k/3ᵏ = (1/3)/(1 − 1/3)² = (1/3)/(4/9) = 3/4.

Convergence tests. A series converges if its terms shrink fast enough. The ratio test: if |aₖ₊₁/aₖ| tends to a number below 1, the series converges. Σ 1/k² converges (to π²/6 ≈ 1.6449) but Σ 1/k does not.

Worked example. Σ 1/(k(k + 2)) for k = 1 to ∞ = ½(1 + 1/2) = 3/4 (telescoping, as in Unit 20).

3. Recurrence and closed forms

To find a closed form for a sum, compute the first terms and see whether the sum is a polynomial in n; then check or prove by induction. The sum of the first n triangular numbers 1, 3, 6, 10 is 1, 4, 10, 20: n(n + 1)(n + 2)/6 (tetrahedral numbers).

Worked example. Σₖ₌₁ⁿ k(k + 1) = n(n + 1)(n + 2)/3 (Unit 20). For n = 4: 2 + 6 + 12 + 20 = 40 = 4 × 5 × 6/3 ✓.

Using sums to solve problems. How many terms of 1 + 2 + 3 + … are needed for the sum to exceed 1,000? n(n + 1)/2 > 1,000: n = 44 gives 990, n = 45 gives 1,035. So 45 terms.

4. Mistakes, checks and how to practise

Common mistakes. Using the wrong starting index. Applying the infinite geometric formula when |x| ≥ 1. Forgetting that Σ k² ≠ (Σ k)². Using n instead of n − 1 for the number of terms.

Checks. Test the closed form with n = 1, 2, 3.

Practice. Write the first three terms of each sum to be sure of the pattern.

Worked examples with Try-its: Arithmetic and geometric sequences

An arithmetic sequence adds a constant d: its n-th term is a + (n − 1)d and the sum of n terms is n(first + last)/2, so 1 + 2 + … + 100 = 5050. A geometric sequence multiplies by a ratio r: the sum is a(1 − rⁿ)/(1 − r), and if |r| < 1 the infinite sum is a/(1 − r), so 1 + 1/2 + 1/4 + … = 2. Useful sums: Σk² = n(n + 1)(2n + 1)/6, so the first ten squares total 385.

Telescoping. Since 1/(k(k + 1)) = 1/k − 1/(k + 1), the sum for k = 1 to n is 1 − 1/(n + 1); for n = 10 it is 10/11.

Try it

Sum of 3 + 7 + 11 + … + 43?

Answer. 11 terms, (3 + 43) · 11/2 = 253.

Worked examples with Try-its: Recurrences

A linear recurrence such as aₙ = 5aₙ₋₁ − 6aₙ₋₂ is solved by trying aₙ = xⁿ, which gives x² = 5x − 6, so x = 2 or 3 and aₙ = A·2ⁿ + B·3ⁿ. With a₀ = 2 and a₁ = 5 we get A = B = 1, so aₙ = 2ⁿ + 3ⁿ (check: a₂ = 25 − 12 = 13 = 4 + 9). Fibonacci numbers satisfy Fₙ = Fₙ₋₁ + Fₙ₋₂ with characteristic roots (1 ± √5)/2.

First-order recurrences. For aₙ₊₁ = 2aₙ + 1 with a₁ = 1, add 1 to both sides: aₙ₊₁ + 1 = 2(aₙ + 1), so aₙ + 1 = 2ⁿ and aₙ = 2ⁿ − 1 (1, 3, 7, 15, 31, 63).

Try it

Solve aₙ = 3aₙ₋₁ with a₀ = 4, and find a₅.

Answer. aₙ = 4 · 3ⁿ; a₅ = 972.

Worked examples with Try-its: A longer problem

Problem. The sequence is defined by x₁ = 1, x₂ = 1 and xₙ = xₙ₋₁ + 2xₙ₋₂. Find a closed form and x₁₀.

Solution. Characteristic equation x² = x + 2 has roots 2 and −1, so xₙ = A·2ⁿ + B(−1)ⁿ. From x₁ = 2A − B = 1 and x₂ = 4A + B = 1 we get 6A = 2, A = 1/3, B = −1/3, so xₙ = (2ⁿ − (−1)ⁿ)/3. Then x₁₀ = (1024 − 1)/3 = 341.

Reflection. Always test the formula on the first few terms: the sequence is 1, 1, 3, 5, 11, 21, 43, 85, 171, 341.

More worked examples: Worked examples

Arithmetic. For aₙ = 3n + 2 the first ten terms sum to 10 · (5 + 32)/2 = 185. Geometric. The first five terms of 2, 6, 18, … sum to 2(3⁵ − 1)/2 = 242. Repeated root. For aₙ = 4aₙ₋₁ − 4aₙ₋₂ with a₀ = 1 and a₁ = 4 the characteristic equation has the double root 2, so aₙ = (A + Bn)2ⁿ; the starting values give aₙ = (n + 1)2ⁿ, for example a₂ = 12 = 4 · 4 − 4 · 1.

Try it

Sum of the infinite series 1/3 + 1/9 + 1/27 + … ?

Answer. (1/3)/(1 − 1/3) = 1/2.

Try it

Find a₁₀ if a₁ = 7 and each term is 4 more than the previous.

Answer. 7 + 9 · 4 = 43.

More worked examples: A second longer problem

Problem. The sequence is defined by a₁ = 1 and aₙ₊₁ = aₙ + 2n + 1. Find aₙ. Solution. The differences 3, 5, 7, … are odd numbers, so aₙ = 1 + 3 + 5 + … + (2n − 1) = n². Check: 1, 4, 9, 16.

Reflection. Telescoping the differences gives a closed form directly.
