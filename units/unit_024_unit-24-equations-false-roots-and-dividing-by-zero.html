Reading

1. What an equation really says

An equation asks: for which values of the unknown do the two sides agree? Solving means finding all such values — and nothing else. Each step in a solution replaces one equation by another. The new equation may have exactly the same solutions (the steps are equivalent), or it may have more (a step has introduced false roots), or fewer (a step has lost solutions). Good solving is the habit of knowing which has happened.

Safe steps. Adding or subtracting the same quantity on both sides, and multiplying or dividing both sides by a non-zero number, never change the solutions. Expanding, collecting and simplifying brackets are safe too, as long as the expression is defined for the same values of x before and after.

Risky steps. (1) Multiplying both sides by an expression containing x: if that expression is 0 for some x, you may add that x as a false root. (2) Dividing both sides by an expression containing x: if it is 0 for some x you may lose that x. (3) Squaring both sides: a = b implies a² = b², but a² = b² only implies a = ±b, so false roots can appear. (4) Taking logarithms or removing them. Each of these requires a check at the end.

The golden rule. Whenever a step is not reversible, substitute each candidate into the original equation. Substitution is the only proof that is independent of the method.

Try it

Is the step 'divide both sides of x(x − 2) = 3x by x' safe?

Answer. No: it loses the solution x = 0. Writing x(x − 2) − 3x = 0 gives x(x − 5) = 0 and the solutions x = 0 and x = 5.

2. Dividing by zero and lost roots

Division by zero is undefined, and the bad habit of dividing by an expression that might be zero produces both false 'proofs' and lost solutions. The classic fallacy. Let a = b = 1. Then a² = ab, so a² − b² = ab − b², so (a − b)(a + b) = b(a − b). 'Dividing by a − b' gives a + b = b, that is 2 = 1. The error is the division by a − b, which equals 0.

Lost solutions. Solve (x − 1)(x − 2) = 3(x − 1). If we divide by x − 1 we get x − 2 = 3 and x = 5, but x = 1 also works (both sides are 0). The correct way is to move everything to one side and factor: (x − 1)(x − 2 − 3) = 0, so x = 1 or x = 5 (the computer algebra system gives the same pair). Likewise x³ = x has three solutions, −1, 0 and 1, not two.

Rule. Never cancel a common factor that contains the unknown unless you separately examine the case where that factor is zero. The safe habit is to bring all terms to one side and factor.

Try it

Solve x(x + 1) = 2(x + 1).

Answer. (x + 1)(x − 2) = 0, so x = −1 or x = 2. Dividing by x + 1 would lose x = −1.

3. Rational equations and excluded values

With fractions, the first thing to do is to state the excluded values: any x making a denominator zero. Then multiply through by the common denominator and solve, discarding any answer that is excluded.

Example 1. Solve (x² − 9)/(x − 3) = 6. For x ≠ 3, the left side simplifies to x + 3, so x + 3 = 6 and x = 3. But x = 3 is excluded. So there is no solution (the computer solver also returns the empty set). Example 2. x/(x − 2) = 2/(x − 2). Multiplying by x − 2 gives x = 2, which is excluded; no solution. Example 3. 1/(x − 1) + 1/(x + 1) = 2/(x² − 1). Combining gives 2x/(x² − 1) = 2/(x² − 1), so x = 1, excluded: no solution.

Example 4 (with solutions). 3/(x − 1) − 2/(x + 1) = 1. Multiply by (x − 1)(x + 1): 3(x + 1) − 2(x − 1) = x² − 1, i.e. x + 5 = x² − 1, so x² − x − 6 = 0 and x = 3 or x = −2. Neither is excluded (1 and −1 are), and substitution confirms both: at x = 3 the left side is 3/2 − 2/4 = 1; at x = −2 it is −1 + 2 = 1.

Try it

Solve 1/x + 1/(x − 1) = 1.

Answer. Excluded: 0, 1. Multiply by x(x − 1): (x − 1) + x = x² − x, so x² − 3x + 1 = 0 and x = (3 ± √5)/2. Neither is excluded.

4. Radical equations

When the unknown is under a square root, isolate the root and square. Because squaring can create false roots, always check. Example 1. √(x + 2) = x. Squaring: x + 2 = x², so x² − x − 2 = 0 and x = 2 or x = −1. Check: √4 = 2 ✓; √1 = 1 but the right side is −1 ✗. So the only solution is x = 2. The reason: a square root is never negative, so the right side x must be ≥ 0.

Example 2. √(2x − 1) = x − 2. Squaring: 2x − 1 = x² − 4x + 4, so x² − 6x + 5 = 0 and x = 1 or 5. Check: x = 5 gives √9 = 3 = 3 ✓; x = 1 gives √1 = 1 but x − 2 = −1 ✗. So only x = 5. A shortcut. Before squaring, note the condition: x − 2 ≥ 0, i.e. x ≥ 2. Then x = 1 is eliminated without any substitution.

Two roots. √(x + 4) + √(x − 1) = 5. Isolate one root: √(x + 4) = 5 − √(x − 1); square: x + 4 = 25 − 10√(x − 1) + x − 1; simplify: 10√(x − 1) = 20, so √(x − 1) = 2 and x = 5. Check: √9 + √4 = 3 + 2 = 5 ✓. Another. √x + √(x + 9) = 9 gives x = 16 (4 + 5 = 9 ✓). And √(3x + 1) − √(x − 1) = 2 has two valid solutions, x = 1 and x = 5 (2 − 0 = 2 and 4 − 2 = 2), so false roots do not always appear; but you cannot know without checking.

Try it

Solve √(3x + 3) = x + 1.

Answer. Square: 3x + 3 = x² + 2x + 1, so x² − x − 2 = 0 and x = 2 or x = −1. Check: x = 2: √9 = 3 ✓. x = −1: √0 = 0 and the right side is 0 ✓. Both are valid.

5. Absolute value equations

|A| = B means A = B or A = −B, but only if B ≥ 0. Example 1. |x − 1| = 2x + 1. Case A = B: x − 1 = 2x + 1 gives x = −2, but then B = −3 is negative: rejected. Case A = −B: x − 1 = −2x − 1 gives x = 0, and B = 1 ≥ 0 ✓. So x = 0 is the only solution (confirmed by the solver).

Example 2. |2x − 3| = |x + 1|. Both sides are absolute values, so there is no sign restriction: 2x − 3 = x + 1 gives x = 4, or 2x − 3 = −(x + 1) gives x = 2/3. Check x = 4: |5| = |5| ✓; x = 2/3: |−5/3| = |5/3| ✓.

Strategy. Either split into cases on the sign of the expression inside, solving each case on its own interval, or square both sides when both are absolute values. In every case verify that your solution lies in the interval assumed.

Try it

Solve |x + 2| = 3x − 2.

Answer. Need 3x − 2 ≥ 0. Case 1: x + 2 = 3x − 2 gives x = 2 ✓. Case 2: x + 2 = −3x + 2 gives x = 0, but then the right side is −2: rejected. So x = 2.

6. Logarithmic and exponential equations

Logarithms. log x + log(x − 3) = log 4. Combining gives log(x(x − 3)) = log 4, so x(x − 3) = 4, x² − 3x − 4 = 0, x = 4 or −1. But a logarithm needs a positive argument, so x > 3, and x = −1 is a false root. The only solution is x = 4.

The domain principle. Before solving, write down the domain: x > 0 and x − 3 > 0. The domain cuts out false roots immediately. This is exactly like the excluded values for fractions.

Exponentials. 4ˣ − 3 · 2ˣ − 4 = 0. Substitute t = 2ˣ (which must be positive): t² − 3t − 4 = 0, so t = 4 or t = −1. Since t > 0, only t = 4, giving x = 2. The substitution t = 2ˣ hides a restriction (t > 0) which must be applied at the end. Check: 16 − 12 − 4 = 0 ✓.

Try it

Solve log₂(x) + log₂(x − 2) = 3.

Answer. x(x − 2) = 8, so x² − 2x − 8 = 0 and x = 4 or x = −2. The domain requires x > 2, so x = 4. Check: log₂ 4 + log₂ 2 = 2 + 1 = 3 ✓.

7. A longer problem

Problem. Solve √(x + 7) + 1 = x. Then solve the equation (x − 1)(x − 3)/(x − 3) = x + 4 and decide whether x = 3 is a solution.

Solution. First: isolate the root, √(x + 7) = x − 1, and note that x − 1 ≥ 0. Squaring: x + 7 = x² − 2x + 1, so x² − 3x − 6 = 0 and x = (3 ± √33)/2 ≈ 4.37 or −1.37. Only the positive root satisfies x ≥ 1, so x = (3 + √33)/2. Second: for x ≠ 3 the left side simplifies to x − 1, and x − 1 = x + 4 has no solution at all (it reduces to −1 = 4). At x = 3 the left side is undefined, so 3 is not a solution either.

Reflection. The first part is a model of the standard routine: isolate, record the sign condition, square, solve, discard. The second shows that an equation can be simplified into a contradiction, in which case the solution set is empty.

8. Mistakes, checks and how to practise

Common mistakes. (1) Cancelling a factor that can be zero. (2) Forgetting to check after squaring. (3) Forgetting the domain of logarithms and square roots. (4) Forgetting the case B < 0 in |A| = B. (5) Accepting a solution that makes a denominator zero. (6) Substituting into a later equation instead of the original.

Checks. Substitute every answer into the original equation. Compare the number of solutions with the degree of the polynomial you ended with. If you lost or gained roots, identify which step was non-reversible.

How to practise. Write the domain first in every problem. For each step, label it 'reversible' or 'check needed'. In Unlimited practice, rotate the radical, rational and absolute value equation families.

Answer0

Problem x22. The roots of x² − 7x + 10 = 0 are r and s. Find r² + s².

HintUse r + s and rs.
Answer29
Method: Vieta

r + s = 7 and rs = 10, so r² + s² = (r + s)² − 2rs = 49 − 20 = 29.

Method: Recurrence

Let pₙ = rⁿ + sⁿ. Then p₀ = 2, p₁ = 7 and p₂ = 7 · p₁ − 10 · p₀ = 49 − 20 = 29.
