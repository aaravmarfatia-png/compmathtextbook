1. Divisors and Euler's totient

The number of positive divisors of n = p₁^{a₁}⋯p_k^{a_k} is (a₁ + 1)⋯(a_k + 1) and their sum is Π (p^{a+1} − 1)/(p − 1). For 360 = 2³ · 3² · 5 there are 24 divisors; σ(12) = 28 and σ(28) = 56 = 2 · 28, so 28 is perfect. Euler's totient φ(n) counts integers in 1, …, n coprime to n: φ(p) = p − 1, φ(pᵏ) = pᵏ − pᵏ⁻¹ and φ is multiplicative on coprime arguments. So φ(36) = φ(4)φ(9) = 2 · 6 = 12, φ(100) = 40, φ(97) = 96, φ(49) = 42.

Euler's theorem. If gcd(a, n) = 1 then a^{φ(n)} ≡ 1 (mod n); for prime p this is Fermat's little theorem a^{p−1} ≡ 1. Examples: 3¹⁰⁰ ≡ 3^{100 mod 6} = 3⁴ = 81 ≡ 4 (mod 7); 7⁴⁰ ≡ 1 (mod 100); 2¹⁰ ≡ 1 (mod 11). Wilson: (p − 1)! ≡ −1 (mod p): 6! = 720 ≡ 6 (mod 7).

Try it

Find φ(72) and the number of divisors of 72.

Answer. 72 = 2³ · 3²: φ = 72 · (1/2) · (2/3) = 24; divisors 4 · 3 = 12.

2. Congruences and the Chinese Remainder Theorem

A linear congruence ax ≡ b (mod n) has a solution iff gcd(a, n) divides b. When gcd(a, n) = 1 multiply by the inverse of a: the inverse of 7 modulo 26 is 15 since 7 · 15 = 105 = 4 · 26 + 1; and 7x ≡ 3 (mod 11) gives x ≡ 3 · 8 = 24 ≡ 2.

CRT. If moduli are pairwise coprime, the system x ≡ 2 (mod 3), x ≡ 3 (mod 5), x ≡ 2 (mod 7) has a unique solution modulo 105, namely x ≡ 23. Solve by combining one pair at a time: x = 2 + 3k ≡ 3 (mod 5) gives 3k ≡ 1, k ≡ 2, x ≡ 8 (mod 15); then x = 8 + 15m ≡ 2 (mod 7) gives m ≡ 1, x ≡ 23.

gcd facts. gcd(2ᵃ − 1, 2ᵇ − 1) = 2^{gcd(a,b)} − 1 (check: gcd(2¹² − 1, 2¹⁸ − 1) = 2⁶ − 1 = 63). gcd × lcm = product: gcd(48, 180) = 12 and lcm = 720.

Try it

Solve x ≡ 1 (mod 4), x ≡ 2 (mod 5).

Answer. x = 1 + 4k ≡ 2 (mod 5): 4k ≡ 1, k ≡ 4, x = 17 (mod 20).

3. A longer problem

Problem. Find the last two digits of 7²⁰²³ using Euler, and count the solutions of x² ≡ 1 (mod 15).

Solution. φ(100) = 40 and 2023 ≡ 23 (mod 40), so 7²⁰²³ ≡ 7²³ (mod 100); using the cycle 07, 49, 43, 01 of period 4 and 23 ≡ 3 (mod 4), the answer is 43 (as in Unit 31). For x² ≡ 1 (mod 15): x² ≡ 1 mod 3 and mod 5 gives x ≡ ±1 mod 3 and ±1 mod 5, so there are 4 solutions mod 15, namely 1, 4, 11, 14 (verified by listing).

Reflection. CRT turns a composite modulus into prime ones; solve each and combine.

4. Mistakes, checks and how to practise

Common mistakes. (1) Using Euler's theorem when gcd(a, n) ≠ 1. (2) Reducing the exponent mod n instead of mod φ(n). (3) Dividing by a non-invertible element. (4) Forgetting that CRT needs coprime moduli.

Checks. Substitute the solution into every congruence.

How to practise. Memorise φ for small numbers. In Unlimited practice, rotate the totient and congruence families.

Problem x23. What is the remainder when 8^60 is divided by 15?

HintFind the pattern of remainders of successive powers.
Answer1
Method: Cycle of remainders

The remainders of 8, 8², 8³, … are 8, 4, 2, 1, and then they repeat from position 1 with period 4. Exponent 60 lands on 1.
