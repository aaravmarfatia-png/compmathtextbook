Reading

1. Ceva and Menelaus revisited

Unit 27 introduced Ceva's theorem (concurrent cevians satisfy (BD/DC)(CE/EA)(AF/FB) = 1) and Menelaus' theorem (collinear points satisfy the same product equal to −1 with signed ratios). Here we use them to solve ratio problems. Problem. D divides BC with BD : DC = 2 : 3 and E divides CA with CE : EA = 3 : 4. For the cevians AD, BE, CF to be concurrent, AF : FB must equal 1/((2/3)(3/4)) = 2 : 1, i.e. F is two thirds of the way from A to B.

Using Menelaus for a ratio. A line meets sides BC, CA, AB at X, Y, Z. If CY : YA = 1 : 2 and AZ : ZB = 3 : 1 then, with unsigned ratios, BX : XC = 1/((1/2)(3)) = 2 : 3, and X lies outside the segment BC (an even number of the three points are inside the triangle's sides, so exactly one or three points are on extensions; here Y and Z are interior, so X is exterior).

Try it

In triangle ABC, D on BC with BD : DC = 3 : 2, F on AB with AF : FB = 1 : 3. If AD, CF and a third cevian BE are concurrent, find CE : EA.

Answer. (3/2)(CE/EA)(1/3) = 1, so CE/EA = 2.

2. Mass points in problems

Assign masses to vertices so that each cevian foot balances. If AD, BE meet at P with BD : DC = 2 : 3 and CE : EA = 1 : 2, then masses are B = 3, C = 2, A = 1, and the mass of P is 6. Hence AP : PD = 5 : 1 and BP : PE = (mass E) : (mass B) = 3 : 3 = 1 : 1 (E has mass A + C = 3). A coordinate check with A = (0, 0), B = (10, 0), C = (0, 10) confirms AP/AD = 5/6 and BP/BE = 1/2.

Area ratios. The area of each of the triangles PBC, PCA, PAB is proportional to the mass at the opposite vertex: with masses A = 1, B = 3, C = 2, [PBC] : [PCA] : [PAB] = 1 : 3 : 2.

Try it

Cevians AD and BE of triangle ABC meet at P with AP : PD = 3 : 1 and BP : PE = 2 : 1. What is BD : DC?

Answer. Give A mass 1, so D has mass 3 (AP : PD = 3 : 1). BP : PE = 2 : 1 means E has twice the mass of B, so with B = k we get E = 2k = A + C = 1 + C, i.e. C = 2k − 1. Since D = B + C = 3: 3k − 1 = 3, k = 4/3, B = 4/3 and C = 5/3. Then BD : DC = C : B = 5 : 4.

3. A longer problem

Problem. In triangle ABC, D is the midpoint of BC, E divides CA with CE : EA = 1 : 3, and AD meets BE at P. Find AP : PD and the area of triangle PBC as a fraction of ABC.

Solution. Masses: B = C = 1 (D is the midpoint), D = 2. E: CE : EA = 1 : 3 means mass A : mass C = 1 : 3, so A = 1/3 if C = 1; scale by 3: B = C = 3, D = 6, A = 1, E = 4. P has mass 7 and AP : PD = mass D : mass A = 6 : 1. The area of PBC is the fraction of the triangle whose height from P is proportional to PD/AD = 1/7 of the height from A: [PBC] = (1/7)[ABC].

Reflection. The height argument (distance from P to BC is PD/AD times the distance from A) converts a ratio of lengths on a cevian into an area ratio.

4. Mistakes, checks and how to practise

Common mistakes. (1) Assigning masses the wrong way round (the shorter segment gets the larger mass). (2) Adding masses incorrectly at a foot. (3) Using Ceva with directed ratios inconsistently.

Checks. Verify with coordinates on a right triangle.

How to practise. Keep a table of masses. In Unlimited practice, rotate the Ceva, Menelaus and mass-point families.

More worked examples: Worked examples

Ceva. Cevians AD, BE, CF are concurrent exactly when (BD/DC)(CE/EA)(AF/FB) = 1. If BD/DC = 2 and CE/EA = 1/3 then concurrency needs AF/FB = 3/2, since 2 · (1/3) · (3/2) = 1. The medians (all ratios 1) and the incircle cevians are examples. Mass points. For BD/DC = 2 put mass 1 at B and mass 2 at C; the cevians' ratios then follow from masses adding at the junction.

Try it

Cevians in a triangle satisfy BD/DC = 3/2 and CE/EA = 2/5. For concurrency, what is AF/FB?

Answer. (3/2)(2/5) = 3/5, so AF/FB = 5/3.

Try it

In triangle ABC, AB = 6 and AC = 9. In what ratio does the angle bisector from A divide BC?

Answer. BD : DC = 6 : 9 = 2 : 3.

More worked examples: A second longer problem

Problem. In triangle ABC, D is on BC with BD : DC = 2 : 3, and E is on CA with CE : EA = 1 : 4. The cevians AD and BE meet at P. Find AP : PD. Solution. Masses: B = 3, C = 2 (so D = 5). For E, CE : EA = 1 : 4 gives C : A = 4 : 1, so scale: C = 4, A = 1 and then B = 6, D = 10. P is on AD with A = 1 and D = 10, so AP : PD = 10 : 1.

Check with coordinates. Take A = (0, 0), B = (5, 0) and C = (0, 5): D = (3, 2), E = (0, 4) (CE : EA = 1 : 4). Line AD: y = 2x/3; line BE: x/5 + y/4 = 1. Solving: x/5 + x/6 = 1, x = 30/11, y = 20/11, so AP/AD = (30/11)/3 = 10/11 and AP : PD = 10 : 1 ✓.

Problem p1. In triangle ABC, D is on BC with BD:DC = 2:3 and E is on CA with CE:EA = 3:4. If AD, BE, CF are concurrent with F on AB, find AF/FB.

HintCeva: the three ratios multiply to 1.
Answer2
Method: Ceva

(2/3)(3/4)(AF/FB) = 1, so AF/FB = 2.

Method: Mass points

BD:DC = 2:3 means mass B : mass C = 3:2. CE:EA = 3:4 means mass C : mass A = 4:3. Scale the first to B = 6, C = 4 and keep C = 4, A = 3. Then AF/FB = mass B / mass A = 6/3 = 2.

Problem p4. In triangle ABC, D is on BC with BD:DC = 1:2 and E is the midpoint of AC. AD and BE meet at P. Find AP/PD.

HintMass points, or Menelaus.
Answer3
Method: Mass points

B = 2, C = 1 balance D (weight 3). E is the midpoint so A = C = 1. On AD the weights are A = 1 and D = 3, so AP:PD = 3:1, giving 3.

Method: Coordinates

Put B = (0,0), C = (3,0), A = (0,3), so D = (1,0), E = (3/2, 3/2). BE is y = x and AD is y = 3 − 3x, meeting at x = 3/4. P is 3/4 of the way from A to D, so AP/PD = (3/4)/(1/4) = 3.

Source: Coxeter & Greitzer, Geometry Revisited, ch. 3

Problem p5. Triangle ABC has AB = 13, BC = 14, CA = 15. The incircle touches BC at D. Find BD.

HintTangent lengths from one vertex are equal: BD = s − CA.
Answer6
Method: Tangent lengths

s = 21 and BD = s − CA = 21 − 15 = 6.

Method: Equations

Let the tangent lengths from A, B, C be x, y, z. Then x + y = 13, y + z = 14, x + z = 15. Adding gives x + y + z = 21, so y = 21 − 15 = 6.

Problem p8. E is on AC with AE:EC = 2:1 and F is on AB with AF:FB = 1:3. Line EF meets line BC at D. Find BD/DC.

HintMenelaus.
Answer6

Problem p14. In triangle ABC, D is on BC with BD:DC = 2:1 and E is the midpoint of AD. BE meets AC at F. Find AF/FC as a fraction.

HintMass points.
Answer2/3
Method: Mass points

B = 1 and C = 2 balance D (weight 3). E is the midpoint of AD so A = D = 3. On AC, AF/FC = mass C / mass A = 2/3.

Method: Coordinates

Put B = (0, 0), C = (3, 0), A = (0, 3). D = (2, 0), E = (1, 3/2), BE is y = (3/2)x, and AC is x + y = 3, meeting at x = 6/5. So AF/FC = (6/5)/(3 − 6/5) = (6/5)/(9/5) = 2/3.

Source: Coxeter & Greitzer, Geometry Revisited, ch. 3

Problem x19. In triangle ABC, BC = 14, CA = 9 and AB = 11. D lies on BC with BD = 6. Find AD².

HintStewart's theorem.
Answer391/7
Method: Stewart

AD² = (CA² · BD + AB² · DC)/BC − BD · DC = (81 · 6 + 121 · 8)/14 − 48 = 391/7.

Method: Law of cosines

cos B = 59/77. Then AD² = AB² + BD² − 2 · AB · BD · cos B = 121 + 36 − 708/7 = 391/7.

Source: Coxeter & Greitzer, Geometry Revisited, ch. 3

Problem x20. A triangle has sides 9, 10 and 17. Find the square of the median to the side of length 9.

Hintm² = (2b² + 2c² − a²)/4.
Answer697/4
Method: Median formula

(2 · 100 + 2 · 289 − 81)/4 = 697/4.

Method: Parallelogram law

Doubling the median completes a parallelogram with diagonals 9 and 2m; the law gives 81 + 4m² = 2(100 + 289), so m² = 697/4.
