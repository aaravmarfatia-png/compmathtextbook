Reading

1. Writing numbers in other bases

In base b, the digits dₖ…d₁d₀ stand for dₖbᵏ + … + d₁b + d₀. Binary uses b = 2 with digits 0 and 1; 1011₂ = 8 + 2 + 1 = 11. Hexadecimal uses b = 16 with digits 0–9 and A–F; FF₁₆ = 15 × 16 + 15 = 255. Base 5: 123₅ = 25 + 10 + 3 = 38.

Converting to base b. Divide repeatedly by b and read the remainders from the last to the first. For 100 in binary: 100 = 2 × 50 + 0, 50 = 2 × 25 + 0, 25 = 2 × 12 + 1, 12 = 2 × 6 + 0, 6 = 2 × 3 + 0, 3 = 2 × 1 + 1, 1 = 2 × 0 + 1. Reading upward: 1100100₂ = 64 + 32 + 4 = 100 ✓.

Arithmetic. Add as usual, carrying when you reach b. In binary 1011 + 110 = 10001 (11 + 6 = 17 = 16 + 1). Multiplication: 1011₂ × 11₂ = 11 × 3 = 33 = 100001₂ ✓.

2. Digits and divisibility in base b

A number is congruent to its digit sum mod (b − 1), as in base 10 with 9. In base 8, a number is divisible by 7 iff its digit sum is. The last digit in base b is n mod b; the last two digits give n mod b². To count digits: n has ⌊log_b n⌋ + 1 digits in base b, so 2¹⁰⁰ has 101 binary digits and 31 decimal digits.

Worked example 1. The number 2⁶⁴ − 1 in binary is sixty-four 1s; in hex it is sixteen Fs.

Worked example 2. In which bases is 36 written with two digits? Need b ≤ 36 < b²: b = 7, …, 35.

Worked example 3. A number is 121 in base b and equals 49 in base 10: b² + 2b + 1 = 49, (b + 1)² = 49, b = 6.

3. Tricks with binary

Weights. With weights 1, 2, 4, 8, 16, 32 you can balance any total from 1 to 63: each number has a binary form. Balanced ternary with weights 1, 3, 9, 27 on both pans of a balance makes every integer from 1 to 40.

Nim and binary. The nim-sum in Unit 58 is addition without carrying in binary.

Counting 1s. The number of 1s in binary of n is its binary weight. The number of odd entries in row n of Pascal's triangle is 2 raised to it (Unit 76).

Worked example. What is the sum of the binary digits of 1 through 7? 1, 1, 2, 1, 2, 2, 3 add to 12 = 3 × 4 (each of the 3 bit positions is 1 in 4 of the 7 numbers).

4. Mistakes, checks and how to practise

Common mistakes. Reading remainders in the wrong order. Using digits ≥ b. Forgetting a carry. Mixing up the base of the answer with the base of the question.

Checks. Convert back to decimal.

Practice. Always write the base as a subscript.

Worked examples with Try-its: Converting between bases

A number written dₖ…d₁d₀ in base b equals Σdᵢbⁱ. So 101101₂ = 32 + 8 + 4 + 1 = 45 and 213₄ = 2 · 16 + 1 · 4 + 3 = 39. To convert down, divide repeatedly by b and read the remainders backwards: 2024 = 11111101000₂ (1024 + 512 + 256 + 128 + 64 + 32 + 8). 100 in base 5 is 400₅ since 4 · 25 = 100.

Try it

Write 77 in base 3.

Answer. 77 = 2 · 27 + 2 · 9 + 1 · 3 + 2, so 2212₃.

Worked examples with Try-its: Digits and divisibility

Since b ≡ 1 mod (b − 1), a number is congruent to its digit sum mod 9 in base 10 (and mod 3). In base b the digit sum tells you the remainder mod (b − 1); the alternating digit sum gives the remainder mod (b + 1). The number of digits of n in base b is ⌊log_b n⌋ + 1, so there are 7³ − 7² = 294 three-digit numbers in base 7.

Trailing zeros. n! ends in as many zeros in base b as the smallest ratio (exponent of p in n!)/(exponent of p in b) over the primes of b. In base 10, 100! has ⌊100/5⌋ + ⌊100/25⌋ = 24 zeros. 10! = 2⁸ · 3⁴ · 5² · 7, so in base 12 = 2² · 3 it ends in min(8/2, 4) = 4 zeros.

Try it

What is the remainder when 123456789 is divided by 9?

Answer. Digit sum 45, so remainder 0.

Worked examples with Try-its: A longer problem

Problem. The number 1001₂ · 11₂ is computed in base 2. What is the result in base 10? Solution. 1001₂ = 9 and 11₂ = 3, product 27 = 11011₂.

Reflection. Convert to base 10, compute, and convert back unless the problem needs base-b arithmetic directly.

1101₂ = 8 + 4 + 1 = 13; 212₃ = 18 + 3 + 2 = 23; and 255 = FF in base 16. In base 2, 101₂ · 11₂ = 5 · 3 = 15 = 1111₂. The digit sum of 2¹⁰ = 1024 is 7, and 1024 ≡ 7 (mod 9), consistent with the digit-sum rule.

More worked examples: A second longer problem

Problem. Find all bases b for which 14ᵦ is a perfect square. Solution. 14ᵦ = b + 4 with b ≥ 5. Squares of the form b + 4: b = 5 (9 = 3²), b = 12 (16 = 4²), b = 21 (25 = 5²), …, namely b = k² − 4 for k ≥ 3.

Check. In base 5, 14₅ = 9 = 3² ✓.

Problem p3. How many three-digit positive integers have digit sum 7?

HintStars and bars with first digit at least 1.
Answer28
Method: Stars and bars

Let the first digit be a + 1: a + b + c = 6 with nonnegative digits, so C(8,2) = 28.

Method: List by first digit

First digit 1 leaves digit sum 6 for two digits (7 ways), then 6 ways, 5, 4, 3, 2, 1 for first digits 2 to 7: 7 + 6 + 5 + 4 + 3 + 2 + 1 = 28.

Problem p9. How many positive integers up to 1000 have digit sum 9?

HintTreat 000 to 999 as three digits.
Answer55
Method: Stars and bars

Digit triples with sum 9: C(11,2) = 55; 1000 has digit sum 1, so the count is 55.

By leading digit d = 0, 1, …, 9, the other two digits sum to 9 − d, which has 10 − d ways: 10 + 9 + … + 1 = 55.

Problem x20. What is the last digit of 13^45?

HintFind the pattern of remainders of successive powers.
Answer3
Method: Cycle of remainders

The remainders of 13, 13², 13³, … are 3, 9, 7, 1, and then they repeat from position 1 with period 4. Exponent 45 lands on 3.

Method: Repeated squaring

Write 45 = 101101 in binary. The squares 13^(2^i) mod 10 are 3, 9, 1, 1, 1, 1; multiplying the ones for the 1-bits gives 3.
