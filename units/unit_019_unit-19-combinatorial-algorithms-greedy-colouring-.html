1. What an algorithm argument looks like

Many olympiad combinatorics problems ask you to prove that something can be done: colour a map, cover a set of points, reach a target configuration. The standard method is to describe a procedure — an algorithm — and then prove that the procedure always works. The proof has three parts: say what the procedure does at each step; show that every step is possible; and show that after finitely many steps the goal has been reached. The third part usually needs a quantity that changes in a controlled way: a number that increases, a set that shrinks, or a count that cannot go on forever.

Example (tournament). In a knockout tournament with 8 players, every game eliminates exactly one player and the tournament ends when one player remains, so exactly 8 − 1 = 7 games are played whatever the pairings. The argument counts eliminations, not games per round. In the same spirit, a chocolate bar of 4 × 6 squares needs exactly 4 × 6 − 1 = 23 breaks to separate into single squares, since each break increases the number of pieces by exactly one, from 1 to 24.

Habit. Before looking for a clever construction, ask what quantity your procedure changes by a fixed amount. A quantity that changes in a predictable way is the engine of the proof.

Try it

A knockout tournament starts with 20 players (some get byes). How many games are played in all?

Answer. Each game eliminates one player and one player remains: 19 games.

2. Greedy colouring

A graph is a set of points (vertices) joined by some segments (edges). A colouring gives each vertex a colour so that the endpoints of every edge have different colours. A greedy method takes the vertices in some order and gives each the first colour not used by its already-coloured neighbours. If every vertex has at most d neighbours, then when we reach a vertex at most d colours are blocked, so one of d + 1 colours is free. Therefore every graph in which each vertex has at most d neighbours can be coloured with d + 1 colours.

Sharpness. This bound cannot be improved in general. The complete graph on 4 vertices (every pair joined) has maximum degree 3 and needs 4 colours, and the 5-cycle has degree 2 and needs 3 colours; a computer search confirms that 2 colours fail for the 5-cycle but 3 succeed. Even cycles, however, need only 2 colours: alternate them around.

Applications. Scheduling: if each exam conflicts with at most 4 others, the exams can be fitted into 5 time slots. Map-making: if each country borders at most 5 others, 6 colours always suffice by the greedy argument (the famous four-colour theorem is much deeper).

The technique to remember. Order the vertices cleverly. If you process a vertex of smallest degree last (repeatedly removing a vertex of minimum degree), you can often reduce the colour count below d + 1.

Try it

A school has 10 clubs; each club shares members with at most 3 others. Why do 4 meeting slots always suffice?

Answer. Colour each club with a slot: each club has at most 3 conflicting clubs, so greedy colouring never needs more than 3 + 1 = 4 slots.

3. Covering and tiling arguments

To cover a set means to find sets (intervals, dominoes, circles) that together contain it. Two types of argument occur: a construction showing a covering exists, and a lower bound showing you cannot do with fewer pieces.

Greedy covering on a line. To cover points on a line with unit intervals, start at the leftmost uncovered point and place an interval beginning exactly there; repeat. For the points 0.1, 0.5, 0.9, 1.3, 2.8, 3.0, 3.2, 5.0 the procedure places [0.1, 1.1] (covering 0.1, 0.5, 0.9), then [1.3, 2.3], then [2.8, 3.8] (covering 2.8, 3.0, 3.2), then [5.0, 6.0]: 4 intervals, and running the procedure by computer agrees. The greedy method is optimal here because any interval covering the leftmost point cannot reach further right than one that starts exactly on it.

The chessboard colouring. Remove two opposite corners of an 8 × 8 board. Can the remaining 62 squares be tiled by 31 dominoes? Colour the board like a chessboard. Opposite corners have the same colour, so after removal there are 30 squares of one colour and 32 of the other (a computer count agrees). Each domino covers one square of each colour, so tiling is impossible. This colouring argument is the prototype of an invariant proof.

Counting tilings. The number of ways to tile a 2 × n strip with dominoes is 1, 2, 3, 5, 8, 13, 21 for n = 1, …, 7: the Fibonacci recurrence appears again, because the last column is covered either by one vertical domino (leaving a 2 × (n − 1) strip) or by two horizontal ones (leaving 2 × (n − 2)).

Try it

Can a 5 × 5 board with one corner removed be tiled by dominoes?

Answer. Yes. It has 24 squares, and a chessboard colouring gives 12 of each colour (the corners belong to the majority colour), so colouring does not forbid a tiling, and a computer search finds one. This shows that a colouring argument proves impossibility only when the counts differ.

4. Invariants and parity

An invariant is a quantity that never changes during a process. If the starting configuration and the target have different values of the invariant, the target cannot be reached. A parity argument uses 'odd or even' as the invariant.

Example (coins). Seven coins lie heads up. A move flips exactly two coins. Can all seven be turned tails? Each move changes the number of tails by +2, 0 or −2, so the number of tails stays even. But we need 7 tails, which is odd. Impossible. If we are allowed to flip one coin at a time, the parity argument disappears and the target is easily reached.

Example (swaps and inversions). An inversion in a list is a pair out of order. The list 3, 1, 4, 2, 5 has 3 inversions: (3,1), (3,2), (4,2). Swapping adjacent entries changes the number of inversions by exactly 1, and sorting by adjacent swaps removes one inversion per swap when the swap is of an out-of-order neighbouring pair; so bubble sort uses exactly 3 swaps here (verified by running the algorithm). Thus the minimum number of adjacent swaps to sort a list equals its number of inversions.

Choosing the invariant. Typical choices: parity, a sum modulo some number, a colouring count, a product, or a sign. Ask: what do all allowed moves leave unchanged?

Try it

The numbers 1, 2, …, 10 are written on a board. A move erases two numbers and writes their sum. After 9 moves one number remains. What is it?

Answer. The total is unchanged by every move (invariant) and equals 1 + … + 10 = 55, so the final number is 55.

5. Building a process that must end

To prove that a process terminates, find a monovariant: a quantity that moves in only one direction and takes values in a set that cannot be traversed forever (e.g. non-negative integers going down). Example. A line of people each faces left or right. Whenever a person who faces right stands directly left of one facing left, they swap places. Does it end? The number of inversions (RL pairs) strictly decreases with each swap, and it is a non-negative integer, so the process must stop.

Weighing puzzles. A balance scale compares groups, giving three outcomes. With 9 coins, one heavier, two weighings suffice: split into groups of 3, weigh two groups, find the heavy group by the result, then repeat with the 3 coins of that group. In general, k weighings can handle 3ᵏ coins, because each weighing has at most 3 outcomes, so an argument counting outcomes gives the lower bound.

Ramsey-type example. Among any 6 people, there are 3 mutual friends or 3 mutual strangers. For 5 people it can fail (a 5-cycle of friendships with the complementary 5-cycle of strangers has no such triple, and a computer check of all 2¹⁵ colourings of the 6-person case finds none that avoid the triple). The proof for 6 people: take one person A, who has at least 3 friends or at least 3 strangers among the other 5; in the first case, if two of those 3 friends know each other, we have a friendly triangle with A; otherwise the three are mutual strangers.

Try it

Cards numbered 1 to 5 lie in the order 2, 1, 4, 3, 5. A move swaps two neighbouring cards. What is the smallest number of moves needed to sort them?

Answer. The list has 2 inversions, (2,1) and (4,3), and each move can remove at most one, so 2 moves are needed and suffice.

6. A longer problem

Problem. A school has 12 students. Any student is friends with at most 4 others. Show that the students can be divided into 5 groups so that no two friends are in the same group.

Solution. Build a graph with the students as vertices and friendships as edges: every vertex has degree at most 4. Colour the students one by one. When we come to a student, at most 4 friends are already coloured, so at most 4 of the 5 colours are blocked; at least one colour is free. Continue until every student is coloured. Students with the same colour form a group and no two of them are friends.

Reflection. This is the whole greedy colouring proof in miniature. Notice that we never need to know how the friendships are arranged: the bound depends only on the maximum degree. Notice also what the argument does not claim: 5 groups are enough, but 4 might also work, and finding the minimum number can be much harder.

7. Mistakes, checks and how to practise

Common mistakes. (1) Describing an algorithm but not proving that it always works. (2) Proving it works for the examples drawn, not for every possible case. (3) Using an invariant that does change. (4) Forgetting to show termination. (5) Assuming that a greedy choice is optimal without proof.

Checks. Run your procedure on a small example by hand. Test that your invariant has the same value before and after a typical move and after an unusual move (the edge cases are where invariants break). For a colouring argument, check that you used the right number of colours: degree plus one.

How to practise. For each problem, write one sentence of the form 'I will show that the procedure ... because the quantity ... always ...'. Then see whether the quantity really behaves as claimed.

Problem a1. A graph has no vertex with more than 4 neighbours. The greedy colouring argument guarantees how many colours suffice?

HintΔ + 1.
Answer5
Method: The argument

A vertex has at most Δ = 4 neighbours, so at most 4 colours are blocked when we reach it; one of colours 1 to 5 is free. So 5 colours suffice.

Method: Why not fewer in general

A complete graph on 5 vertices (everyone joined to everyone) has Δ = 4 and needs all 5 colours, so Δ + 1 cannot be improved for all graphs.

Source: Sriram, Olympiad Combinatorics, Chapter 1, Example 1

Problem a2. Colour the vertices of a path of 6 dots (each joined to the next) greedily, in order along the path. How many colours are used?

HintSmallest free colour each time.
Answer2
Method: Run it

Dot 1: colour 1. Dot 2 touches colour 1: gets 2. Dot 3 touches 2: gets 1. Then 2, 1, 2. Colours used: 1 and 2.

Method: Check the bound

Every dot has at most 2 neighbours, so the guarantee is 3 colours; this order does better (2).

Source: Sriram, Olympiad Combinatorics, Chapter 1, Example 1

Problem a3. Colour a 5-dot cycle (dots 1–5, with 5 joined back to 1) greedily in the order 1, 2, 3, 4, 5. How many colours are used?

HintThe fifth dot touches dots 4 and 1.
Answer3
Method: Run it

1 → colour 1, 2 → colour 2, 3 → colour 1, 4 → colour 2. Dot 5 touches dot 4 (colour 2) and dot 1 (colour 1), so it needs colour 3.

Method: Why 2 is impossible

An odd cycle cannot be 2-coloured: colours would have to alternate around a cycle of odd length, giving a clash.

Source: Sriram, Olympiad Combinatorics, Chapter 1, Example 1

Problem a4. In a 2 × n array of positive reals, each column sums to 1. The book shows we can choose one number per column so each row's chosen sum is at most (n + 1)/4. What is this bound for n = 8? Give a decimal or fraction.

Hint(8 + 1)/4.
Answer9/4
Method: Substitute

(8 + 1)/4 = 9/4 = 2.25.

Method: Compare with a trivial bound

A careless choice could put a number close to 1 from the same row in every column, making that row's sum nearly 8. The theorem says a smart choice always keeps both row sums at or below 2.25.

Source: Sriram, Olympiad Combinatorics, Chapter 1, Example 2

Problem a5. Top row: 0.4, 0.7, 0.9, 0.2, 0.6, 0.4, 0.3, 0.1. Bottom row: 0.6, 0.3, 0.1, 0.8, 0.4, 0.6, 0.7, 0.9. In each column pick the smaller number (the 'trivial' greedy rule). What is the larger of the two row sums? Give a decimal.

HintTop picks come from columns 1, 4, 6, 7, 8.
Answer1.4
Method: Pick and add

Smaller numbers: column 1 top 0.4, col 2 bottom 0.3, col 3 bottom 0.1, col 4 top 0.2, col 5 bottom 0.4, col 6 top 0.4, col 7 top 0.3, col 8 top 0.1. Top-row sum: 0.4 + 0.2 + 0.4 + 0.3 + 0.1 = 1.4. Problem a9. A 2 × 2 board has numbers [[3, 4], [5, 2]] and the chessboard colouring has the top-left square black. Compute (sum of black squares) − (sum of white squares).

HintBlack: top-left and bottom-right.
Answer-4

Black squares: 3 and 2 (sum 5). White squares: 4 and 5 (sum 9). 5 − 9 = −4. Since it is not 0, reaching all zeros is impossible.

A move adds the same k to one black and one white square, leaving the difference unchanged, so it stays −4 forever.

Answer15
