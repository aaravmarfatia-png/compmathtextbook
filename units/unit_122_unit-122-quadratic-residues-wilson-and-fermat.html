Reading

1. Fermat's little theorem

If p is prime and p does not divide a, then a^{p−1} ≡ 1 (mod p). Consequently a^p ≡ a (mod p) for every integer a. It lets you reduce huge exponents: reduce the exponent mod p − 1.

Worked example 1. 3¹⁰⁰ mod 7: 3⁶ ≡ 1, 100 = 6 × 16 + 4, so 3¹⁰⁰ ≡ 3⁴ = 81 ≡ 4 (mod 7). Example 2. 2¹⁰⁰ mod 13: 2¹² ≡ 1 and 100 = 12 × 8 + 4, so ≡ 16 ≡ 3. Example 3. 7²²² mod 5: 7 ≡ 2, 2⁴ ≡ 1, 222 = 4 × 55 + 2, so ≡ 4.

2. Wilson's theorem

For a prime p, (p − 1)! ≡ −1 (mod p). Conversely, if (n − 1)! ≡ −1 (mod n) then n is prime. The reason: each residue other than 1 and p − 1 pairs with its inverse, and the product of 1 and p − 1 is p − 1 ≡ −1.

Worked example. p = 7: 6! = 720 = 7 × 103 − 1, so 6! ≡ −1 ✓. p = 5: 4! = 24 ≡ −1 mod 5 ✓.

Use. Evaluate (p − 2)! ≡ 1 (mod p), since (p − 1)! = (p − 1)(p − 2)! ≡ −(p − 2)!.

3. Quadratic residues

A number a is a quadratic residue mod p if x² ≡ a has a solution. For an odd prime p exactly (p − 1)/2 of the non-zero residues are quadratic residues. Euler's criterion: a is a residue iff a^{(p−1)/2} ≡ 1 (mod p); otherwise it is ≡ −1.

Worked example. The squares mod 7 are 1, 4, 2 (from 1², 2², 3²): {1, 2, 4}. Mod 13: {1, 3, 4, 9, 10, 12}, six of them (13 − 1)/2 = 6 ✓. For p = 11: {1, 3, 4, 5, 9}; check Euler for a = 3: 3⁵ = 243 = 22 × 11 + 1 ≡ 1 ✓.

The number −1. −1 is a residue mod p iff p ≡ 1 (mod 4). Mod 13 we have 5² = 25 ≡ −1 ✓, while mod 7 (7 ≡ 3 mod 4) −1 = 6 is not in {1, 2, 4}. This proves that x² + y² is never divisible by a prime p ≡ 3 mod 4 unless p divides both x and y.

4. Mistakes, checks and how to practise

Common mistakes. Applying Fermat when p divides a. Reducing the exponent mod p instead of p − 1. Applying Wilson's theorem to composite numbers.

Checks. Test with small primes (3, 5, 7).

Practice. Make a table of squares mod p for p = 5, 7, 11, 13.

Worked examples with Try-its: Fermat and Wilson

Fermat's little theorem: if p is prime and p does not divide a then aᵖ⁻¹ ≡ 1 (mod p); for instance 2¹⁰ ≡ 1 (mod 11). So 3¹⁰⁰ mod 7: since 3⁶ ≡ 1, 3¹⁰⁰ = 3⁴ · (3⁶)¹⁶ ≡ 81 ≡ 4. Wilson's theorem: (p − 1)! ≡ −1 (mod p), so 10! ≡ −1 (mod 11), that is 10! leaves remainder 10.

Try it

Find the remainder when 5¹⁰⁰ is divided by 13.

Answer. 5¹² ≡ 1, and 100 = 8 · 12 + 4, so 5¹⁰⁰ ≡ 5⁴ = 625 = 48 · 13 + 1. The remainder is 1.

Worked examples with Try-its: Quadratic residues

A number a is a quadratic residue mod p if x² ≡ a has a solution. Mod 7 the residues are 1, 2, 4. By Euler's criterion −1 is a residue exactly when p ≡ 1 (mod 4): mod 13 we have 5² = 25 ≡ −1. Half of the non-zero residues mod an odd prime are quadratic residues.

Try it

Is 3 a quadratic residue mod 7?

Answer. No: the residues are 1, 2, 4.

Worked examples with Try-its: A longer problem

Problem. Show that x² + 1 is never divisible by 7. Solution. We would need x² ≡ −1 ≡ 6 (mod 7), but the squares mod 7 are only 0, 1, 2, 4.

Reflection. Listing squares mod a small prime settles many such questions.

More worked examples: Worked examples

Fermat. 2¹⁰⁰ ≡ 1 (mod 101) since 101 is prime. Orders. 3⁵ = 243 = 22 · 11 + 1, so 3 has order 5 modulo 11. Residues. The quadratic residues modulo 11 are 1, 3, 4, 5, 9. Wilson. 12! ≡ −1 (mod 13), so 12! leaves remainder 12.

Try it

Answer. Yes: 4² = 16 ≡ 5.

More worked examples: A second longer problem

Problem. Show that p divides 2ᵖ − 2 for every prime p. Solution. For odd p, 2ᵖ⁻¹ ≡ 1 (mod p) by Fermat, so 2ᵖ ≡ 2. For p = 2 the number 2² − 2 = 2 is divisible by 2.

Answer12

Problem p5. Find the inverse of 7 modulo 31 (a number from 1 to 30).

HintSolve 7x ≡ 1.
Answer9
Method: Search

7 · 9 = 63 = 2 · 31 + 1, so the inverse is 9.

Method: Euclid

31 = 4 · 7 + 3, 7 = 2 · 3 + 1, so 1 = 7 − 2(31 − 4 · 7) = 9 · 7 − 2 · 31.

Problem p9. Find the smallest positive x with x ≡ 1 (mod 4), x ≡ 2 (mod 5) and x ≡ 3 (mod 7).

HintChinese remainder theorem.
Answer17
Method: Combine

x ≡ 1 mod 4 and x ≡ 2 mod 5 gives x ≡ 17 mod 20. Then 17 + 20t ≡ 3 mod 7 gives 3 + 6t ≡ 3, so t ≡ 0 and x = 17.

Method: Check

17 = 4 · 4 + 1 = 3 · 5 + 2 = 2 · 7 + 3.

Problem x18. What is the remainder when 4^99 is divided by 9?

HintFind the pattern of remainders of successive powers.
Answer1
Method: Cycle of remainders

The remainders of 4, 4², 4³, … are 4, 7, 1, and then they repeat from position 1 with period 3. Exponent 99 lands on 1.

Method: Repeated squaring

Write 99 = 1100011 in binary. The squares 4^(2^i) mod 9 are 4, 7, 4, 7, 4, 7, 4; multiplying the ones for the 1-bits gives 1.

Source: AoPS Volume 2, ch. 23 (Number Theory)

Problem x19. Find the smallest positive x with 13x ≡ 1 (mod 17).

HintTry multiples, or use the Euclidean algorithm.
Answer4
Method: Table

13 · k mod 17 for k = 1, 2, …: 13, 9, 5, 1; the first 1 appears at k = 4.

Method: Equation

We need 13 · x = 1 + 17 · t. With x = 4 we get 52 = 1 + 17 · 3, which checks.
