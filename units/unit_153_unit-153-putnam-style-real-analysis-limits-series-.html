1. Limits, series and recurrences

A limit with a square root is usually handled by multiplying by the conjugate: √(n² + n) − n = n/(√(n² + n) + n) → 1/2. A telescoping series cancels in the partial sums: Σ 1/(n(n+1)) = Σ (1/n − 1/(n+1)) = 1. For a recurrence aₙ₊₁ = g(aₙ), if the sequence converges then the limit L satisfies L = g(L); you must still check that it converges (for example, increasing and bounded). Example: a₁ = 1, aₙ₊₁ = √(2 + aₙ) → 2.

Try it

What is lim (√(n² + 2n) − n)?

Answer. 1.

Try it

Answer. 3/4.

Problem p1. What is the limit as n → ∞ of √(n² + 1n) − n? (fraction if needed)

HintMultiply and divide by the conjugate.
Answer1/2
Method: Conjugate

√(n²+1n) − n = 1n/(√(n²+1n) + n) = 1/(√(1+1/n) + 1) → 1/2.

Method: Binomial expansion

√(n²+1n) = n(1 + 1/n)^(1/2) ≈ n + 1/2, so the expression tends to 1/2.

Source: Technique from Putnam and Beyond ch. 3 (original problem)

Problem p4. What is the sum of 1/(n(n + 2)) over all n ≥ 1? (fraction if needed)

HintPartial fractions: 1/(n(n+k)) = (1/k)(1/n − 1/(n+k)); the sum telescopes.
Answer3/4
Method: Telescoping

The sum equals (1/2)(1 + 1/2 + … + 1/2) = 3/4.

Method: Partial sums

S_N = (1/2)(H_N − H_{N+2} + H_2) → H_2/2 = 3/4.

L² = 6 + L gives L = 3 or −2; the sequence is positive, bounded above by 3 and increasing, so L = 3.

Problem p15. What is ∫ from 0 to 4 of √x/(√x + √(4 − x)) dx?

HintSubstitute x → 4 − x and add.
Answer2
Method: Symmetry

Call it I; the substitution x → 4 − x gives I = ∫ √(4−x)/(√x + √(4−x)) dx; adding, 2I = ∫ 1 dx = 4, so I = 2.

Method: Check

The integrand f(x) satisfies f(x) + f(4 − x) = 1, so the average value is 1/2 and I = 4·(1/2) = 2.

Source: Technique from Putnam and Beyond ch. 3 (original problem)

Problem p24. What is the sum over all n ≥ 1 of n/2ⁿ?

Method: Recurrence
