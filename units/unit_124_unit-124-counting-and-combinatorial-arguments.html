Reading

1. Counting in two ways and basic identities

Counting the same set in two different ways proves identities. Σ C(n, k) = 2ⁿ because both sides count subsets of an n-element set (the right side by yes/no for each element). Pascal: C(n, k) = C(n − 1, k − 1) + C(n − 1, k): choose a committee either including or excluding a particular person.

Hockey stick. Σ_{i=2}^{n} C(i, 2) = C(n + 1, 3). For n = 5: 1 + 3 + 6 + 10 = 20 = C(6, 3) ✓. Vandermonde. Σ C(m, i) C(n, k − i) = C(m + n, k).

Worked example. Show Σ k C(n, k) = n 2^{n−1}. Count pairs (committee, chairperson in it): choose the chair (n ways) then any subset of the others (2^{n−1}). For n = 4: 1·4 + 2·6 + 3·4 + 4·1 = 4 + 12 + 12 + 4 = 32 = 4 × 8 ✓.

2. Stars and bars, inclusion-exclusion

The number of non-negative integer solutions of x₁ + … + x_k = n is C(n + k − 1, k − 1). For x₁ + x₂ + x₃ + x₄ = 10 it is C(13, 3) = 286.

Inclusion-exclusion. |A ∪ B ∪ C| = |A| + |B| + |C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|. Among the numbers 1 to 100, the number divisible by 2, 3 or 5 is 50 + 33 + 20 − 16 − 10 − 6 + 3 = 74.

Derangements. The number D_n of permutations with no fixed point satisfies D_n = (n − 1)(D_{n−1} + D_{n−2}): D₁ = 0, D₂ = 1, D₃ = 2, D₄ = 9, D₅ = 44.

3. Bijections and double counting

A bijection pairs up two sets, proving they have the same size. The number of subsets of {1, …, n} of even size equals the number of odd size (for n ≥ 1): toggle element 1.

Double counting. Count pairs (x, y) in two ways. A classic: in a graph the sum of the degrees is twice the number of edges. In a party of n people, the number of handshakes counted from each person's perspective sums to 2E.

Worked example. A set of 10 points, no three collinear: the number of triangles is C(10, 3) = 120, and each pair of points lies in 8 of them: 45 × 8 = 360 = 120 × 3 ✓ (counting pairs inside triangles in two ways).

4. Mistakes, checks and how to practise

Common mistakes. Counting ordered arrangements when order should not matter. Forgetting to subtract overlaps. Using stars and bars with an upper bound without adjusting.

Checks. Test with a tiny case you can list.

Practice. Try to explain every identity with a committee story.

Worked examples with Try-its: Standard counting models

Circular arrangements: n people around a table, rotations equal, give (n − 1)!; for 5 people that is 24. Repeated letters: MISSISSIPPI has 11!/(4! 4! 2!) = 34650 arrangements. Stars and bars: distributing 10 identical candies among 4 children can be done in C(13, 3) = 286 ways. Handshakes among 10 people: C(10, 2) = 45.

Try it

How many distinct arrangements of the letters in BANANA?

Answer. 6!/(3! 2!) = 60.

Worked examples with Try-its: Choosing a method

Ask: does order matter? Can items repeat? Are the objects identical? Is there a restriction better handled by subtracting the complement? A good habit is to count a small case by hand to validate the formula before using it.

Try it

How many ways are there to choose a president and a vice-president from 8 people?

Answer. 8 · 7 = 56.

Worked examples with Try-its: A longer problem

Problem. How many integer solutions with x, y, z ≥ 0 are there to x + y + z = 10 with each variable at most 6? Solution. Without the cap C(12, 2) = 66; subtract solutions where one variable is at least 7: 3 · C(5, 2) = 30; two variables cannot both be at least 7. Total 36.

Reflection. Inclusion-exclusion handles the upper bounds.

More worked examples: Worked examples

Arrangements. 6!/(3! 2!) = 60 arrangements of the letters AAABBC. Choosing. C(9, 3) = 84 ways to choose 3 of 9. Restrictions. The permutations of 1 to 5 in which no two consecutive numbers (like 2 and 3) are adjacent number 14 (checked by listing all 120). Stars and bars. The number of ways to put 5 identical balls into 3 boxes is C(7, 2) = 21.

Try it

How many ways can 4 people be seated in a row if two particular people must sit together?

Answer. 3! · 2 = 12.

Try it

How many 3-letter words (repeats allowed) can be formed from the letters A, B, C, D?

Answer. 64.

More worked examples: A second longer problem

Problem. How many ways can 5 identical balls go into 3 distinct boxes with at most 3 in any box? Solution. Total C(7, 2) = 21; subtract those with a box holding at least 4: choose the box (3 ways), put 4 balls in it and place the fifth ball in any of the 3 boxes (3 ways), giving 3 · 3 = 9 such cases with no overlap. So 21 − 9 = 12.

Check. Direct count: 3+2+0 and permutations (6), 3+1+1 (3), 2+2+1 (3): total 12 ✓.

HintStars and bars.

Problem p17. How many subsets of a 9-element set have an even number of elements?

HintPair each subset with the one that toggles a fixed element.
Answer256
Method: Pairing

Fix one element e. Toggling e in a subset changes its size by 1, so it matches the even subsets one-to-one with the odd ones. The 512 subsets split evenly: 256.

Method: Binomial sum

(1 + 1)^9 + (1 − 1)^9 = 2 · (sum of the even binomial coefficients), so the sum is 512/2 = 256.

Source: Zeitz ch. 6

Problem p19. How many lattice paths from (0, 0) to (6, 6) with steps right or up never go above the line y = x?

HintCount all paths and subtract the bad ones by reflecting.
Answer132
Method: Reflection

All paths: C(12, 6) = 924. A bad path touches y = x + 1; reflect its start part to get a path ending at (5, 7), and there are C(12, 7) = 792 of these. So 924 − 792 = 132.

Method: Catalan formula

The answer is the Catalan number C(12, 6)/(6 + 1) = 924/7 = 132.

Problem p21. How many subsets of {1, 2, …, 10} contain no two consecutive integers?

HintCondition on whether 10 is chosen.
Answer144
Method: Recurrence

Let a(n) count them. If n is not chosen, a(n − 1) ways; if n is chosen, n − 1 is not, and a(n − 2) ways. With a(0) = 1, a(1) = 2 this is the Fibonacci sequence, giving a(10) = 144.

Method: Count by size

A subset of size k can be chosen in C(10 − k + 1, k) ways. Adding over k gives 1+10+36+56+35+6 = 144.

Source: Zeitz ch. 6

Problem p25. Find the value of 1·C(10, 1) + 2·C(10, 2) + … + 10·C(10, 10).

Hintk·C(n, k) = n·C(n − 1, k − 1).
Answer5120
Method: Identity

k·C(10, k) = 10·C(9, k − 1), so the sum is 10 · 2^9 = 5120.

Method: Committee with chair

Choose a committee of any size and a chair from it: 10 choices of chair, then each of the other 9 people is in or out: 10 · 2^9 = 5120.
