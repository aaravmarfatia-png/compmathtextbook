Reading

1. Exponent rules and fractional powers

aᵐ · aⁿ = aᵐ⁺ⁿ, (aᵐ)ⁿ = aᵐⁿ, aᵐ/aⁿ = aᵐ⁻ⁿ, a⁰ = 1, a⁻ⁿ = 1/aⁿ, and a^(1/n) is the n-th root: 8^(2/3) = (∛8)² = 4, 16^(3/4) = 8, 27^(−1/3) = 1/3. Always take the root first, then the power, to keep numbers small. Compare sizes by writing with a common base or exponent: 3⁶⁴ > 2¹⁰⁰ since log₁₀ 3⁶⁴ ≈ 30.5 and log₁₀ 2¹⁰⁰ ≈ 30.1.

Exponent equations. To solve 4ˣ − 5 · 2ˣ + 4 = 0, put t = 2ˣ: t² − 5t + 4 = 0, so t = 1 or 4, and x = 0 or 2. The substitution works because 4ˣ = (2ˣ)².

Try it

Simplify (2³ · 4²)/8² .

Answer. (8 · 16)/64 = 2.

2. Radicals

√72 = √(36 · 2) = 6√2; √50 + √18 = 5√2 + 3√2 = 8√2. Rationalising removes radicals from a denominator: 1/(√5 − 2) = (√5 + 2)/((√5 − 2)(√5 + 2)) = (√5 + 2)/1 = √5 + 2. The conjugate product is a difference of squares: (3 + √2)(3 − √2) = 7. Squaring: (1 + √3)² = 4 + 2√3.

Nested radicals. √(4 + 2√3) = 1 + √3 since (1 + √3)² = 4 + 2√3. To denest √(a + 2√b), find p and q with p + q = a and pq = b.

Try it

Rationalise 6/(√7 − 1).

Answer. 6(√7 + 1)/6 = √7 + 1.

3. Logarithms

log_b(N) = k means bᵏ = N. So log₂ 8 = 3 and log₁₀ 1000 = 3. Rules: log(MN) = log M + log N, log(M/N) = log M − log N, log(Mᵖ) = p log M, and change of base log_b N = log N/log b. Hence log₁₀ 2 + log₁₀ 5 = log₁₀ 10 = 1, log₃ 81 = 4, and log₂ 3 · log₃ 4 = 2 (the product telescopes: (log 3/log 2)(log 4/log 3) = log 4/log 2).

Log equations. log₂ x + log₂(x − 2) = 3 gives x(x − 2) = 8, x = 4 or −2; the domain requires x > 2, so x = 4 (Unit 24). Number of digits. The number N has ⌊log₁₀ N⌋ + 1 digits.

Try it

Evaluate log₂ 12 + log₂ (2/3).

Answer. log₂ 8 = 3.

4. A longer problem

Problem. Solve 9ˣ − 4 · 3ˣ⁺¹ + 27 = 0, and simplify (√3 + √2)/(√3 − √2).

Solution. Put t = 3ˣ: t² − 12t + 27 = 0, so t = 3 or 9, x = 1 or 2. For the fraction multiply by the conjugate: (√3 + √2)²/(3 − 2) = 5 + 2√6.

Reflection. Recognise the hidden quadratic: 9ˣ = (3ˣ)² and 3ˣ⁺¹ = 3 · 3ˣ.

5. Mistakes, checks and how to practise

Common mistakes. (1) (a + b)ⁿ ≠ aⁿ + bⁿ. (2) √(a + b) ≠ √a + √b. (3) log(a + b) ≠ log a + log b. (4) Forgetting the domain x > 0.

Checks. Test rules with small numbers. Substitute solutions into the original.

How to practise. Convert everything to a common base. In Unlimited practice, rotate the exponent and logarithm families.

More worked examples: Worked examples

Exponents. 8^(2/3) = (∛8)² = 4 and 2¹⁰ = 1024. Radicals. √72 = √(36 · 2) = 6√2, and to rationalise 1/(√3 − 1) multiply top and bottom by √3 + 1: (√3 + 1)/(3 − 1) = (√3 + 1)/2. Logarithms. log₂ 8 = 3, log₃ 81 = 4, log 2 + log 5 = log 10 = 1 and log₄ 8 = (log₂ 8)/(log₂ 4) = 3/2.

A log equation. To solve log₂ x + log₂(x − 2) = 3 combine: log₂(x(x − 2)) = 3, so x² − 2x = 8, giving x = 4 or x = −2. The argument x − 2 must be positive, so only x = 4 is valid. For an exponential equation such as 2ˣ = 5 take logarithms: x = log₂ 5 ≈ 2.32.

Try it

Simplify (27)^(−2/3).

Answer. 1/9.

Try it

Solve log₃(x + 1) = 2.

Answer. x + 1 = 9, so x = 8.

More worked examples: A second longer problem

Problem. Solve 4ˣ − 3 · 2ˣ − 4 = 0. Solution. Put t = 2ˣ > 0: t² − 3t − 4 = 0, so t = 4 or t = −1. Only t = 4 is allowed, giving x = 2. Check: 16 − 12 − 4 = 0.

Reflection. A substitution turns an exponential equation into a quadratic; always discard t ≤ 0, since 2ˣ is positive.

Problem x22. What is the last digit of 8^2030?

HintFind the pattern of remainders of successive powers.
Answer4
Method: Cycle of remainders

The remainders of 8, 8², 8³, … are 8, 4, 2, 6, and then they repeat from position 1 with period 4. Exponent 2030 lands on 4.

Method: Repeated squaring

Write 2030 = 11111101110 in binary. The squares 8^(2^i) mod 10 are 8, 4, 6, 6, 6, 6, 6, 6, 6, 6, 6; multiplying the ones for the 1-bits gives 4.

Source: Rusczyk, Art of Problem Solving Vol. 1, ch. 1

Problem x24. Evaluate 1/(1·2) + 1/(2·3) + … + 1/(49·50).

Hint1/(k(k + 1)) = 1/k − 1/(k + 1).
Answer49/50
Method: Telescoping

Each term is 1/k − 1/(k + 1); everything cancels except 1 − 1/50 = 49/50.

Method: Small cases

Up to n = 1, 2, 3 the sums are 1/2, 2/3, 3/4, so up to n = 49 the sum is 49/50.
