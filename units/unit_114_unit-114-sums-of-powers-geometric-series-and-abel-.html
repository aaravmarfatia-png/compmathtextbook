Reading

1. Sums of powers

The standard formulas: Σk = n(n+1)/2, Σk² = n(n+1)(2n+1)/6, Σk³ = [n(n+1)/2]². For n = 10 these give 55, 385 and 3,025 = 55². They can be proved by induction or by telescoping with (k + 1)^{m+1} − k^{m+1}.

Worked example. Σ_{k=1}^{10} k(k + 1) = Σk² + Σk = 385 + 55 = 440, and 10 × 11 × 12/3 = 440 ✓.

Differences of powers. a^n − b^n = (a − b)(a^{n−1} + a^{n−2} b + … + b^{n−1}); this is also the geometric sum in disguise.

2. Geometric series

For a ratio r ≠ 1: 1 + r + … + r^{n−1} = (rⁿ − 1)/(r − 1). So Σ_{k=0}^{9} 2ᵏ = 1,023. If |r| < 1 the infinite sum is 1/(1 − r): Σ (1/2)^k = 2, and 0.999… = 9/10 + 9/100 + … = 1.

Worked example. A ball dropped from 8 m bounces to ¾ of its previous height each time. Total distance: 8 + 2 × (6 + 4.5 + …) = 8 + 2 × 6/(1 − 3/4) = 8 + 48 = 56 m.

The trick S − rS. For Σ k·2ᵏ, write S = Σ_{k=1}^{n} k 2ᵏ; then 2S − S gives S = (n − 1)2^{n+1} + 2. For n = 4: 1·2 + 2·4 + 3·8 + 4·16 = 98 and 3 × 32 + 2 = 98 ✓.

3. Abel summation

Abel summation is summation by parts. With partial sums A_k = a₁ + … + a_k: Σ_{k=1}^{n} a_k b_k = A_n b_n − Σ_{k=1}^{n−1} A_k (b_{k+1} − b_k). It is to sums what integration by parts is to integrals.

Worked example. Evaluate Σ_{k=1}^{4} k · 2ᵏ. Take a_k = 2ᵏ, so A_k = 2^{k+1} − 2, and b_k = k with b_{k+1} − b_k = 1. Then the sum = A₄ · 4 − Σ_{k=1}^{3} A_k = 30 × 4 − (2 + 6 + 14) = 120 − 22 = 98 ✓.

When it helps. When b_k is monotonic and the partial sums A_k are easy, as for bounding sums of oscillating terms.

4. Mistakes, checks and how to practise

Common mistakes. Off-by-one in the number of terms (r⁰ to r^{n−1} has n terms). Using the infinite-sum formula when |r| ≥ 1. Forgetting the boundary term in Abel summation.

Checks. Test a formula on n = 1, 2, 3.

Practice. Whenever you see k·rᵏ, try S − rS.

Worked examples with Try-its: Sums of powers

Σk = n(n + 1)/2, Σk² = n(n + 1)(2n + 1)/6 and Σk³ = (n(n + 1)/2)²: for n = 5 the cubes sum to 225 = 15². A geometric series has Σ rᵏ = (1 − rⁿ⁺¹)/(1 − r) and, for |r| < 1, an infinite sum 1/(1 − r). Differentiating gives Σ k rᵏ = r/(1 − r)² (equal to 2 for r = 1/2).

Try it

Evaluate 1² + 2² + … + 12².

Answer. 12 · 13 · 25/6 = 650.

Worked examples with Try-its: Abel summation

Summation by parts: Σ aₖbₖ = Aₙbₙ − Σ Aₖ(bₖ₊₁ − bₖ) where Aₖ = a₁ + … + aₖ. It converts a sum of products into one with simpler terms. For example Σ_{k=1}^{4} k · 2ᵏ = 2 + 8 + 24 + 64 = 98, which matches the closed form (n − 1)2ⁿ⁺¹ + 2 = 3 · 32 + 2.

Try it

Evaluate 1 · 2 + 2 · 4 + 3 · 8.

Answer. 2 + 8 + 24 = 34.

Worked examples with Try-its: A longer problem

Problem. Find the sum 1 + 2x + 3x² + 4x³ + … for |x| < 1 and evaluate it at x = 1/3. Solution. The sum is 1/(1 − x)², so at x = 1/3 it equals 1/(2/3)² = 9/4.

Reflection. Differentiating the geometric series is a standard source of such formulas.

More worked examples: Worked examples

Pronic sum. Σ k(k + 1) for k = 1 to n equals n(n + 1)(n + 2)/3: for n = 5 that is 70. Arithmetico-geometric. Σ k · 3ᵏ from 1 to 3 = 3 + 18 + 81 = 102, which matches the closed form ((2n − 1)3ⁿ⁺¹ + 3)/4 = (5 · 81 + 3)/4. Cubes. 1³ + 2³ + 3³ + 4³ = 100 = 10².

Try it

Evaluate 1 · 2 + 2 · 3 + 3 · 4.

Answer. 3 · 4 · 5/3 = 20.

Try it

Evaluate the infinite sum Σ k/2ᵏ.

Answer. 2.

More worked examples: A second longer problem

Problem. Find 1² − 2² + 3² − 4² + … − 100². Solution. Pair terms: (2k − 1)² − (2k)² = −(4k − 1), so the sum is −Σ(4k − 1) for k = 1 to 50 = −(4 · 1275 − 50) = −5050.

Check. It equals −(1 + 2 + … + 100) = −5050.
