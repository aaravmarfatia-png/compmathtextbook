Reading

1. Limits at a point

The limit of f(x) as x approaches a is the value that f(x) gets close to, even if f(a) is undefined. Removable discontinuity. (x² − 1)/(x − 1) is undefined at x = 1, but for x ≠ 1 it equals x + 1, so the limit is 2. Rationalising. (√(x + 4) − 2)/x: multiply by the conjugate to get x/(x(√(x + 4) + 2)) = 1/(√(x + 4) + 2), with limit 1/4 at x = 0. Factoring. (x² − 9)/(x² − 5x + 6) = (x − 3)(x + 3)/((x − 3)(x − 2)) = (x + 3)/(x − 2), with limit 6 at x = 3 (all these limits were confirmed by computer algebra).

Two famous limits. sin x/x → 1 as x → 0 and (1 + 1/x)ˣ → e ≈ 2.718 as x → ∞.

Try it

Find lim as x → 2 of (x² − 4)/(x − 2).

Answer. x + 2 → 4.

2. Limits at infinity and horizontal asymptotes

For rational functions compare the degrees. (3x² + 1)/(x² − 4) → 3 as x → ∞ (ratio of leading coefficients, since the degrees are equal). If the numerator has lower degree the limit is 0; if higher, the function grows without bound: (x³ + 1)/(x² + x) → ∞. A horizontal asymptote y = L means f(x) → L as x → ±∞. For (2x − 1)/(x + 4) the horizontal asymptote is y = 2.

Differences of roots. √(x² + x) − x → 1/2 as x → ∞: multiply and divide by the conjugate to get x/(√(x² + x) + x) → 1/2. A common trap is to claim the difference tends to 0 because both terms are 'about' x.

Try it

Find the limit of (5x³ − x)/(2x³ + 7) as x → ∞.

Answer. 5/2.

3. Vertical and slant asymptotes

A vertical asymptote occurs where the denominator is zero but the numerator is not: (2x + 1)/(x − 3) → +∞ as x → 3 from the right and −∞ from the left. A slant asymptote occurs when the numerator's degree is exactly one more than the denominator's: (x² + 1)/(x − 1) = x + 1 + 2/(x − 1), so the line y = x + 1 is the slant asymptote (long division or partial fractions reveals it).

Infinite series. A geometric series 1 + 1/2 + 1/4 + … has limit 2: the partial sums 2 − 1/2ⁿ approach 2.

Try it

Find all asymptotes of f(x) = (x² − 1)/(x − 2).

Answer. Vertical x = 2. Slant: x² − 1 = (x − 2)(x + 2) + 3, so y = x + 2.

4. A longer problem

Problem. Sketch the graph features of f(x) = (2x² + 3x − 2)/(x² − 1): intercepts, asymptotes, any hole.

Solution. Numerator 2x² + 3x − 2 = (2x − 1)(x + 2), denominator (x − 1)(x + 1): no common factor, so no holes. x-intercepts at x = 1/2 and x = −2; y-intercept f(0) = 2. Vertical asymptotes x = 1 and x = −1. Horizontal asymptote y = 2.

Reflection. Factor first: a common factor would create a hole rather than an asymptote.

5. Mistakes, checks and how to practise

Common mistakes. (1) Substituting before simplifying a 0/0 form. (2) Cancelling terms rather than factors. (3) Confusing holes with asymptotes. (4) Believing 'infinity minus infinity' is zero.

Checks. Evaluate the function at numbers close to the limit point.

How to practise. Always factor and simplify first. In Unlimited practice, rotate the limit and asymptote families.

More worked examples: Worked examples

Limit at a point. (x² − 9)/(x − 3) = x + 3 for x ≠ 3, so the limit as x → 3 is 6. At infinity. Divide by the highest power: (3x² + 1)/(x² − 5) → 3 as x → ∞. Asymptotes. For (x² − 1)/(x − 2), long division gives x + 2 + 3/(x − 2), so there is a slant asymptote y = x + 2 and a vertical asymptote x = 2.

Try it

Find lim (2x + 1)/(5x − 3) as x → ∞.

Answer. 2/5.

Try it

Find the vertical asymptote(s) of (x + 1)/(x² − 4).

Answer. x = 2 and x = −2.

More worked examples: A second longer problem

Problem. Find lim (√(x² + x) − x) as x → ∞. Solution. Multiply by the conjugate: (x² + x − x²)/(√(x² + x) + x) = x/(√(x² + x) + x) = 1/(√(1 + 1/x) + 1) → 1/2.

Reflection. A difference of large quantities needs a conjugate or a common denominator.

Problem p9. How many vertical asymptotes does (x + 1)/((x − 1)(x + 1)(x − 4)) have?

HintCancel common factors first.
Answer2

The factor x + 1 cancels (a gap, not an asymptote). The remaining denominator (x − 1)(x − 4) gives asymptotes at x = 1 and x = 4: two.

Near x = −1 the simplified fraction 1/((x − 1)(x − 4)) is close to 1/10, so there is no blow-up there.

Problem x20. If x + 1/x = 9, find x² + 1/x².

HintSquare both sides.
Answer79
Method: Square

(x + 1/x)² = x² + 2 + 1/x², so x² + 1/x² = 81 − 2 = 79.

Method: Recurrence

With pₙ = xⁿ + x⁻ⁿ we have p₀ = 2, p₁ = 9 and p₂ = 9 · p₁ − p₀ = 79.
