Reading

1. No square is negative

For real x, x² ≥ 0, with equality only at x = 0. So a sum of squares is zero only if every square is zero. This simple fact solves many problems: completing the square shows the minimum of an expression and the equality case.

Worked example 1. Solve x² + y² − 4x + 6y + 13 = 0. Complete the squares: (x − 2)² + (y + 3)² = 0, because 4 + 9 = 13. So x = 2, y = −3, the only solution.

Worked example 2. The minimum of x² − 6x + 11 is 2, at x = 3, since x² − 6x + 11 = (x − 3)² + 2.

Worked example 3. For real a, b: a² + b² ≥ 2ab, since (a − b)² ≥ 0, with equality only when a = b. Hence a² + b² ≥ 2ab leads to AM-GM for two numbers.

2. Look at the endpoints

A linear function on an interval attains its maximum and minimum at the endpoints. A convex function (for instance x²) attains its maximum on an interval at an endpoint, and a concave function attains its minimum at an endpoint. More generally, in an optimisation problem with several variables, the extreme often occurs when variables are pushed to their extreme values (a boundary).

Worked example. For x + y = 10 with x, y ≥ 0 the product xy = x(10 − x) is concave, with maximum 25 at x = 5 and minimum 0 at the endpoints x = 0 or x = 10. The sum x² + y² = x² + (10 − x)² is convex: minimum 50 at x = 5, maximum 100 at the endpoints.

Worked example (a linear expression on a polygon). To maximise 3x + 2y on the triangle with corners (0, 0), (4, 0), (0, 5): evaluate at corners: 0, 12, 10. The maximum is 12 at (4, 0).

3. Extreme choices and inequalities

If a quantity is largest or smallest at some configuration, an extremal argument considers that configuration and derives a contradiction or a property. In inequality problems write the difference as a sum of squares: for instance a² + b² + c² − ab − bc − ca = ½[(a − b)² + (b − c)² + (c − a)²] ≥ 0.

Worked example. Show a² + b² + c² ≥ ab + bc + ca. The identity above gives it immediately, with equality iff a = b = c. For a = 1, b = 2, c = 3: 14 ≥ 11, and the difference 3 = ½(1 + 1 + 4) = 3 ✓.

4. Mistakes, checks and how to practise

Common mistakes. Using real-number facts for complex numbers (squares can be negative there). Claiming a boundary maximum without checking that the function is convex. Forgetting to check the equality case is attainable.

Checks. Substitute the claimed extremal point.

Practice. Complete the square first, then ask where each square can be zero.

Worked examples with Try-its: Squares are never negative

For real x, x² ≥ 0 with equality only at 0. This gives sharp inequalities quickly: x² − 6x + 13 = (x − 3)² + 4 ≥ 4, so its minimum is 4. For real a, b, c: a² + b² + c² − ab − bc − ca = ½[(a − b)² + (b − c)² + (c − a)²] ≥ 0, with equality only when a = b = c. Also a² + b² ≥ 2ab.

Try it

Find the minimum of x² + 4x + 9.

Answer. (x + 2)² + 5 ≥ 5, so the minimum is 5 at x = −2.

Worked examples with Try-its: Looking at the endpoints

A continuous or linear expression on an interval takes its extreme values at endpoints. For f(x) = 3x − 5 on [1, 4] the range is [−2, 7]. For a convex expression such as a product xy with x + y fixed, the extremes are at the middle (maximum) and the ends (minimum). In integer problems check the smallest and largest allowed values first.

Try it

What is the maximum of x(10 − x) for integers x from 0 to 10, and where is the minimum?

Answer. 25 at x = 5; minimum 0 at x = 0 or 10.

Worked examples with Try-its: A longer problem

Problem. If x and y are real and x² + y² = 8, find the largest possible value of x + y. Solution. (x + y)² = 8 + 2xy ≤ 8 + (x² + y²) = 16 since 2xy ≤ x² + y², so x + y ≤ 4, attained at x = y = 2.

Reflection. The inequality (x − y)² ≥ 0 does all the work.

More worked examples: Worked examples

Completing squares. x² + y² − 2x + 4y = (x − 1)² + (y + 2)² − 5 ≥ −5, with equality at (1, −2). Absolute values. |x − 1| + |x − 5| is the sum of distances from x to 1 and to 5, so it is at least 4, with equality for 1 ≤ x ≤ 5. Endpoints. A linear function such as 2x − 3 on [0, 5] ranges from −3 to 7.

Try it

Find the minimum of x² − 8x + 20.

Answer. (x − 4)² + 4, so 4.

Try it

Find the minimum of |x + 2| + |x − 3|.

Answer. 5.

More worked examples: A second longer problem

Problem. Show that a² + b² + 1 ≥ ab + a + b for all real a, b. Solution. Twice the difference is (a − b)² + (a − 1)² + (b − 1)² ≥ 0, so the inequality holds, with equality when a = b = 1.

Check. At a = b = 1: 3 ≥ 3 ✓.

Problem x19. The roots of x² − 12x + 20 = 0 are r and s. Find r² + s².

HintUse r + s and rs.
Answer104
Method: Vieta

r + s = 12 and rs = 20, so r² + s² = (r + s)² − 2rs = 144 − 40 = 104.

Method: Recurrence

Let pₙ = rⁿ + sⁿ. Then p₀ = 2, p₁ = 12 and p₂ = 12 · p₁ − 20 · p₀ = 144 − 40 = 104.

Source: Andreescu & Gelca, Mathematical Olympiad Challenges, 2.1-2.2
