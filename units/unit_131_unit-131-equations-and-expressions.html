Reading

1. Radical equations

To solve √(f(x)) = g(x), first require g(x) ≥ 0, then square, solve, and check every candidate, because squaring may introduce extra roots.

Worked example. √(x + 5) = x − 1. Squaring: x + 5 = x² − 2x + 1, so x² − 3x − 4 = 0 and x = 4 or x = −1. For x = 4: √9 = 3 = 4 − 1 ✓. For x = −1: √4 = 2 but x − 1 = −2, so it is rejected. The only solution is x = 4.

2. Absolute values

|a| is the distance from a to 0. Solve equations with absolute values by splitting into cases where each expression inside is positive or negative, or by using the distance interpretation.

Worked example. |x − 2| + |x + 1| = 5 means: the sum of the distances from x to 2 and to −1 equals 5. The two points are 3 apart, so the sum is at least 3 and equals 5 outside the segment: x = 3 (1 + 4 = 5 ✓) or x = −2 (4 + 1 = 5 ✓).

Inequalities. |x − 2| < 3 means −1 < x < 5.

3. Substitution and factoring

Recognise a hidden quadratic: x⁴ − 5x² + 4 = 0 becomes u² − 5u + 4 = 0 with u = x², so u = 1 or 4 and x = ±1, ±2. Expressions in √x become polynomials with u = √x.

Worked example (Vieta). If the roots of x² − 5x + 3 = 0 are p and q, then p + q = 5 and pq = 3, so p² + q² = 25 − 6 = 19 and 1/p + 1/q = 5/3.

Rational equations. Multiply by the common denominator and reject any solution that makes a denominator zero: 1/(x − 1) + 1/(x + 1) = 1 gives 2x = x² − 1, x² − 2x − 1 = 0, x = 1 ± √2.

4. Mistakes, checks and how to practise

Common mistakes. Squaring both sides and not checking. Losing a case in absolute values. Cancelling a factor that can be zero.

Checks. Plug each solution into the original equation.

Practice. Write 'Check:' after every radical or rational equation.

Worked examples with Try-its: Factoring tricks

Difference of squares: 2023² − 2022² = (2023 − 2022)(2023 + 2022) = 4045. Sophie Germain: x⁴ + 4y⁴ = (x² + 2y² − 2xy)(x² + 2y² + 2xy). Four consecutive factors: (x + 1)(x + 2)(x + 3)(x + 4) + 1 = (x² + 5x + 5)². These identities turn a hard-looking expression into a perfect square or a product.

Try it

Factor x⁴ + 4.

Answer. (x² − 2x + 2)(x² + 2x + 2).

Worked examples with Try-its: Symmetric and completing the square

x² + y² = (x + y)² − 2xy and x² − y² = (x − y)(x + y). To solve x² + 6x + 5 = 0 write (x + 3)² = 4. A quadratic ax² + bx + c has roots (−b ± √(b² − 4ac))/2a, and the discriminant b² − 4ac tells how many real roots there are.

Try it

For which k does x² + kx + 9 = 0 have exactly one real root?

Answer. k² = 36, so k = ±6.

Worked examples with Try-its: A longer problem

Problem. Evaluate 1 · 2 · 3 · 4 + 1 and 2 · 3 · 4 · 5 + 1 and explain the pattern. Solution. 25 = 5² and 121 = 11². With x = 0 and x = 1 in the identity above, (x² + 5x + 5)² gives 25 and 121; so the product of four consecutive integers plus 1 is always a perfect square.

Reflection. Test the pattern on small numbers before trying to prove it.

More worked examples: Worked examples

Cubes. x³ + y³ = (x + y)(x² − xy + y²) = (x + y)³ − 3xy(x + y). So if x + y = 5 and xy = 6 then x³ + y³ = 125 − 90 = 35 (indeed x, y = 2, 3 and 8 + 27 = 35). Completing the square. x² − 6x + 10 = (x − 3)² + 1.

Try it

Factor 8x³ + 27.

Answer. (2x + 3)(4x² − 6x + 9).

Try it

If a − b = 2 and ab = 3, find a² + b².

Answer. 4 + 6 = 10.

More worked examples: A second longer problem

Problem. Simplify (x² + 3x + 2)/(x² − 1). Solution. The numerator factors as (x + 1)(x + 2) and the denominator as (x − 1)(x + 1), so the fraction is (x + 2)/(x − 1) for x ≠ ±1.

Check. At x = 3: 20/8 = 5/2 and 5/2 ✓.

Problem p1. Solve the system x + y + z = 6; x − y + 2z = 5; 2x + y − z = 1. Find x + y + z.

HintEliminate one variable at a time.
Answer6
Method: Elimination

Eliminating one variable from pairs of equations gives a 2 × 2 system whose solution is (x, y, z) = (1, 2, 3), so x + y + z = 6.

Method: Cramer's rule

The determinant of the coefficients is 7, and the three replaced determinants give x = 1, y = 2, z = 3, with sum 6.

Problem p5. Real numbers satisfy x + y = 7, y + z = 9 and z + x = 12. Find xyz.

HintAdd all three equations.
Answer70
Method: Add

Adding gives 2(x + y + z) = 28, so x + y + z = 14. Subtracting each given sum: z = 7, x = 5, y = 2, so xyz = 70.

Method: Substitute

From the first equation y = 7 − x; the second gives z = 9 − y = 2 + x; the third becomes 2 + 2x = 12, so x = 5 and the rest follow: xyz = 70.

Problem p11. Find the sum of all real solutions of |x − 2| + |x − 10| = 10.

HintSplit at the points 2 and 10.
Answer12
Method: Cases

For x ≥ 10: 2x − 12 = 10 gives x = 11. For x ≤ 2: 12 − 2x = 10 gives x = 1. The middle case gives a constant 8 ≠ 10. Sum = 12.

Method: Distances

The distances from x to 2 and 10 add to 10, which is larger than the distance 8 between them, so x lies outside by (10 − 8)/2 = 1 on each side: x = 1 and 11.

Source: AoPS Vol. 2 ch. 13

Problem p17. One pipe fills a tank in 6 hours and another in 12 hours. How many hours do both take together? (answer as a fraction if needed)

HintAdd the rates.
Answer4
Method: Rates

1/6 + 1/12 = 1/4 per hour, so the time is 4 hours.

Method: Tank units

Use a tank of 72 units: the pipes fill 12 and 6 units per hour, together 18 per hour, so 72/18 = 4 hours.

Answer3
