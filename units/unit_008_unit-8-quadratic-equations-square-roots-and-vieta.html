1. Square roots and what kind of number they are

The square root of a non-negative number a, written √a, is the non-negative number whose square is a. So √49 = 7 (not ±7: the symbol √ always means the non-negative one), and 'solve x² = 49' has two answers, x = 7 and x = −7. Square roots obey two simple rules that you will use constantly: √(ab) = √a · √b and √(a/b) = √a / √b for a, b ≥ 0. They do not turn sums into sums: √(9 + 16) = 5 is not 3 + 4 = 7.

Simplifying. To simplify a root, pull out the largest perfect-square factor: √72 = √(36 × 2) = 6√2. Similarly √50 + √8 = 5√2 + 2√2 = 7√2, and √12 × √3 = √36 = 6. Roots with the same radicand (the number under the sign) combine like terms in algebra, so 5√2 + 2√2 = 7√2 in the same way that 5x + 2x = 7x.

Rationalising a denominator. It is usually neater not to leave a root in the bottom of a fraction. For 2/√2 multiply top and bottom by √2: 2√2/2 = √2. For a denominator like 3 + √2, use the difference of squares (a + b)(a − b) = a² − b²: multiply by the conjugate 3 − √2, giving 1/(3 + √2) = (3 − √2)/((3 + √2)(3 − √2)) = (3 − √2)/(9 − 2) = (3 − √2)/7.

Irrational numbers. Not every square root is a fraction. Why √2 is irrational: suppose √2 = p/q in lowest terms. Then p² = 2q², so p² is even, so p is even, say p = 2m. Then 4m² = 2q², so q² = 2m² and q is even too. But then p and q share the factor 2, contradicting 'lowest terms'. So no such fraction exists. The same argument shows √n is irrational whenever n is not a perfect square.

Try it

Simplify √98 − √32 and rationalise 6/(√5 − 1).

Answer. √98 = 7√2 and √32 = 4√2, so the difference is 3√2. For the fraction: 6(√5 + 1)/((√5 − 1)(√5 + 1)) = 6(√5 + 1)/4 = 3(√5 + 1)/2.

2. Quadratic equations: factoring and completing the square

A quadratic equation has the form ax² + bx + c = 0 with a ≠ 0. Its solutions are the roots. There are three main ways to find them, each useful in different situations; the general formula of the next section covers all cases but is slower when the answer is easy to see.

Factoring. If you can write the quadratic as a product, set each factor to zero (a product is zero only when one of its factors is). For x² − 4x − 5 = 0, look for two numbers with product −5 and sum −4: they are −5 and +1, so (x − 5)(x + 1) = 0 and x = 5 or x = −1. Check x = 5: 25 − 20 − 5 = 0 ✓.

Completing the square. The identity (x + m)² = x² + 2mx + m² shows that to turn x² + bx into a perfect square you add (b/2)². For x² + 6x + 2 = 0: move the constant, x² + 6x = −2; add 9 to both sides, x² + 6x + 9 = 7; so (x + 3)² = 7, x + 3 = ±√7 and x = −3 ± √7. Check one root numerically: x ≈ −0.354, x² + 6x + 2 = 0.125 − 2.125 + 2 = 0 ✓. This method always works, and it is exactly how the quadratic formula is derived.

Choosing a method. If the numbers are small and whole, try factoring first. If the equation has the form (something)² = a number, take square roots. If the middle coefficient is even and the others are small, completing the square is quick. Otherwise use the formula.

Try it

Solve x² − 8x + 5 = 0 by completing the square.

Answer. x² − 8x = −5; add 16: (x − 4)² = 11; so x = 4 ± √11.

3. The quadratic formula and the discriminant

Start from ax² + bx + c = 0 with a ≠ 0, divide by a, complete the square, and the result is x = (−b ± √(b² − 4ac)) / (2a). The quantity under the root, D = b² − 4ac, is the discriminant. It tells you what to expect before computing the roots: if D > 0 there are two different real roots; if D = 0 there is one repeated real root (x = −b/2a); if D < 0 there are no real roots, because a negative number has no real square root.

Worked example 1. 2x² − 7x + 3 = 0. Here a = 2, b = −7, c = 3, so D = 49 − 24 = 25 and x = (7 ± 5)/4, giving x = 3 or x = ½. Check: 2 × 9 − 21 + 3 = 0 ✓ and 2 × ¼ − 3.5 + 3 = 0 ✓. Because D came out a perfect square, the roots are rational and the quadratic could have been factored as (2x − 1)(x − 3).

Worked example 2. x² + 2x + 5 = 0: D = 4 − 20 = −16 < 0, so there are no real solutions. Geometrically the graph of y = x² + 2x + 5 never touches the x-axis (its lowest point is 4).

Worked example 3 (a parameter). For which values of k does x² − kx + 9 = 0 have exactly one solution? A repeated root needs D = k² − 36 = 0, so k = 6 or k = −6; the equations are then (x − 3)² = 0 and (x + 3)² = 0. For which k are there two real roots? When k² > 36, i.e. k > 6 or k < −6.

Worked example 4 (D tells you about the shape). 3x² − 12x + 7 = 0 has D = 144 − 84 = 60, so the roots are (12 ± √60)/6 = (12 ± 2√15)/6 = 2 ± √15/3 ≈ 2 ± 1.291, that is 3.291 and 0.709. Always simplify the root of the discriminant: √60 = 2√15.

Try it

How many real solutions does 5x² − 4x + 1 = 0 have? What about x² − 6x + 9 = 0?

Answer. First: D = 16 − 20 = −4 < 0, so none. Second: D = 36 − 36 = 0, so exactly one, x = 3.

4. Vieta's formulas: the roots' sum and product

If r and s are the roots of ax² + bx + c = 0, then r + s = −b/a and rs = c/a. These are Vieta's formulas. To see why, note that a(x − r)(x − s) = ax² − a(r + s)x + a·rs, and match the coefficients. Their power is that they tell you things about the roots without solving the equation.

Worked example 1. The roots r, s of x² − 7x + 3 = 0 satisfy r + s = 7 and rs = 3. Then r² + s² = (r + s)² − 2rs = 49 − 6 = 43; 1/r + 1/s = (r + s)/(rs) = 7/3; and (r − s)² = (r + s)² − 4rs = 49 − 12 = 37. We computed all these without finding r and s (they are (7 ± √37)/2).

Worked example 2 (sum of cubes). r³ + s³ = (r + s)³ − 3rs(r + s) = 343 − 63 = 280. The trick is always the same: express a symmetric expression through r + s and rs.

Building an equation from its roots. The quadratic with roots r and s is x² − (r + s)x + rs = 0. For the roots 2 + √3 and 2 − √3 the sum is 4 and the product is 4 − 3 = 1, so the equation is x² − 4x + 1 = 0, with whole-number coefficients even though the roots are irrational. The equation whose roots are the reciprocals 1/r and 1/s of x² − 7x + 3 = 0 has sum 7/3 and product 1/3, so it is 3y² − 7y + 1 = 0.

A sneaky use. A rectangle has perimeter 30 and area 54. Its sides x and y satisfy x + y = 15 and xy = 54, so x and y are the roots of t² − 15t + 54 = 0, with D = 225 − 216 = 9, t = (15 ± 3)/2 = 9 or 6. The sides are 6 and 9 (check: 6 + 9 = 15 and 6 × 9 = 54), and the diagonal is √(36 + 81) = √117 = 3√13.

Try it

The roots of x² − 5x + 3 = 0 are p and q. Find p² + q² and (p − q)².

Answer. p + q = 5 and pq = 3. p² + q² = 25 − 6 = 19 and (p − q)² = 25 − 12 = 13.

5. Quadratic word problems

Quadratics come from areas (length × width), from products of quantities that change together, and from motion under gravity. The skill is in translating the story into an equation, solving, and then interpreting the roots, because one of them is sometimes impossible (a negative length).

Worked example 1 (a thrown ball). A ball thrown upwards has height h = 20t − 5t² metres after t seconds. When is it 15 m high? Solve 20t − 5t² = 15, i.e. t² − 4t + 3 = 0, so (t − 1)(t − 3) = 0 and t = 1 or t = 3: once on the way up and once on the way down. The ball is highest at the midpoint t = 2, where h = 20; the symmetry of the two roots about t = 2 is a general fact for parabolas.

Worked example 2 (a garden path). A 10 m by 6 m garden is surrounded by a path of uniform width w, and the path's area equals the garden's area (60 m²). The whole rectangle is (10 + 2w)(6 + 2w) = 120, which expands to 4w² + 32w + 60 = 120, i.e. w² + 8w − 15 = 0. The formula gives w = (−8 ± √(64 + 60))/2 = −4 ± √31. Since a width must be positive, w = −4 + √31 ≈ 1.568 m. The other root is negative and is rejected.

Worked example 3 (two workers). One tap fills a tank 3 hours faster than another. Together they fill it in 2 hours. If the slower tap takes x hours alone, the faster takes x − 3 hours, so 1/x + 1/(x − 3) = 1/2. Multiplying by 2x(x − 3): 2(x − 3) + 2x = x(x − 3), so x² − 7x + 6 = 0, giving x = 6 or x = 1. But x = 1 would make x − 3 negative, so the slower tap takes 6 hours and the faster takes 3 hours (check: 1/6 + 1/3 = 1/2 ✓).

Try it

Two positive numbers differ by 3 and have product 40. Find them.

Answer. Let the smaller be x: x(x + 3) = 40, so x² + 3x − 40 = 0, (x + 8)(x − 5) = 0; the positive solution is x = 5 and the numbers are 5 and 8.

6. Equations with square roots, and false solutions

To solve √(x + 6) = x, square both sides to get x + 6 = x², i.e. x² − x − 6 = 0, so (x − 3)(x + 2) = 0, giving x = 3 or x = −2. But squaring can create answers that do not satisfy the original equation, so always substitute back: x = 3 gives √9 = 3 ✓; x = −2 gives √4 = 2, which is not −2 ✗. Only x = 3 is a solution. The extra root appeared because (−2)² = 2², so squaring forgot the sign.

A good habit is to note the condition before squaring: √(x + 6) = x requires x ≥ 0 (a root cannot equal a negative number) and x + 6 ≥ 0. Applying x ≥ 0 immediately discards −2. When an equation contains two roots, isolate one root, square, simplify, and if a root remains, isolate it and square again, checking the solutions at the end.

Another example. √(2x + 3) = x gives 2x + 3 = x², x² − 2x − 3 = 0, (x − 3)(x + 1) = 0. Check x = 3: √9 = 3 ✓. Check x = −1: √1 = 1 ≠ −1 ✗. So x = 3.

7. A longer problem

Problem. The equation x² − 5x + k = 0 has two real roots whose squares add up to 13. Find k, and then the roots.

Solution. Let the roots be p and q. Then p + q = 5 and pq = k, so p² + q² = 25 − 2k = 13, which gives k = 6. Check the discriminant: 25 − 24 = 1 > 0, so the roots are real. The equation is x² − 5x + 6 = 0, i.e. (x − 2)(x − 3) = 0, and the roots are 2 and 3 (check: 4 + 9 = 13 ✓). The sum-and-product viewpoint found k without solving anything, and the discriminant check confirmed that real roots exist.

A second step. What if the problem had asked for the squares to sum to 30 instead? Then 25 − 2k = 30 gives k = −2.5, and the discriminant is 25 + 10 = 35 > 0, so it works, with roots (5 ± √35)/2 ≈ 5.458 and −0.458. Always test the discriminant: for example, 'squares sum to 10' gives k = 7.5 and D = 25 − 30 = −5 < 0, so no real roots exist and the problem has no real solution.

8. Mistakes, checks and how to practise

Common mistakes. (1) Writing √(a + b) = √a + √b. (2) Forgetting the ± when solving x² = a. (3) Sign slips with b in the formula: for 2x² − 7x + 3 use −b = +7. (4) Dividing both sides by x and losing the root x = 0. (5) Not checking for false roots after squaring. (6) Treating a negative length or time as a valid answer.

Checks. Substitute roots back into the original equation. Check that the sum of your roots is −b/a and the product is c/a: that single test catches most errors in the formula. For word problems check the answer against the story.

How to practise. For each quadratic compute the discriminant first, predict how many roots, then solve and compare. In the Unlimited practice section, the families 'Quadratic with integer roots' and 'Vertex of a parabola' give an endless supply.
