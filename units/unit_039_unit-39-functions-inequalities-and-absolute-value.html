Reading

1. Functions: notation and composition

A function assigns to each input exactly one output. We write f(x) for the output. If f(x) = 2x + 3 and g(x) = x² − 1, then f(g(2)) = f(3) = 9 while g(f(2)) = g(7) = 48: composition depends on the order. The domain is the set of allowed inputs and the range the set of outputs. For √(x − 2)/(x − 5) the domain is x ≥ 2 with x ≠ 5. The range of x² − 4x + 7 = (x − 2)² + 3 is [3, ∞).

Inverse functions. To find the inverse of y = (2x + 1)/(x − 3), solve for x: y(x − 3) = 2x + 1, so x(y − 2) = 3y + 1 and x = (3y + 1)/(y − 2). Swap the names: f⁻¹(x) = (3x + 1)/(x − 2). The graph of the inverse is the reflection in y = x.

Try it

If f(x) = 3x − 2, find f(f(x)) and f⁻¹(x).

Answer. f(f(x)) = 3(3x − 2) − 2 = 9x − 8. f⁻¹(x) = (x + 2)/3.

2. Absolute value equations and inequalities

|a| is the distance of a from 0, so |x − 3| < 2 means x is within 2 units of 3: 1 < x < 5. The equation |2x − 1| = 5 means 2x − 1 = 5 or 2x − 1 = −5: x = 3 or x = −2. The inequality |x − 3| > 2 means x < 1 or x > 5. The sum |x − 1| + |x − 4| is the total distance from x to 1 and 4, which is at least 3, with equality exactly for 1 ≤ x ≤ 4 (confirmed by a numerical scan).

Strategy. Interpret |x − a| as distance. For several absolute values, mark the break points on a number line and treat each interval separately.

Try it

Solve |x + 2| ≤ 5.

Answer. −7 ≤ x ≤ 3.

3. Quadratic and rational inequalities

To solve x² − 5x + 6 < 0, factor: (x − 2)(x − 3) < 0, and the product is negative between the roots: 2 < x < 3. For a rational inequality (x − 1)(x + 2)/(x − 3) ≥ 0, mark the critical points −2, 1 and 3 on a number line, check the sign in each interval, and remember to exclude x = 3 (the denominator is zero): the solution is −2 ≤ x ≤ 1 or x > 3.

Never multiply an inequality by an expression of unknown sign. Move everything to one side, put it over a common denominator, and study the sign.

Try it

Solve (x − 4)/(x + 1) > 0.

Answer. x < −1 or x > 4.

4. A longer problem

Problem. Let f(x) = |x − 1| + |x − 5|. Find the minimum of f, solve f(x) = 6 and f(x) < 8.

Solution. f is the total distance to 1 and 5; the minimum is 4 on 1 ≤ x ≤ 5. For f(x) = 6, the two points are 1 unit beyond each end: x = 0 and x = 6. For f(x) < 8: 2 units beyond each end: −1 < x < 7.

Reflection. The distance interpretation avoids all case work. Check: f(0) = 1 + 5 = 6 ✓.

5. Mistakes, checks and how to practise

Common mistakes. (1) Forgetting to flip the inequality when multiplying by a negative. (2) Including a value that makes a denominator zero. (3) Writing |a| = b as only one equation. (4) Confusing f(g(x)) with g(f(x)).

Checks. Test one point in each interval of your answer. Test the endpoints.

How to practise. Draw the number line for every inequality. In Unlimited practice, rotate the function and inequality families.

More worked examples: Worked examples

Composition. If f(x) = x² − 4x then f(1) = −3 and f(f(1)) = f(−3) = 9 + 12 = 21. Absolute value. |2x − 3| < 5 means −5 < 2x − 3 < 5, so −1 < x < 4. For |x − 2| + |x − 5| = 7 split into regions: for x ≤ 2 we get 7 − 2x = 7, so x = 0; for x ≥ 5 we get 2x − 7 = 7, so x = 7; between 2 and 5 the left side is 3. Solutions: 0 and 7.

Sign charts. (x − 1)(x − 4) < 0 holds between the roots, 1 < x < 4. For (x + 1)/(x − 2) ≥ 0 the critical points are −1 (included) and 2 (excluded because the denominator vanishes), giving x ≤ −1 or x > 2. Domain. √(x − 3)/(x − 5) is defined for x ≥ 3 with x ≠ 5.

Try it

Solve |x + 1| ≥ 3.

Answer. x + 1 ≥ 3 or x + 1 ≤ −3, so x ≥ 2 or x ≤ −4.

Try it

Give the domain of √(6 − x)/(x + 2).

Answer. x ≤ 6 and x ≠ −2.

More worked examples: A second longer problem

Problem. Solve x² − 5x + 6 ≤ |x − 2|. Solution. The left side is (x − 2)(x − 3). For x ≥ 2: (x − 2)(x − 3) ≤ x − 2, so (x − 2)(x − 4) ≤ 0, giving 2 ≤ x ≤ 4. For x < 2: (x − 2)(x − 3) ≤ 2 − x gives (x − 2)(x − 3 + 1) = (x − 2)² ≤ 0, impossible for x < 2. Answer: 2 ≤ x ≤ 4.

Check. At x = 3 the left side is 0 and the right side is 1. ✓ At x = 5 the left is 6, the right is 3: fails, as expected.

Problem p8. What is the smallest value of |x − 3| + |x + 2| over all real x?

HintDistances on a number line.
Answer5
