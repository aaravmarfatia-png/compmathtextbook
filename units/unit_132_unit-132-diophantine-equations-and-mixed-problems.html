Reading

1. Linear Diophantine equations

The equation ax + by = c has integer solutions iff gcd(a, b) divides c. If (x₀, y₀) is one solution, all are (x₀ + (b/g)t, y₀ − (a/g)t).

Worked example. 7x + 11y = 100 in positive integers. Reduce mod 7: 11y ≡ 100, 4y ≡ 2 (mod 7), so y ≡ 4 (mod 7) (since 4 × 4 = 16 ≡ 2). Then y = 4 gives 7x = 56, x = 8. The next solution has y = 11, too large. So (8, 4) is the only positive solution (found also by search).

2. Factoring tricks

Many Diophantine equations factor. Difference of squares: x² − y² = (x − y)(x + y). Simon's trick: xy + ax + by = (x + b)(y + a) − ab. Sophie Germain: n⁴ + 4 = (n² + 2n + 2)(n² − 2n + 2).

Worked example 1. x² − y² = 105 in positive integers. The factor pairs of 105 are (1, 105), (3, 35), (5, 21), (7, 15) with x − y the smaller and x + y the larger: (x, y) = (53, 52), (19, 16), (13, 8), (11, 4).

Worked example 2. For n = 3: 3⁴ + 4 = 85 = 17 × 5, matching (9 + 6 + 2)(9 − 6 + 2). So n⁴ + 4 is composite for n > 1.

3. Sums of squares and mixed problems

A positive integer is a sum of two squares iff every prime ≡ 3 (mod 4) appears to an even power in its factorisation. 325 = 5² × 13 can be written in several ways: 1² + 18², 6² + 17², 10² + 15² (and the reversed pairs).

Mixed problems. Combine tools: modular arithmetic to exclude cases, bounding to limit the search, factoring to reduce to divisors, and a direct check.

Worked example (a bound). Find positive integers with x² + y² = 325 and x < y. The list x = 1, 6, 10 above gives the triples (1, 18), (6, 17), (10, 15).

Infinite descent. If x² + y² is divisible by 3 then 3 divides both x and y; repeating the argument shows x² + y² = 3z² has only the trivial solution.

4. Mistakes, checks and how to practise

Common mistakes. Forgetting negative factor pairs when negative solutions are allowed. Forgetting to check that x and y are integers (x − y and x + y must have the same parity). Missing the trivial solution.

Checks. Substitute each answer into the original equation.

Practice. Before solving, decide: is a congruence, a bound or a factorisation the key?

Worked examples with Try-its: Factoring Diophantine equations

To solve x² − y² = 45 in positive integers write (x − y)(x + y) = 45 with both factors odd and x − y < x + y: the pairs (1, 45), (3, 15), (5, 9) give (x, y) = (23, 22), (9, 6), (7, 2). For linear equations such as 2x + 3y = 20 the positive solutions are (1, 6), (4, 4), (7, 2).

Try it

Solve x² − y² = 15 in positive integers.

Answer. (x − y)(x + y) = 15: (1, 15) gives (8, 7) and (3, 5) gives (4, 1).

Worked examples with Try-its: Mixed strategies

Combine tools: bound the variables, use residues to rule out cases, factor, and finally check small values. For example x² + y² = 3z² has no non-trivial solutions: squares are 0 or 1 (mod 3), so x² + y² ≡ 0 needs both x and y divisible by 3, and then descent shows z is as well.

Try it

Can x² + y² = 2023 have integer solutions?

Answer. 2023 ≡ 3 (mod 4) but a sum of two squares is 0, 1 or 2 (mod 4): no.

Worked examples with Try-its: A longer problem

Problem. Find all pairs of positive integers (m, n) with n² − m² = 9. Solution. (n − m)(n + m) = 9 with n + m > n − m > 0 gives (1, 9) and (3, 3); the first yields (n, m) = (5, 4), the second m = 0 which is not positive. So the only solution is m = 4, n = 5.

Reflection. Factorisation reduces an equation to a finite list.

More worked examples: Worked examples

Linear. 3x + 5y = 47 has the positive solutions (4, 7), (9, 4), (14, 1). Squares. x² − y² = 45 has (23, 22), (9, 6), (7, 2). Residues. x² + y² = 4k + 3 has no integer solutions, since a sum of two squares is 0, 1 or 2 mod 4.

Try it

Does 2x + 4y = 13 have integer solutions?

Answer. No: the left side is even.

Try it

Find positive integers x ≤ y with xy = 2(x + y).

Answer. (x − 2)(y − 2) = 4: (3, 6) and (4, 4).

More worked examples: A second longer problem

Problem. Find all integers n for which n² + 19 is a perfect square. Solution. Write n² + 19 = m², so (m − n)(m + n) = 19, which is prime: m − n = 1 and m + n = 19, giving m = 10 and n = 9 (and n = −9).

Check. 81 + 19 = 100 ✓.

Problem p1. How many ordered pairs of positive integers (x, y) satisfy xy + 2x + 3y = 20?

HintAdd 6 to both sides and factor.
Answer0
Method: Factor

(x + 3)(y + 2) = 26. Divisors d of 26 with d > 3 and 26/d > 2 give x = d − 3: none. That is 0 pairs.

Method: Test x

For each x from 1 up, y = (20 − 2x)/(x + 3) must be a positive integer; this works for x = none only.

Problem p16. How many ordered pairs of integers (x, y) satisfy x² + y² = 25?

HintList the squares up to 25 and include the signs.
Answer12
Method: Squares

0² + 5², 3² + 4². With all sign choices and orders these give 12 pairs.

Method: Divisor rule

The number is 4 times (divisors ≡ 1 mod 4 minus divisors ≡ 3 mod 4) = 4(3 − 0) = 12.

Problem p24. Find the sum of all positive integers n for which n + 1 divides n² + 11.

HintSince n ≡ −1 mod (n + 1), n² + 11 ≡ 12 mod (n + 1).
Answer22
Method: Reduce

n² + 11 ≡ 1 + 11 = 12 (mod n + 1), so n + 1 must divide 12. The divisors of 12 above 1 are 2, 3, 4, 6, 12, so n = 1, 2, 3, 5, 11 with sum 22.

Method: Check

For n = 1, 2, 3, 5, 11 the quotient (n² + 11)/(n + 1) is 6, 5, 5, 6, 11, all whole numbers.
