Reading

1. Barycentric coordinates

Every point P in the plane of triangle ABC can be written P = (αA + βB + γC) with α + β + γ = 1; the triple (α, β, γ) gives the barycentric coordinates. P is inside the triangle iff all three are positive. The vertices are (1, 0, 0), (0, 1, 0), (0, 0, 1); the centroid is (1/3, 1/3, 1/3); the midpoint of BC is (0, 1/2, 1/2). With A = (0, 0), B = (10, 0), C = (0, 10), the point with coordinates (0.2, 0.3, 0.5) is (3, 5).

The area interpretation. α = [PBC]/[ABC], β = [PCA]/[ABC], γ = [PAB]/[ABC]: the weights are the sub-triangle areas opposite each vertex (verified exactly for the point (3, 5) above). Hence the incentre of a triangle with sides a, b, c has coordinates (a : b : c), and the circumcentre has coordinates (a²(b² + c² − a²) : …).

Try it

Find the barycentric coordinates of the midpoint of AB.

Answer. (1/2, 1/2, 0).

2. Areas and lines

The area of the triangle whose vertices have barycentric coordinates (αᵢ, βᵢ, γᵢ) is [ABC] times the absolute value of the determinant of the 3 × 3 matrix of those coordinates. Three points are collinear iff this determinant is zero. A line has the equation ux + vy + wz = 0 in homogeneous coordinates.

Ceva and Menelaus in this language. The cevians through (α : β : γ) meet the sides at (0 : β : γ), (α : 0 : γ), (α : β : 0), and their concurrency is immediate: no calculation is needed to verify Ceva.

Try it

Is the point (2 : 3 : −1) inside triangle ABC? (Normalise first.)

Answer. Sum 4, so (1/2, 3/4, −1/4): γ < 0, so it is outside, beyond side AB.

3. A longer problem

Problem. For the triangle with A = (0, 0), B = (6, 0), C = (0, 6), find the barycentric coordinates of P = (2, 1) and the area of triangle PBC.

Solution. P = αA + βB + γC gives (6β, 6γ) = (2, 1), so β = 1/3, γ = 1/6, α = 1/2. [ABC] = 18, so [PBC] = α · 18 = 9, [PCA] = β · 18 = 6, [PAB] = γ · 18 = 3 (they sum to 18).

Reflection. Reading off areas from barycentric coordinates avoids computing three separate determinants.

4. Mistakes, checks and how to practise

Common mistakes. (1) Forgetting to normalise so the coordinates sum to 1. (2) Assigning the area opposite the wrong vertex. (3) Confusing barycentric with Cartesian coordinates.

Checks. The three areas must sum to [ABC].

How to practise. Convert a few points back and forth. In Unlimited practice, rotate the area-ratio families.

More worked examples: Worked examples

A point with barycentric coordinates (α : β : γ) (not all zero, scaled so that α + β + γ = 1) is αA + βB + γC. In the triangle A = (0, 0), B = (6, 0), C = (0, 6) the point (1 : 2 : 3) is (1 · A + 2 · B + 3 · C)/6 = (2, 3), and the centroid (1 : 1 : 1) is (2, 2). The normalised coordinates are area ratios: the area of triangle ABP over the area of ABC equals the weight on C. For (1 : 2 : 3) that is 3/6 = 1/2 (checked with coordinates).

Try it

Find the point with barycentric coordinates (2 : 1 : 1) in the triangle above.

Answer. (2 · A + B + C)/4 = (6/4, 6/4) = (3/2, 3/2).

Try it

The point P has barycentrics (1 : 1 : 2). What fraction of the area of ABC is triangle ABP?

Answer. 2/4 = 1/2.

More worked examples: A second longer problem

Problem. A point P inside triangle ABC has areas [PBC] = 1, [PCA] = 2 and [PAB] = 3. Find the barycentric coordinates of P and the ratio in which line AP divides BC. Solution. The coordinates are proportional to the opposite areas: (1 : 2 : 3). Line AP meets BC at the point with coordinates (0 : 2 : 3), so BD : DC = 3 : 2.

Check. With the coordinates above P = (2, 3) and the line from A = (0, 0) through (2, 3) hits BC (x + y = 6) at D = (12/5, 18/5). Since B = (6, 0) and C = (0, 6), D is (6 − 12/5)/6 = 3/5 of the way from B to C, so BD : DC = 3 : 2 ✓.

Problem p1. P has barycentric coordinates (1 : 2 : 3) in triangle ABC of area 60. Find [PBC].

HintNormalise: [PBC] = (x/(x+y+z))·[ABC].
Answer10
Method: Normalise

(1, 2, 3)/6 = (1/6, 1/3, 1/2). [PBC] = 60/6 = 10.

Method: Check

The three areas are 10, 20, 30, which sum to 60.

Problem p2. D is on BC with BD:DC = 2:3. If [ABC] = 50, find [ABD].

HintTriangles with the same apex share the height.
Answer20
Method: Ratio of bases

Triangles ABD and ABC have the same height from A, so [ABD]/[ABC] = BD/BC = 2/5, giving 20.

Method: Barycentric

D = (0 : 3 : 2)/5. The weight of C is [ABD]/[ABC] = 2/5, so [ABD] = 20.

Problem p3. Triangle ABC has BC = 14, CA = 15, AB = 13. The incentre I has barycentric coordinates (a : b : c). Find [IBC]/[ABC] as a fraction.

HintNormalise (14, 15, 13).
Answer1/3
Method: Normalise

14 + 15 + 13 = 42, so the ratio is 14/42 = 1/3.

Method: Inradius

[IBC] = (1/2)·14·r and [ABC] = (1/2)·42·r, so the ratio is 14/42 = 1/3.

Problem p4. A = (0,0), B = (10,0), C = (0,10) and P = (2 : 3 : 5) in barycentric coordinates. Find x + y for P = (x, y).

HintP = (2A + 3B + 5C)/10.
Answer8
Method: Weighted average

x = (3·10)/10 = 3 and y = (5·10)/10 = 5, so x + y = 8.

Method: Areas

P is 3/10 of the way along x and 5/10 along y by the weights of B and C, again 3 + 5 = 8.

Problem p5. P has barycentric coordinates (1 : 1 : 2). The line AP meets BC at D. Find BD/DC.

HintDrop A's weight: D = (0 : y : z).
Answer2
Method: Drop A

D = (0 : 1 : 2), the weights of B and C. BD:DC is the inverse of the weight ratio y:z, so BD:DC = 2:1, giving 2.

Method: Balance

With masses B = 1 and C = 2, the balance point D is closer to C, so BD = 2 · DC and BD/DC = 2.

Source: Chen, Euclidean Geometry in Mathematical Olympiads, ch. 7

Problem p6. G is the centroid of triangle ABC and D is the midpoint of BC. Find AG/GD.

HintG = (1:1:1) and D = (0:1:1).
Answer2
Method: Masses

A has weight 2 when B and C (weight 1 each) are combined at D, so AG:GD = 2:1 and AG/GD = 2.

Method: Coordinates

With A = (0,0), B = (6,0), C = (0,6): G = (2,2) and D = (3,3). AG = 2√2, GD = √2, ratio 2.

Problem x18. Find the area of the triangle with vertices (0, 0), (6, 2) and (2, 7).

HintShoelace formula.
Answer19
Method: Shoelace

|0(2 − 7) + 6(7 − 0) + 2(0 − 2)|/2 = 19.

Method: Cross product

The edge vectors are (6, 2) and (2, 7); half the absolute value of 6 · 7 − 2 · 2 is 19.

Problem x20. Two similar triangles have corresponding sides in the ratio 4 : 7. The smaller has area 48. Find the larger area.

HintAreas scale as the square of the ratio.
Answer147
Method: Area ratio

The areas are in the ratio 16 : 49, so the larger area is 48 · 49/16 = 147.

Method: Scale factor

The linear factor is 7/4, so the area factor is 49/16; 48 · 49/16 = 147.

Problem x21. Find the area of the triangle with sides 13, 14 and 15.

HintHeron's formula.
Answer84
Method: Heron

s = 21, so K = √(21 · 8 · 7 · 6) = 84.

Method: Altitude

The altitude to the side 15 is 2K/15 = 56/5, so the area is ½ · 15 · 56/5 = 84.
