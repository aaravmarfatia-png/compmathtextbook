1. What stays the same: invariants

An invariant is a quantity associated with a configuration that does not change when an allowed operation is performed. If a starting position and a target position have different values of the invariant, the target cannot be reached. The skill is guessing the invariant. Natural candidates are the total sum, the sum modulo 2 or 3, the product, the number of objects of a certain colour, and the sign of a permutation.

Example 1 (absolute differences). The numbers 1, 2, …, 10 are written on a board. A move erases two numbers a and b and writes |a − b|. After nine moves one number remains. Is it possible that it is 0? Look at the parity of the sum: a + b and |a − b| have the same parity, so replacing a and b by |a − b| does not change the parity of the total. The sum 1 + … + 10 = 55 is odd, so the final number is odd and cannot be 0. (I simulated many random sequences of moves for boards of size 2 to 11, and in every one the final number had the parity of the original sum.)

Example 2 (a product invariant). The numbers 1, 2, …, n are written down. A move erases two numbers a, b and writes a + b + ab. Since 1 + (a + b + ab) = (1 + a)(1 + b), the product of the numbers (1 + x) is invariant. Hence the final number N satisfies 1 + N = 2 · 3 · … · (n + 1) = (n + 1)!. For n = 5 the final number is 719 whatever order you choose (simulations agree).

Finding the invariant. Ask what the operation does to simple quantities. If it preserves a + b mod 2, use parity; if it turns a, b into something whose (1 + x) multiply, use a product. Experiment with a small case first.

Try it

Numbers 1, 2, …, 7 are on a board. A move replaces two numbers a, b by a + b. What is the final number, and what is the invariant?

Answer. The total is invariant: 1 + … + 7 = 28.

2. Parity of permutations and the sliding puzzle

A transposition swaps two items. The number of inversions in a list (pairs out of order) changes by an odd number when two items swap, so the parity of the permutation — even or odd — flips with every swap. Hence a list can be reached from the sorted list only by an even number of swaps if its inversion count is even, and by an odd number if it is odd.

The sliding puzzle. In the 15-puzzle on a 4 × 4 board the allowed move slides a tile into the empty square. Sliding horizontally does not change the order of the tiles in the reading order. Sliding vertically moves a tile past 3 others, changing the number of inversions by 3, an odd number, but it also changes the row of the blank by one. Combining the two gives an invariant: the parity of (inversions + the blank's row number) cannot change. Therefore swapping two adjacent tiles, say 14 and 15, is impossible.

A small case you can check. On a 2 × 3 board with five tiles and a blank, the number of arrangements is 6! = 720, but only 360 are reachable from the start by sliding (I found exactly 360 by a breadth-first search). In that board the inversion count of the tiles in reading order always keeps the same parity, which explains the missing half.

Row and column flips. On a 3 × 3 grid each move flips all three lights in a row or a column. From all-off, only 32 of the 512 patterns can ever be reached (found by a search), and in particular a single lit cell is not among them.

Try it

Can the list 3, 2, 1 be sorted using an even number of swaps?

Answer. The list has 3 inversions (odd), so it needs an odd number of swaps: e.g. one swap of 3 and 1 sorts it.

3. The extremal principle

The extremal principle says: consider the largest, smallest, first, or last element of a finite set of objects. That object is special and the argument gains information from its special status. Example 1. In a tournament where every pair of players plays one game with no draws, there is always a player (a 'king') who has beaten every other player or beaten someone who beat them. Take the player with the most wins. If she has not beaten player X, then X beat her; X's wins are fewer than hers, so some player she beat must have beaten X (otherwise X would have at least as many wins). I tested 100 random 7-player tournaments and each had such a king.

Example 2 (numbers on a circle). Real numbers are placed around a circle, each equal to the average of its two neighbours. Then all the numbers are equal. Look at the largest number: it is the average of two neighbours that are not larger, so both neighbours equal it; continue around the circle. (A computation for 6 numbers shows that the system has a one-dimensional family of solutions, the constants.)

Example 3 (splitting into equal-sum halves). Can 1, 2, …, 7 be divided into two sets with the same sum? The total is 28, so each half must sum to 14, and {1, 6, 7} works. Can 1, …, 5? The total is 15, odd: impossible. The parity of the total, an invariant of the whole set, immediately rules out half the values of n.

Typical uses. Choose the shortest path, the largest area, the leftmost point, the smallest counterexample. Then show that a still more extreme object exists, which is a contradiction.

Try it

Can the numbers 1, 2, …, 2023 be partitioned into two groups with equal sums?

Answer. The total is 2023 · 2024/2 = 2 047 276, which is even, so parity does not forbid it (a construction exists). For 1, …, 2022 the total 2 045 253 is odd, which does forbid it.

4. Infinite descent

Infinite descent is the extremal principle applied to positive integers: if a counterexample exists, a smallest one exists; then produce an even smaller one, contradiction. Example. √2 is irrational. Suppose a² = 2b² with positive integers a, b and b smallest. Then a is even, a = 2c, so 4c² = 2b² and b² = 2c², so b is even too, b = 2d, and then c² = 2d² with d < b: a smaller solution. Contradiction.

Example. The equation x² + y² = 3z² has no solution in positive integers. Modulo 3, squares are 0 or 1, so x² + y² ≡ 0 mod 3 forces x and y both divisible by 3. Then 9 divides 3z², so 3 divides z² and so z; so (x/3, y/3, z/3) is a smaller solution. A computer search up to 60 finds none, as predicted.

Recipe. Assume a solution exists; choose the one with the smallest value of some positive integer quantity; show that a divisibility or parity argument produces a smaller solution.

Try it

Prove that x² + y² = 7z² has no solution in positive integers.

Answer. Squares mod 7 are 0, 1, 2, 4. x² + y² ≡ 0 mod 7 only if both are 0 (1 + 6, 2 + 5, 4 + 3 are impossible since 6, 5, 3 are not squares). So 7 divides x and y, then 7 divides z², hence z, and descent applies.

5. Tilings and tours

The knight's tour. A knight alternates between light and dark squares at every move. A closed tour visits every square once and returns to the start. On a 5 × 5 board there are 13 squares of one colour and 12 of the other; a closed tour would have to alternate colours, so it needs equal numbers. Therefore no closed knight's tour exists on a 5 × 5 board (nor on any board with an odd number of squares).

Splitting totals. Parity of a total is a free invariant: in any problem that asks to divide a set of numbers into two groups with equal sums, check first whether the total is even. In the same spirit, a sign problem such as 'put + or − in front of 1, 2, …, n to make the total 0' needs n(n + 1)/2 to be even.

Combining invariants. Some problems need two invariants at once, such as parity and a colour count. When one invariant fails to separate start and target, look for a second one.

Try it

Why can no closed knight's tour exist on a 7 × 7 board?

Answer. 49 squares, so the colour counts (25 and 24) differ, but a closed alternating tour needs equal counts.

6. A longer problem

Problem. The numbers 1, 2, 3, …, 20 are written on a board. A move erases any two numbers a and b and writes a + b − 1. After 19 moves one number remains. (a) What is it? (b) What if the move writes ab − a − b + 2?

Solution. (a) Replacing a and b by a + b − 1 keeps the sum of the quantities (x − 1) unchanged, because (a − 1) + (b − 1) = (a + b − 1) − 1. Initially that sum is (1 + 2 + … + 20) − 20 = 210 − 20 = 190. At the end one number N remains, so N − 1 = 190 and N = 191 (simulations of random move orders agree). (b) Here ab − a − b + 2 = (a − 1)(b − 1) + 1, so now the product of the quantities (x − 1) is unchanged. The number 1 is on the board at the start and gives the factor 0, so the product is 0 and the final N satisfies N − 1 = 0, i.e. N = 1 (also confirmed by simulation).

Reflection. Both parts used the substitution y = x − 1, which turns a messy operation into a simple one (sum or product). When an operation looks odd, try shifting every number by a constant.

7. Mistakes, checks and how to practise

Common mistakes. (1) Claiming a quantity is invariant without checking every allowed move. (2) Using an invariant that has the same value at the start and the target, which proves nothing. (3) Misusing parity (an invariant 'mod 2' only forbids targets of the other parity). (4) In extremal arguments, forgetting to check that the extremal object exists (finite set, or well-ordered values). (5) In descent, failing to show the new solution is positive and smaller.

Checks. Run the operation on a small example by hand and track the proposed invariant. Simulate if you can. Check that the starting and target values differ before concluding impossibility.

How to practise. For each process problem, write down three candidate invariants (sum, parity, product) and test them on one move. In Unlimited practice, work the invariant and extremal families.

Problem p1. The numbers 1, 2, …, 10 are written on a board. A move erases two numbers and writes their difference. After nine moves one number is left. Is it even or odd?

HintThink about the sum's parity.
Answerodd
Method: Parity invariant

The sum 55 is odd. Replacing a and b by |a − b| changes the sum by a + b − |a − b|, which is an even number (2·min(a, b)). So the sum stays odd, and so does the final number.

Method: Experiments

Playing the game several ways (differences in many orders) always gives an odd final number.

Source: Engel, Problem-Solving Strategies, ch. 1 (invariance) and ch. 3-4 (pigeonhole, extremal ideas); Zeitz, ch. 2

Problem p2. At a party of 15 people, can each person shake hands with exactly 3 others? Answer yes or no.

HintCount handshakes from each person.
Answerno
Method: Count ends of handshakes

Each handshake is counted twice if we add each person's count, so the total 15·3 = 45 must be even. It is odd: impossible.

Method: Degree parity

In any graph the number of people with an odd number of handshakes is even. Here all 15 would be odd, and 15 is odd.

Source: Engel, Problem-Solving Strategies, ch. 1 (invariance) and ch. 3-4 (pigeonhole, extremal ideas); Zeitz, ch. 2

Answer6

The pairs (1,10), (2,9), (3,8), (4,7), (5,6) are five boxes. Choosing six numbers puts two in the same box, and they add to 11. Five numbers can avoid it (1, 2, 3, 4, 5).

Each break raises the number of pieces by exactly 1. We go from 1 piece to 96, so 95 breaks, regardless of how we break.

Answer25

Problem p8. What is the smallest n such that in any list of n integers, some run of consecutive entries has a sum divisible by 6?

HintUse partial sums mod 6.
Answer6
Method: Partial sums

Take the partial sums s₀ = 0, s₁, …, sₙ mod 6. With n = 6 there are 7 sums and only 6 residues, so two are equal, and the numbers between them add to a multiple of 6. With n = 5, the list 1, 1, 1, 1, 1 has no group of consecutive numbers summing to a multiple of 6.

Method: Computer check

Trying all residue lists for n up to 6 confirms this.
