1. The floor function

The floor ⌊x⌋ is the greatest integer not exceeding x: ⌊3.7⌋ = 3, ⌊5⌋ = 5, ⌊−1.2⌋ = −2 (note: not −1). The fractional part {x} = x − ⌊x⌋ lies in [0, 1). The ceiling ⌈x⌉ is the least integer at least x. Basic facts: ⌊x + n⌋ = ⌊x⌋ + n for an integer n; ⌊x⌋ ≤ x < ⌊x⌋ + 1; and ⌊n/k⌋ is the number of multiples of k among 1, …, n.

Worked example 1. Solve ⌊2x − 1⌋ = 4. We need 4 ≤ 2x − 1 < 5, so 2.5 ≤ x < 3.

Worked example 2. How many multiples of 7 are there between 1 and 500? ⌊500/7⌋ = 71. Between 100 and 500 inclusive: ⌊500/7⌋ − ⌊99/7⌋ = 71 − 14 = 57.

2. Sums with floors

Square roots. The number of n ≤ 100 with ⌊√n⌋ = k is (k + 1)² − k² = 2k + 1 (for k ≤ 9). So Σ ⌊√n⌋ for n = 1 to 100 = Σ_{k=1}^{9} k(2k + 1) + 10 = 2 × 285 + 45 + 10 = 625.

The divisor-sum trick. Σ_{k=1}^{n} ⌊n/k⌋ counts pairs (k, m) with km ≤ n, which equals the sum of the number of divisors of 1, …, n. For n = 10: 10 + 5 + 3 + 2 + 2 + 1 + 1 + 1 + 1 + 1 = 27 ✓ (indeed τ(1) + … + τ(10) = 1 + 2 + 2 + 3 + 2 + 4 + 2 + 4 + 3 + 4 = 27).

Hermite's identity. ⌊x⌋ + ⌊x + 1/2⌋ = ⌊2x⌋. Check x = 2.3: 2 + 2 = 4 = ⌊4.6⌋ ✓; x = 2.7: 2 + 3 = 5 = ⌊5.4⌋ ✓.

Legendre's formula (Unit 21) uses floors: v_p(n!) = Σ ⌊n/pᵏ⌋.

3. Beatty sequences and equations

If α is irrational and α > 1, the sequence ⌊α⌋, ⌊2α⌋, ⌊3α⌋, … is a Beatty sequence. Two Beatty sequences ⌊nα⌋ and ⌊nβ⌋ with 1/α + 1/β = 1 partition the positive integers. For α = φ (the golden ratio) the pair is ⌊nφ⌋ = 1, 3, 4, 6, 8, 9, 11, … and ⌊nφ²⌋ = 2, 5, 7, 10, 13, 15, 18, … Together they cover every positive integer once.

Worked example 1. Solve x² − 7⌊x⌋ + 6 = 0. Let n = ⌊x⌋; then x² = 7n − 6 and n ≤ x < n + 1. Try n = 1: x² = 1, x = 1 ✓ (⌊1⌋ = 1). n = 2: x² = 8, x ≈ 2.83, ⌊x⌋ = 2 ✓. n = 3: x² = 15, x ≈ 3.87 ✓. n = 4: x² = 22, x ≈ 4.69 ✓. n = 5: x² = 29, x ≈ 5.39 ✓. n = 6: x² = 36, x = 6 ✓. n = 7: x² = 43, x ≈ 6.56 ✗. So x = 1, √8, √15, √22, √29, 6.

Worked example 2. For which positive integers n is ⌊n/3⌋ = ⌊n/5⌋? Checking n = 1, 2 (both 0) and n = 5 (both 1) works; n = 3, 4, 6, 7, … fail. For n ≥ 8, n/3 − n/5 = 2n/15 > 1, so the floors must differ. Only n = 1, 2, 5 qualify, as a direct check up to 7 confirms.

4. Mistakes, checks and how to practise

Common mistakes. Taking ⌊−1.2⌋ = −1. Forgetting that {x} is never 1. Using ⌊x + y⌋ = ⌊x⌋ + ⌊y⌋ (it can be one bigger). Dropping the inequality range when solving for x.

Checks. Test an interval's endpoint and a point inside.

Practice. Replace ⌊x⌋ = n by n ≤ x < n + 1.

Worked examples with Try-its: Properties of ⌊x⌋

⌊x⌋ is the greatest integer not exceeding x; {x} = x − ⌊x⌋ is the fractional part, between 0 and 1. Key facts: ⌊x + n⌋ = ⌊x⌋ + n for integer n; ⌊x⌋ + ⌊y⌋ ≤ ⌊x + y⌋ ≤ ⌊x⌋ + ⌊y⌋ + 1; and ⌊n/2⌋ + ⌊(n + 1)/2⌋ = n for every integer n. A sum like ⌊1/3⌋ + ⌊2/3⌋ + … + ⌊10/3⌋ = 0 + 0 + 1 + 1 + 1 + 2 + 2 + 2 + 3 + 3 = 15.

Try it

Evaluate ⌊−2.5⌋ and ⌊π⌋.

Answer. −3 and 3.

Worked examples with Try-its: Legendre and counting multiples

The exponent of a prime p in n! is ⌊n/p⌋ + ⌊n/p²⌋ + …; for p = 5 and n = 100 this is 20 + 4 = 24. The number of multiples of d up to n is ⌊n/d⌋. To solve ⌊x⌋ = 3 write 3 ≤ x < 4; to solve ⌊2x⌋ = 5 write 5/2 ≤ x < 3.

Try it

How many positive integers up to 200 are divisible by 7?

Answer. ⌊200/7⌋ = 28.

Worked examples with Try-its: A longer problem

Problem. Solve ⌊x⌋ + ⌊2x⌋ = 7. Solution. Write x = n + f with 0 ≤ f < 1. If f < 1/2, ⌊2x⌋ = 2n so 3n = 7, impossible. If f ≥ 1/2, ⌊2x⌋ = 2n + 1, so 3n + 1 = 7 and n = 2, giving 2.5 ≤ x < 3. Check x = 2.5: 2 + 5 = 7 ✓.

Reflection. Split on the fractional part.

More worked examples: Worked examples

Legendre. The exponent of 7 in 50! is ⌊50/7⌋ + ⌊50/49⌋ = 7 + 1 = 8. Sums. Σ_{k=1}^{16} ⌊√k⌋ = 1 · 3 + 2 · 5 + 3 · 7 + 4 · 1 = 3 + 10 + 21 + 4 = 38 (the value m occurs for k from m² to (m + 1)² − 1). Equations. ⌊x⌋ = 3 means 3 ≤ x < 4; ⌊2x⌋ = 5 means 2.5 ≤ x < 3.

Try it

How many trailing zeros does 60! have?

Answer. 12 + 2 = 14.

Try it

Solve ⌊3x⌋ = 7.

Answer. 7/3 ≤ x < 8/3.

More worked examples: A second longer problem

Problem. Evaluate ⌊1000/3⌋ + ⌊1000/9⌋ + ⌊1000/27⌋ + ⌊1000/81⌋ + ⌊1000/243⌋ + ⌊1000/729⌋. Solution. 333 + 111 + 37 + 12 + 4 + 1 = 498, which is the exponent of 3 in 1000!.

Check. Legendre's formula for p = 3 and n = 1000.
