1. The principle of induction

Mathematical induction proves a statement P(n) for every integer n ≥ n₀ in two steps. Base case: prove P(n₀). Inductive step: assume P(k) is true for some k ≥ n₀ (the induction hypothesis) and prove P(k + 1). Then P(n₀) is true, hence P(n₀ + 1), hence P(n₀ + 2), and so on, like a line of dominoes in which the first falls and each falling domino knocks over the next.

First example. Prove 1 + 2 + … + n = n(n + 1)/2. Base case n = 1: 1 = 1 · 2/2. Inductive step: if 1 + … + k = k(k + 1)/2, then 1 + … + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2, which is the formula for n = k + 1. Done. The same pattern proves 1² + … + n² = n(n + 1)(2n + 1)/6 and 1³ + … + n³ = (n(n + 1)/2)², and that the sum of the first n odd numbers is n². I verified all four formulas for n up to 59 by computer, as a sanity check of the statements (the induction is the proof).

The structure of a good write-up. State P(n) clearly. Check the base case explicitly. Write 'assume P(k)'. Show where the hypothesis is used. End by stating P(k + 1) as the conclusion. A proof that never uses the hypothesis is not an induction proof.

Why the base case matters. Consider 'all horses have the same colour', 'proved' by induction on the number of horses. The inductive step splits n + 1 horses into two overlapping sets of n horses; the overlap forces all colours equal. For n = 1 → 2, though, the two sets are single horses with no overlap, so the step fails. A proof by induction is valid only if the step works for every k from the base case on, including the first.

Try it

Prove that 2 + 4 + 6 + … + 2n = n(n + 1).

Answer. n = 1: 2 = 1 · 2. If 2 + … + 2k = k(k + 1), then adding 2(k + 1) gives k(k + 1) + 2(k + 1) = (k + 1)(k + 2).

2. Divisibility by induction

Example. Show that 7 divides 8ⁿ − 1 for all n ≥ 0. Base case: 8⁰ − 1 = 0, divisible by 7. Step: suppose 8ᵏ − 1 = 7m. Then 8ᵏ⁺¹ − 1 = 8 · 8ᵏ − 1 = 8(7m + 1) − 1 = 56m + 7 = 7(8m + 1). So 7 divides 8ᵏ⁺¹ − 1.

The trick for the step. Write the (k + 1) expression in terms of the k expression plus a multiple of the divisor. For n³ − n divisible by 6 (n ≥ 0): (k + 1)³ − (k + 1) = (k³ − k) + 3k(k + 1), and 3k(k + 1) is divisible by 6 because k(k + 1) is even. For 4ⁿ + 15n − 1 divisible by 9: (4ᵏ⁺¹ + 15(k + 1) − 1) = 4(4ᵏ + 15k − 1) − 45k + 18 = 4(4ᵏ + 15k − 1) − 9(5k − 2). Every claim was checked for n up to 59 by computer.

Alternative. Divisibility statements can often be proved without induction by factoring (8ⁿ − 1 is divisible by 8 − 1 = 7 by the factorisation of aⁿ − bⁿ) or by congruences. Induction is the method of choice when no neat factorisation is available.

Try it

Prove by induction that 3 divides 4ⁿ − 1.

Answer. n = 0: 0 ✓. If 4ᵏ − 1 = 3m then 4ᵏ⁺¹ − 1 = 4(3m + 1) − 1 = 12m + 3 = 3(4m + 1).

3. Inequalities by induction

Example. Prove 2ⁿ > n² for n ≥ 5. The base case must be n = 5, not n = 1: 32 > 25 ✓ (while 2ⁿ ≤ n² for n = 2, 3, 4, so the statement is false there, a good reminder to choose the base case with care). Step: assume 2ᵏ > k² with k ≥ 5. Then 2ᵏ⁺¹ = 2 · 2ᵏ > 2k², and we need 2k² ≥ (k + 1)² = k² + 2k + 1, i.e. k² ≥ 2k + 1, which is true for k ≥ 3. So 2ᵏ⁺¹ > (k + 1)².

More examples. n! > 2ⁿ for n ≥ 4: base 24 > 16; step (k + 1)! = (k + 1) k! > (k + 1) 2ᵏ ≥ 2 · 2ᵏ since k + 1 ≥ 2. Bernoulli's inequality: (1 + x)ⁿ ≥ 1 + nx for x ≥ −1: step (1 + x)ᵏ⁺¹ = (1 + x)(1 + x)ᵏ ≥ (1 + x)(1 + kx) = 1 + (k + 1)x + kx² ≥ 1 + (k + 1)x. Here we needed 1 + x ≥ 0 to multiply an inequality.

A useful strengthening. To prove 1/1² + … + 1/n² < 2 directly by induction is difficult because the inductive step fails. Prove the stronger statement 1/1² + … + 1/n² ≤ 2 − 1/n instead: base 1 ≤ 1; step adds 1/(k + 1)², and 2 − 1/k + 1/(k + 1)² ≤ 2 − 1/(k + 1) because 1/k − 1/(k + 1) = 1/(k(k + 1)) ≥ 1/(k + 1)². Strengthening the statement gives the induction hypothesis more power.

Try it

Prove that n! > 2ⁿ for n ≥ 4.

Answer. Base n = 4: 24 > 16. Step: (k + 1)! = (k + 1) · k! > (k + 1) · 2ᵏ ≥ 2 · 2ᵏ = 2ᵏ⁺¹.

4. Recursion and closed forms

A recursive sequence defines each term from earlier ones. For the Tower of Hanoi, moving n discs from one peg to another needs H(n) moves, with H(n) = 2H(n − 1) + 1 (move n − 1 discs away, move the big disc, move n − 1 discs back on top) and H(0) = 0. The values are 1, 3, 7, 15, 31, 63, 127, and the closed form is H(n) = 2ⁿ − 1, which we prove by induction: H(k + 1) = 2(2ᵏ − 1) + 1 = 2ᵏ⁺¹ − 1.

Counting regions. Draw n lines in general position (no two parallel, no three meeting). Each new line crosses the previous n − 1 lines at n − 1 points, which cuts it into n pieces, each of which splits one region into two. So R(n) = R(n − 1) + n with R(0) = 1: values 1, 2, 4, 7, 11, 16 and R(n) = n(n + 1)/2 + 1. For n circles in general position (each pair meets twice) the recurrence is R(n) = R(n − 1) + 2(n − 1) with R(1) = 2, giving 2, 4, 8, 14, 22 and R(n) = n² − n + 2.

Fibonacci. The sequence 1, 1, 2, 3, 5, 8, … satisfies F(n + 1) = F(n) + F(n − 1). Induction proves many identities: F(1) + … + F(n) = F(n + 2) − 1, F(1)² + … + F(n)² = F(n)F(n + 1), and Cassini's identity F(n − 1)F(n + 1) − F(n)² = (−1)ⁿ. All three were checked numerically for n up to 49. Another consequence is that consecutive Fibonacci numbers are coprime.

Binary strings. The number of binary strings of length n with no two adjacent 1s satisfies s(n) = s(n − 1) + s(n − 2): a string ends in 0 (any good string of length n − 1 before it) or in 01 (any good string of length n − 2 before it). The values 2, 3, 5, 8, 13, 21, 34, 55, 89 match a direct enumeration.

Try it

Show that three straight lines in general position divide the plane into 7 regions.

Answer. R(3) = R(2) + 3 = 4 + 3 = 7.

5. Strong induction

In strong induction the hypothesis is that P holds for all values from the base up to k, and you prove P(k + 1). It is the right tool when P(k + 1) depends on several earlier cases, not just the last one.

Stamps. Show that any postage of 12 or more can be made from 4-cent and 5-cent stamps. Base cases: 12 = 4 + 4 + 4, 13 = 4 + 4 + 5, 14 = 4 + 5 + 5, 15 = 5 + 5 + 5. Step: for n ≥ 16 write n = (n − 4) + 4, where n − 4 ≥ 12 is covered by the hypothesis, so add one 4-cent stamp. (Four base cases are needed because the step jumps back by 4. A computer search confirms every n from 12 to 199 works, and 11 does not.) The same method with 3-cent and 5-cent stamps works for every n ≥ 8.

Every integer greater than 1 is a product of primes. Take n > 1. If n is prime, we are done. Otherwise n = ab with 1 < a, b < n, and both a and b are products of primes by the strong hypothesis, so n is too. Here ordinary induction (assuming only P(n − 1)) would not work, because the factors a and b can be any smaller numbers.

The Catalan numbers. The number of ways to bracket a product of n + 1 factors satisfies C(n) = C(0)C(n − 1) + C(1)C(n − 2) + … + C(n − 1)C(0): first multiplication at some split, then independent bracketings on the two sides. This is a strong-recursion pattern; the values are 1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862 and C(n) = C(2n, n)/(n + 1).

Try it

Show that any amount of at least 8 cents can be paid with 3-cent and 5-cent coins.

Answer. Base cases 8 = 3 + 5, 9 = 3 + 3 + 3, 10 = 5 + 5. For n ≥ 11, n − 3 ≥ 8 is payable, so add a 3-cent coin.

6. A longer problem

Problem. In the Josephus problem, n people stand in a circle; starting from person 1, every second person is removed (2, 4, 6, …) until one remains. Let J(n) be the survivor. Find J(n) in general.

Solution. If n = 2m is even, after one pass around the circle the even-numbered people are gone and we have m people left, numbered 1, 3, 5, …, starting again from person 1. So J(2m) = 2J(m) − 1. If n = 2m + 1 is odd, then after removing 2, 4, …, 2m and then person 1, we are left with m people starting from person 3, so J(2m + 1) = 2J(m) + 1. With J(1) = 1 we find by strong induction J(n) = 2L + 1 where n = 2ᵐ + L with 0 ≤ L < 2ᵐ. The formula matches a direct simulation for every n from 1 to 63; for n = 10 it gives 5 and for n = 41 it gives 19.

Reflection. The solution has three parts: find a recursion by thinking about one round, guess a closed form from small cases (1, 1, 3, 1, 3, 5, 7, 1, …), and prove it by strong induction. This is the typical workflow for recursion problems.

7. Mistakes, checks and how to practise

Common mistakes. (1) Omitting the base case or checking the wrong one. (2) In the step, assuming what you want to prove. (3) Using n = k + 1 on one side and n = k on the other without noticing. (4) Needing P(k − 1) in the step but having verified only one base case (use strong induction with several base cases). (5) A step that works only for large k while the base case starts too early.

Checks. Test the claim for n = 1, 2, 3 before attempting a proof. Confirm that the step works for the smallest k allowed. Check that your closed form satisfies the recursion.

How to practise. For each induction proof write P(k) and P(k + 1) side by side before manipulating. In Unlimited practice, rotate the sums, divisibility and recursion families.

Problem p1. For which n is 1 + 2 + … + n = 210?

HintUse n(n+1)/2.
Answer20
Method: Formula

n(n + 1)/2 = 210 gives n² + n − 420 = 0, so (n − 20)(n + 21) = 0 and n = 20.

Method: Pairing

Pair first with last: each pair of n + 1, and n/2 pairs. 20·21/2 = 210 works and 19·20/2 = 190, 21·22/2 = 231 do not.

Problem p9. What is the largest integer that divides n³ − n for every integer n?

Hintn³ − n = (n − 1)n(n + 1).
Answer6
Method: Three consecutive numbers

(n − 1)n(n + 1) contains a multiple of 2 and a multiple of 3, so 6 divides it. n = 2 gives 6, so nothing larger works.

Method: Induction

(n + 1)³ − (n + 1) = n³ − n + 3n(n + 1), and 3n(n + 1) is a multiple of 6 since n(n + 1) is even. So divisibility by 6 passes from n to n + 1.

Problem p11. With 3¢ and 5¢ stamps, what is the largest postage that cannot be made?
