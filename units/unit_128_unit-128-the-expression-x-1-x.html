Andreescu & Gelca, Mathematical Olympiad Challenges, section 2.8 (x + 1/x).

Reading

1. Powers of x + 1/x

Put t = x + 1/x. Then x² + 1/x² = t² − 2 and x³ + 1/x³ = t³ − 3t. In general s_n = x^n + x^{−n} satisfies s_{n+1} = t · s_n − s_{n−1}, with s₀ = 2 and s₁ = t.

Worked example. If x + 1/x = 3, then s₂ = 7, s₃ = 3 × 7 − 3 = 18, s₄ = 3 × 18 − 7 = 47. Direct check with x = (3 + √5)/2: s₄ = 47.000 ✓.

2. Range of t and the angle form

For real x > 0, x + 1/x ≥ 2 with equality iff x = 1 (AM-GM, or (√x − 1/√x)² ≥ 0). For real x < 0, x + 1/x ≤ −2. So t cannot lie strictly between −2 and 2 for real x. If |x| = 1 and x = cos θ + i sin θ, then x + 1/x = 2 cos θ and x^n + x^{−n} = 2 cos nθ, which makes t ∈ [−2, 2] possible only for complex x on the unit circle.

Worked example. For x > 0 the minimum of x + 4/x is 4, at x = 2, since by AM-GM x + 4/x ≥ 2√4 = 4.

3. Palindromic equations

A palindromic polynomial (coefficients read the same forwards and backwards) can be divided by a power of x so that it becomes a polynomial in t = x + 1/x.

Worked example. x⁴ + x³ + x² + x + 1 = 0: divide by x²: x² + 1/x² + x + 1/x + 1 = (t² − 2) + t + 1 = t² + t − 1 = 0, so t = (−1 ± √5)/2. These are 2 cos 72° ≈ 0.618 and 2 cos 144° ≈ −1.618, the primitive fifth roots of unity ✓.

Worked example. 2x⁴ − 5x³ + 6x² − 5x + 2 = 0 divides by x² into 2(t² − 2) − 5t + 6 = 2t² − 5t + 2 = 0, so t = 2 or 1/2. t = 2 gives x = 1 (double root); t = 1/2 gives complex roots.

4. Mistakes, checks and how to practise

Common mistakes. Forgetting that x = 0 is not allowed (division by x). Forgetting to solve for x after finding t. Using t between −2 and 2 for real x.

Checks. Substitute back to confirm.

Practice. Build the table s₀, s₁, s₂, … using the recurrence.

Worked examples with Try-its: Power sums of x and 1/x

If x + 1/x = 3 then x² + 1/x² = 9 − 2 = 7, x³ + 1/x³ = 3 · 7 − 3 = 18 and x⁴ + 1/x⁴ = 7² − 2 = 47. In general pₙ₊₁ = (x + 1/x)pₙ − pₙ₋₁. For real positive x we always have x + 1/x ≥ 2 with equality at x = 1.

Try it

If x + 1/x = 5, find x² + 1/x².

Answer. 23.

Worked examples with Try-its: The trigonometric link

If x = e^{iθ} then x + 1/x = 2 cos θ and xⁿ + 1/xⁿ = 2 cos nθ. So x + 1/x = 1 means θ = 60° and x⁶ + 1/x⁶ = 2 cos 360° = 2. Likewise x + 1/x = 0 gives x = ±i.

Try it

If x + 1/x = 1, find x³ + 1/x³.

Answer. 1³ − 3 · 1 = −2 (= 2 cos 180°).

Worked examples with Try-its: A longer problem

Problem. Solve x + 1/x = 5/2. Solution. 2x² − 5x + 2 = 0, so x = 2 or x = 1/2.

Reflection. The two roots are reciprocals of each other, as always for this equation.

More worked examples: Worked examples

Golden ratio. With φ = (1 + √5)/2, φ + 1/φ = √5, φ² + 1/φ² = 3 and φ⁴ + 1/φ⁴ = 7. From a sum. If x + 1/x = 5/2 then x² + 1/x² = 25/4 − 2 = 17/4. Equation. x + 1/x = 5/2 gives x = 2 or 1/2.

Try it

More worked examples: A second longer problem

Problem. If x + 1/x = 3, find x⁵ + 1/x⁵. Solution. p₁ = 3, p₂ = 7, p₃ = 3 · 7 − 3 = 18, p₄ = 3 · 18 − 7 = 47 and p₅ = 3 · 47 − 18 = 123.

Check. With x = (3 + √5)/2 the value is 123.

Problem p1. If x + 1/x = 3, find x^2 + 1/x^2.

HintLet pₙ = xⁿ + x⁻ⁿ and use pₙ = k·pₙ₋₁ − pₙ₋₂.
Answer7
Method: Recurrence

Since xⁿ + x⁻ⁿ = (x + 1/x)(xⁿ⁻¹ + x⁻ⁿ⁺¹) − (xⁿ⁻² + x⁻ⁿ⁺²), the values are 2, 3, 7, so p_2 = 7.

Method: Expand powers

(x + 1/x)² = x² + 2 + 1/x², so p₂ = 9 − 2 = 7.

Problem p12. If x + 1/x = 1, find x^2026 + 1/x^2026.

HintThe values pₙ repeat with a short period.
Answer-1
Method: Period

The recurrence pₙ = 1·pₙ₋₁ − pₙ₋₂ gives 2, 1, -1, -2, -1, 1, 2, 1, -1, -2, -1, 1, which repeats, and since 2026 leaves remainder 4 the answer is -1.

Method: Roots of unity

x + 1/x = 1 means x = e^(iπ/3), so xⁿ + x⁻ⁿ = 2cos(2026 · 60°) = -1.

Source: Andreescu & Gelca, 2.8

Problem p16. How many distinct real solutions does x⁴ − 5x³ + 8x² − 5x + 1 = 0 have?

HintDivide by x² and set y = x + 1/x.
Answer3
Method: Substitution

Dividing by x² gives (x² + 1/x²) + -5(x + 1/x) + 8 = 0, i.e. y² − 5y + 6 = 0 with y = x + 1/x. Its roots are y = 3, 2. A real x exists exactly when |y| ≥ 2, giving 2 values of x for |y| > 2 and 1 for |y| = 2: total 3.

Method: Numerical check

Solving the quartic numerically gives the real roots 0.382, 1.0, 2.618, which are 3 distinct values.

Source: Andreescu & Gelca, 2.8

Problem p19. A positive real x has x² + 1/x² = 7. Find x + 1/x.

HintAdd 2 and take a square root.
Answer3
Method: Square

(x + 1/x)² = x² + 2 + 1/x² = 9, and x > 0 makes x + 1/x positive, so it equals 3.

Method: Check

If x + 1/x = 3 then x² + 1/x² = 9 − 2 = 7, matching.
