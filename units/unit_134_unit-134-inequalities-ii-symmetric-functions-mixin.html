Reading

1. Symmetric functions p, q, r

For three numbers write p = a + b + c, q = ab + bc + ca and r = abc. Many symmetric expressions are polynomials in p, q, r: a³ + b³ + c³ = p³ − 3pq + 3r and (a + b)(b + c)(c + a) = pq − r. For the roots 1, 2, 3 we have p = 6, q = 11, r = 6, so the cube sum is 216 − 198 + 18 = 36 = 1 + 8 + 27 ✓ and the product of pair sums is 66 − 6 = 60 = 3 · 4 · 5 ✓.

The uvw method uses this: fix two of p, q, r, and an expression that is monotone or convex in the third attains its extreme when two variables are equal or one is zero. It reduces a three-variable inequality to checking the boundary cases b = c and c = 0.

Try it

If p = 5, q = 8 and r = 4, find (a + b)(b + c)(c + a).

Answer. pq − r = 40 − 4 = 36.

Try it

Find a³ + b³ + c³ when p = 3, q = 0 and r = 1.

Answer. 27 − 0 + 3 = 30.

2. Mixing variables, weighted AM-GM and convexity

Mixing. Replacing two variables by values closer together (keeping the sum) increases a product-like expression, so the extreme is at equal values. Weighted AM-GM. To maximise x² y with x + y = 12, split x into two equal parts: x/2, x/2, y has equal terms when x/2 = y, x = 8, y = 4, giving 64 · 4 = 256 (a grid check agrees). Convexity. For convex f, Jensen gives Σ f(xᵢ) ≥ 3f(mean): for 1/x with sum 9 the minimum of Σ 1/x is 3 · 1/3 = 1.

Tangent line trick. To minimise Σ x³ with Σ x = 6, note x³ ≥ 12x − 16 (since x³ − 12x + 16 = (x − 2)²(x + 4)), so Σ x³ ≥ 12 · 6 − 48 = 24 with equality at x = y = z = 2.

Try it

Maximise x · y² for x + y = 9, x, y ≥ 0.

Answer. x = 3, y = 6: 3 · 36 = 108.

Try it

Minimum of 1/x + 1/y + 1/z for x + y + z = 3, all positive?

Answer. 3, at x = y = z = 1.

3. A worked problem

Problem. For positive reals a, b, c with a + b + c = 6, find the minimum of a² + b² + c² and the maximum of ab + bc + ca. Solution. Since (a + b + c)² = Σa² + 2Σab, with the sum fixed at 36, minimising Σa² is the same as maximising Σab. The identity Σa² − Σab = ½Σ(a − b)² ≥ 0 gives Σa² ≥ Σab, so 36 = Σa² + 2Σab ≤ 3Σa²; thus Σa² ≥ 12 and Σab ≤ 12, both at a = b = c = 2.

Check. At a = b = c = 2: Σa² = 12 and Σab = 12 ✓.

4. In the books

Cîrtoaje, ch. 5 (EV-Theorem). The Equal Variable Theorem says that for non-negative numbers with a fixed sum and a fixed sum of pth powers (p ≤ 0 or p > 1) the extreme values of a symmetric expression occur when all but one of the variables are equal, or when one variable is zero. It is the book's version of the uvw idea used in this unit.

Cîrtoaje, ch. 6. The arithmetic and geometric compensation methods replace two variables by their arithmetic or geometric mean and show the expression moves in a fixed direction. This is the “mixing variables” idea.

Pham Kim Hung vol. 1. Ch. 4 covers convex functions and Jensen's inequality, ch. 6 the method of balanced coefficients, and ch. 8.2 to 8.4 the primary symmetric polynomials (p, q, r), normalisation and symmetric separation. Gelca & Andreescu 2.1.6 covers Sturm's principle, another name for mixing.

Problem p8. Real numbers a, b, c have sum 6. What is the largest possible value of ab + bc + ca? (fraction if needed)

HintCompare (a + b + c)² with 3(ab + bc + ca).
Answer12
Method: Inequality

(a + b + c)² − 3(ab + bc + ca) = ½Σ(a − b)² ≥ 0, so ab + bc + ca ≤ 36/3 = 12.

Method: Equal values

The maximum is at a = b = c = 6/3, where the sum of products is 3 · (6/3)² = 12.

Source: Technique from Cîrtoaje ch. 5–6 and Pham Kim Hung ch. 4, 6, 8 (original problem)

Problem p11. For non-negative x, y with x + y = 12, find the maximum of x^1 · y^2. (fraction if needed)

HintSplit x into 1 equal parts and y into 2 equal parts and use AM-GM.
Answer256
Method: Weighted AM-GM

Maximum when x/1 = y/2, i.e. x = 4, y = 8, giving 256.

Method: Calculus

d/dx[x^1 (12 − x)^2] = 0 gives x = 1·12/3 = 4, and the value there is 256.

Source: Technique from Cîrtoaje ch. 5–6 and Pham Kim Hung ch. 4, 6, 8 (original problem)

Problem p15. Positive reals x, y, z satisfy x + y + z = 3. What is the minimum value of x³ + y³ + z³?

HintUse the tangent-line trick or the power mean inequality.
Answer3
Method: Tangent line

For each variable x³ ≥ 3k²x − 2k³ with k = 1 (since x³ − 3k²x + 2k³ = (x − k)²(x + 2k) ≥ 0). Summing: x³ + y³ + z³ ≥ 3k²·3 − 6k³ = 3.

Method: Power mean

By the power mean inequality Σx³ ≥ (Σx)³/9 = 27/9 = 3.

Source: Technique from Cîrtoaje ch. 5–6 and Pham Kim Hung ch. 4, 6, 8 (original problem)

Problem p19. Positive reals x, y, z have sum 6. What is the minimum of 1/x + 1/y + 1/z? (fraction)

HintUse (x + y + z)(1/x + 1/y + 1/z) ≥ 9.
Answer3/2
Method: Cauchy–Schwarz

(x + y + z)(1/x + 1/y + 1/z) ≥ 9, so the sum of reciprocals is at least 9/6 = 3/2.

Method: Equal values

By symmetry and convexity the minimum is at x = y = z = 6/3, giving 3 · 3/6 = 3/2.
