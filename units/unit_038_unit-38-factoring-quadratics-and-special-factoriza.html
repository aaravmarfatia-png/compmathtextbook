1. Factoring quadratics

Factoring rewrites a polynomial as a product. For x² + bx + c look for two numbers with product c and sum b: x² + 7x + 12 = (x + 3)(x + 4) because 3 · 4 = 12 and 3 + 4 = 7. For ax² + bx + c with a ≠ 1, find numbers with product ac and sum b and split the middle term: 6x² + x − 12 has ac = −72 and the numbers 9 and −8 sum to 1, so 6x² + 9x − 8x − 12 = 3x(2x + 3) − 4(2x + 3) = (2x + 3)(3x − 4).

Why factor? A product is zero only if a factor is zero, so factoring solves equations: x² − 5x + 6 = (x − 2)(x − 3) = 0 gives x = 2 or 3. Factoring also simplifies fractions and reveals the sign of an expression.

Always take out a common factor first: 3x² − 12 = 3(x² − 4) = 3(x − 2)(x + 2); x²y − xy² = xy(x − y).

Try it

Factor 2x² + 7x + 3.

Answer. (2x + 1)(x + 3).

2. Special factorizations

Difference of squares: a² − b² = (a − b)(a + b). Mental arithmetic: 2023² − 2022² = 2023 + 2022 = 4045; 1001² − 999² = 2 · 2000 = 4000; 51 · 49 = 50² − 1 = 2499. Cubes: a³ − b³ = (a − b)(a² + ab + b²) and a³ + b³ = (a + b)(a² − ab + b²): x³ − 8 = (x − 2)(x² + 2x + 4), x³ + 27 = (x + 3)(x² − 3x + 9). Perfect cube: x³ − 3x² + 3x − 1 = (x − 1)³.

Repeated differences: x⁴ − 81 = (x² − 9)(x² + 9) = (x − 3)(x + 3)(x² + 9). Sophie Germain: x⁴ + 4 = (x² − 2x + 2)(x² + 2x + 2), obtained by adding and subtracting 4x²: x⁴ + 4x² + 4 − 4x² = (x² + 2)² − (2x)². It shows that 5⁴ + 4 = 629 = 17 · 37 is composite.

Three cubes: a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca). In particular if a + b + c = 0 then a³ + b³ + c³ = 3abc.

Try it

Factor x⁴ − 16 completely over the integers.

Answer. (x² − 4)(x² + 4) = (x − 2)(x + 2)(x² + 4).

3. Grouping and Simon's Favourite Factoring Trick

Grouping. For four terms, group in pairs: xy + 3x + 2y + 6 = x(y + 3) + 2(y + 3) = (x + 2)(y + 3). The trick (SFFT). To solve xy + 3x + 2y = 10 in integers, add 6 to both sides to complete the rectangle: (x + 2)(y + 3) = 16, then list the factor pairs of 16. In general xy + ax + by = c becomes (x + b)(y + a) = c + ab.

Rational roots. For a polynomial with integer coefficients, any rational root p/q (in lowest terms) has p dividing the constant term and q dividing the leading coefficient. For 2x³ − 3x² − 11x + 6 the candidates include ±1, ±2, ±3, ±6, ±1/2, ±3/2; testing shows x = 3, x = −2 and x = 1/2 are roots, so the factorisation is (x − 3)(x + 2)(2x − 1).

Try it

Solve xy − 2x − 3y = 1 in integers.

Answer. Add 6: (x − 3)(y − 2) = 7, so the pairs are (4, 9), (10, 3), (2, −5), (−4, 1).

4. A longer problem

Problem. Factor x⁶ − 1 completely over the integers and use it to show that 1,000,000 − 1 is divisible by 7, 13 and 37.

Solution. x⁶ − 1 = (x³ − 1)(x³ + 1) = (x − 1)(x² + x + 1)(x + 1)(x² − x + 1). With x = 10: (10 − 1)(100 + 10 + 1)(10 + 1)(100 − 10 + 1) = 9 · 111 · 11 · 91 = 999 999, and 91 = 7 · 13, 111 = 3 · 37, so 999 999 = 3³ · 7 · 11 · 13 · 37.

Reflection. A factorisation of a polynomial gives a factorisation of every number obtained by substituting into it. This is the idea behind many divisibility proofs.

5. Mistakes, checks and how to practise

Common mistakes. (1) Forgetting a common factor. (2) Writing a² + b² = (a + b)² (it has no real factorisation as a sum of two squares). (3) Sign errors in the cube factorisations. (4) Stopping before the factorisation is complete.

Checks. Multiply out your answer. Substitute a test value for x (x = 1 and x = 2 are quick).

How to practise. Memorise the special forms. In Unlimited practice, rotate the factoring families.

Problem p1. For how many integers x is x² − 5x − 14 negative?

HintFactor it.
Answer8
Method: Factor

x² − 5x − 14 = (x − 7)(x + 2), which is negative strictly between −2 and 7: x = −1, 0, …, 6, eight integers.

Method: Table

Values at x = −2 and x = 7 are 0, and the parabola opens upwards, so it is negative only between them.

Source: Rusczyk, Art of Problem Solving Vol. 1, ch. 6-7

Problem p6. Find the sum of all real solutions of (x² − 3x)² − 2(x² − 3x) − 8 = 0.

HintLet u = x² − 3x.
Answer6
Method: Substitute

u² − 2u − 8 = (u − 4)(u + 2) = 0. u = 4: x² − 3x − 4 = 0, x = 4 or −1. u = −2: x² − 3x + 2 = 0, x = 1 or 2. Sum 4 − 1 + 1 + 2 = 6.

Each quadratic has root sum 3, and there are two quadratics, so the total is 6.

Problem x19. The roots of x² − 5x + 3 = 0 are r and s. Find r² + s².

HintUse r + s and rs.
Answer19
Method: Vieta

r + s = 5 and rs = 3, so r² + s² = (r + s)² − 2rs = 25 − 6 = 19.

Method: Recurrence

Let pₙ = rⁿ + sⁿ. Then p₀ = 2, p₁ = 5 and p₂ = 5 · p₁ − 3 · p₀ = 25 − 6 = 19.
