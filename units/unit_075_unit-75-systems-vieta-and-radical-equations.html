1. Systems of equations

Two unknowns need two equations. Substitution: solve one for a variable and substitute. Elimination: add multiples of the equations to cancel a variable. Symmetric systems: use sum and product. For x + y = 7 and x² + y² = 25: xy = (49 − 25)/2 = 12, so x and y are the roots of t² − 7t + 12: (3, 4) or (4, 3).

Worked example 1. Solve x + y = 5 and xy = 6: x, y = 2, 3.

Worked example 2. Solve 2x + 3y = 12 and 4x − y = 10. From the second y = 4x − 10, substitute: 2x + 12x − 30 = 12, x = 3, y = 2. Check: 6 + 6 = 12 ✓; 12 − 2 = 10 ✓.

Worked example 3. Solve x/y = 3/2 and x + y = 10: x = 6, y = 4.

2. Radical equations

An equation with square roots is solved by isolating a radical and squaring, then checking for false roots (Unit 24). A nicer method uses substitution.

Worked example 1. Solve √(x + 7) − √(x − 1) = 2. Let a = √(x + 7) and b = √(x − 1). Then a − b = 2 and a² − b² = 8, so a + b = 4, a = 3, b = 1, and x − 1 = 1 gives x = 2. Check: √9 − √1 = 2 ✓.

Worked example 2. Solve √(x² + 9) = x + 1. Square: x² + 9 = x² + 2x + 1, so x = 4. Check: √25 = 5 = 4 + 1 ✓.

Worked example 3. Solve x + √(x + 6) = 6. Isolate: √(x + 6) = 6 − x, square: x + 6 = 36 − 12x + x², so x² − 13x + 30 = 0, x = 3 or 10. Check x = 3: 3 + 3 = 6 ✓. x = 10: 10 + 4 = 14 ✗. Only x = 3.

3. Vieta and symmetric systems

Using Vieta. If x, y are roots of t² − st + p = 0 then x + y = s and xy = p. For the system x + y = 4 and x³ + y³ = 28: x³ + y³ = s³ − 3ps = 64 − 12p = 28, so p = 3, and x, y = 1, 3. Check 1 + 27 = 28 ✓.

Three variables. x + y + z = 6, xy + yz + zx = 11, xyz = 6 have x, y, z as the roots of t³ − 6t² + 11t − 6 = 0, i.e. 1, 2, 3 in some order.

Worked example. Solve xy = 6 and x² + y² = 13 (so (x + y)² = 25, x + y = ±5): x + y = 5 gives (2, 3), (3, 2); x + y = −5 gives (−2, −3), (−3, −2). Four solutions.

4. Mistakes, checks and how to practise

Common mistakes. Squaring without checking. Forgetting the negative sum solutions. Missing the ordered pairs (x, y) versus (y, x). Dividing by a variable that could be zero.

Checks. Substitute every solution into every original equation.

Practice. Isolate one radical at a time.

Worked examples with Try-its: Vieta's formulas

If r and s are the roots of x² − px + q = 0 then r + s = p and rs = q. Everything symmetric in the roots can be found without the roots themselves. For x² − 7x + 3 = 0: r² + s² = (r + s)² − 2rs = 49 − 6 = 43; r³ + s³ = (r + s)³ − 3rs(r + s) = 343 − 63 = 280; 1/r + 1/s = (r + s)/rs = 7/3. For a cubic x³ − ax² + bx − c the roots satisfy sum = a, sum of pairs = b, product = c; x³ − 6x² + 11x − 6 has roots 1, 2, 3.

Try it

If r, s are the roots of x² − 5x + 2 = 0, find r² + s².

Answer. 25 − 4 = 21.

Worked examples with Try-its: Symmetric systems

For x + y = 5 and x² + y² = 13, use xy = ((x + y)² − (x² + y²))/2 = 6, so x and y are the roots of t² − 5t + 6 = 0, that is 2 and 3. The solutions are (2, 3) and (3, 2). Whenever a system is symmetric, introduce s = x + y and p = xy.

Radical equations. To solve √(x + 7) = x − 5, square: x + 7 = x² − 10x + 25, so x² − 11x + 18 = 0 and x = 2 or 9. Squaring can create false roots, so check: x = 9 gives 4 = 4, while x = 2 gives 3 = −3, which fails. The only solution is x = 9.

Try it

Solve √(2x + 1) = x − 1.

Answer. Squaring: x² − 4x = 0, x = 0 or 4; x = 0 fails (1 ≠ −1); x = 4 works (3 = 3).

Worked examples with Try-its: A longer problem

Problem. The numbers a and b satisfy a + b = 6 and ab = 4. Find a³ + b³ and a⁴ + b⁴. Solution. a² + b² = 36 − 8 = 28. a³ + b³ = 216 − 3 · 4 · 6 = 144. a⁴ + b⁴ = (a² + b²)² − 2(ab)² = 784 − 32 = 752.

Reflection. Power sums obey pₙ = s·pₙ₋₁ − q·pₙ₋₂ (here pₙ = 6pₙ₋₁ − 4pₙ₋₂: p₂ = 28, p₃ = 168 − 24 = 144, p₄ = 864 − 112 = 752).
