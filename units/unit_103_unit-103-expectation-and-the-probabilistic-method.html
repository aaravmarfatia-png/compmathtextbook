Sriram, Olympiad Combinatorics, chapter 9: linearity of expectation and using an average to prove existence.

Reading

1. Expected value and linearity

The expected value of a random quantity X taking values x_i with probabilities p_i is E[X] = Σ x_i p_i. A fair die has E = (1 + 2 + … + 6)/6 = 3.5. The key tool is linearity of expectation: E[X + Y] = E[X] + E[Y], always, even when X and Y are dependent.

Worked example 1. The sum of two dice has expectation 3.5 + 3.5 = 7. Example 2. In a random permutation of n objects the expected number of fixed points is n × (1/n) = 1: each position is fixed with probability 1/n, and we add these n indicators.

Example 3. A coin lands heads with probability 1/2. The expected number of tosses until the first head is 2 (since E = 1 + E/2).

2. Indicator variables and the coupon collector

Write a count as a sum of indicator variables (each is 1 if an event occurs, 0 otherwise); then E[count] is the sum of the probabilities of the events.

Coupon collector. With 6 equally likely coupon types, the expected number of draws to collect all six is 6/6 + 6/5 + 6/4 + 6/3 + 6/2 + 6/1 = 6(1 + 1/2 + … + 1/6) = 6 × 49/20 = 14.7. After you have collected j types, the wait for a new type has expectation 6/(6 − j).

Worked example. Among 10 people, the expected number of pairs sharing a birthday (365 days, ignoring leap years) is C(10, 2)/365 = 45/365 ≈ 0.123.

3. The probabilistic method

To prove that an object with some property exists, show that a random object has the property with positive probability, or that a random object has an average above the target, so some object does at least as well.

Worked example (large cut). Colour each vertex of a graph with m edges red or blue at random. An edge is 'cut' (endpoints different colours) with probability 1/2, so the expected number of cut edges is m/2. Hence some colouring cuts at least m/2 edges. No construction needed.

Averaging. If the average score of a class is 70, some student scored at least 70, and some at most 70. Many existence proofs reduce to this.

4. Mistakes, checks and how to practise

Common mistakes. Multiplying expectations of dependent quantities (E[XY] ≠ E[X]E[Y] in general; linearity is only for sums). Forgetting to define the indicator variable carefully. Treating expectation as the most likely value.

Checks. Test on a tiny case you can enumerate (e.g. permutations of 3 objects have average fixed points (3 + 1 + 1 + 0 + 0 + 0)/6 = 1).

Practice. Split every counting expectation into indicators first.

Worked examples with Try-its: Expectation as a tool

If a random object has average value m, some object has value at least m (and some at most m). Cuts. Colour each vertex of a graph red or blue by a fair coin. Each edge is bichromatic with probability 1/2, so the expected number of bichromatic edges is m/2, hence every graph with m edges has a cut of size at least m/2 (for a triangle m/2 = 1.5 and the best cut is 2). Cycles. The expected number of cycles in a random permutation of n objects is 1 + 1/2 + … + 1/n, which for n = 4 is 25/12 (checked by averaging over all 24 permutations).

Try it

A random permutation of 3 objects: what is the expected number of cycles?

Answer. 1 + 1/2 + 1/3 = 11/6.

Worked examples with Try-its: The probabilistic method

To prove an object with some property exists, show that a random object has the property with positive probability. For example, if the expected number of 'bad' features is below 1 then some object has no bad feature at all. The method is non-constructive: it tells you the object exists, not how to find it.

Try it

A random 2-colouring of the points 1 to 10 is chosen. What is the expected number of adjacent pairs (k, k + 1) with the same colour?

Answer. 9 pairs, each with probability 1/2: 4.5.

Worked examples with Try-its: A longer problem

Problem. Five people sit at random in a row of 5 seats, each person having one reserved seat. What is the expected number in the correct seat? Solution. Each person is correct with probability 1/5, so the expectation is 5 · 1/5 = 1, regardless of dependence.

Reflection. Linearity of expectation needs no independence.

More worked examples: Worked examples

Coupon collector. To collect all 3 coupon types the expected number of draws is 3(1 + 1/2 + 1/3) = 11/2. Runs. In 10 fair coin tosses the expected number of runs (maximal blocks of equal results) is 1 + 9/2 = 11/2, since each of the 9 adjacent pairs begins a new run with probability 1/2 (an average over all 1024 sequences confirms it). Average argument. If the average of a set of numbers is 5.5, some number is at least 5.5.

Try it

A fair die is rolled 12 times. What is the expected number of 6s?

Answer. 2.

Try it

What is the expected number of heads before the first tail with a fair coin?

Answer. 1.

More worked examples: A second longer problem

Problem. Show that some 2-colouring of the edges of K₄ has at most 1 monochromatic triangle. Solution. A random colouring makes each of the 4 triangles monochromatic with probability 2/8 = 1/4, so the expected number is 1; hence some colouring has at most 1 monochromatic triangle.

Reflection. The average is 1, so some colouring is at or below 1.

Problem p1. A random arrangement of 10 distinct objects is made. What is the expected number of objects in their original position?

HintIndicator for each object.
Answer1
Method: Linearity

Each object is in place with probability 1/10, so the expected number is 10 · 1/10 = 1.

Method: Small case

For 3 objects the counts over the 6 arrangements are 3, 1, 1, 1, 1, 0, with mean 1.

Problem p2. A fair coin is flipped 10 times. A run is a maximal block of equal results. What is the expected number of runs, as a fraction?

HintCount the places where the result changes, plus 1.
Answer11/2
Method: Indicators

There are 9 adjacent pairs and each differs with probability 1/2, so the expected number of changes is 9/2 and the runs number 1 + 9/2 = 11/2.

Method: Small case

For 2 flips the run counts are 1, 2, 2, 1 with mean 3/2 = 1 + 1/2.

Problem p4. A graph has 10 edges. Each vertex is coloured red or blue independently with probability 1/2. What is the expected number of edges with endpoints of different colours?

Problem p5. Two fair dice are rolled. What is the expected value of the larger of the two numbers, as a fraction?

HintCount the outcomes for each maximum.
Answer161/36
Method: Distribution

The maximum is k in 2k − 1 of the 36 outcomes, so E = Σ k(2k − 1)/36 = (1 + 6 + 15 + 28 + 45 + 66)/36 = 161/36.

Method: Complement

E[max] + E[min] = 7, and E[min] = 91/36, so E[max] = 252/36 − 91/36 = 161/36.

Source: Sriram, Olympiad Combinatorics, ch. 9 (The Probabilistic Method)

Problem p6. A standard deck has 52 cards including 4 aces. The cards are dealt in random order. What is the expected position of the first ace, as a fraction?

HintThe 4 aces split the other 48 cards into 5 gaps.
Answer53/5
Method: Gaps

Each of the 48 non-aces is before all aces with probability 1/5, so the expected number before the first ace is 48/5 and the position is 48/5 + 1 = 53/5.

Method: Check

This equals (52 + 1)/(4 + 1) = 53/5.

Problem x18. Two fair dice are rolled. Find the probability that the sum is 11.

HintCount the favourable outcomes out of 36.
Answer1/18
Method: Count

The pairs are (5, 6), (6, 5): 2 outcomes out of 36, so the probability is 1/18.

Method: Symmetry

The sums s and 14 − s are equally likely, so sum 11 has the same count as sum 3, namely 2 outcomes, giving 1/18.
