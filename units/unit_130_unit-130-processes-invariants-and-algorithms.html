Reading

1. Invariants

In a process (a game, a repeated operation), an invariant is a quantity that never changes; it can prove that a target state is unreachable. Common invariants: parity, a sum mod k, a product, a colouring count.

Worked example 1. Start with 1, 2, 3, 4. Repeatedly replace two numbers a, b by a + b + ab. Since a + b + ab + 1 = (a + 1)(b + 1), the product of all (number + 1) is invariant. Initially it is 2 × 3 × 4 × 5 = 120, so the final single number is 119 whatever the order (checked on all 24 orders).

Worked example 2. A 7 × 9 rectangle cannot be tiled by dominoes, because it has 63 squares, an odd number, and each domino covers 2.

2. Monovariants and termination

A monovariant is a quantity that always moves in one direction (always decreases, say) and takes values in a set that cannot decrease forever (non-negative integers). It proves that a process ends.

Worked example. Euclid's algorithm terminates because the remainder strictly decreases: gcd(1071, 462): 1071 = 2 × 462 + 147; 462 = 3 × 147 + 21; 147 = 7 × 21. So gcd = 21.

Another. When you repeatedly swap an adjacent pair that is out of order, the number of inverted pairs drops by exactly 1 each time, so the sorting ends after at most C(n, 2) swaps.

3. Designing algorithms

For an algorithm to be correct you need: a clear step, an invariant that is maintained, and a measure of progress that guarantees termination. After the algorithm halts, the invariant plus the stopping condition should give the result.

Worked example (binary exponentiation). To compute 3¹³: 13 = 1101 in binary, so square-and-multiply needs about 3 squarings and 2 multiplications rather than 12 multiplications: 3 → 3² = 9 → 3³ = 27 → 27² = 729 = 3⁶ → 3¹² = 531441 → ×3 = 3¹³ = 1,594,323. In the invariant form result × base^exp stays equal to 3¹³.

Strategy games. A winning strategy often keeps an invariant that the opponent cannot preserve, such as 'after my move the pile size is divisible by 4'.

4. Mistakes, checks and how to practise

Common mistakes. Choosing an invariant that is not actually preserved by every move. Proving termination without showing the quantity cannot decrease forever. Checking only one sample run.

Checks. Test the invariant on each possible type of move.

Practice. Simulate the first few steps and tabulate candidate invariants.

Worked examples with Try-its: Invariants

An invariant is a quantity that does not change under the allowed moves. Write 1, 2, …, 10 on a board; repeatedly erase two numbers and write their difference. The parity of the total sum never changes (a + b and |a − b| have the same parity), and the sum starts as 55, which is odd, so the last number left is odd (a random simulation of 300 such games agrees). Other invariants: the gcd under the Euclidean moves, the colour counts on a chessboard, and the sum modulo n.

Try it

A board has 1, 2, 3, 4, 5. A move replaces two numbers a, b by a + b. What is the last number?

Answer. 15, the sum is invariant.

Worked examples with Try-its: Monovariants and termination

A monovariant is a quantity that always moves in one direction, such as a non-negative integer that strictly decreases. It proves that a process must stop. In sorting by swaps of out-of-order neighbours, the number of inversions drops by one at each swap, so the process ends after at most C(n, 2) swaps.

Try it

Why must a process stop if each move strictly decreases a non-negative integer?

Answer. A non-negative integer cannot decrease forever.

Worked examples with Try-its: A longer problem

Problem. A board shows the numbers 1, 2, …, 10. A move erases two numbers a, b and writes a + b − 1. What number is left after 9 moves? Solution. The quantity (sum − number of entries) is invariant: each move removes a + b and adds a + b − 1 (sum drops by 1) while the count drops by 1. Initially 55 − 10 = 45; at the end the one number x satisfies x − 1 = 45, so x = 46.

Reflection. Search for a combination of the sum and the count that stays fixed.

More worked examples: Worked examples

Product invariant. A board holds 1, 2, 3. A move erases two numbers a, b and writes ab + a + b. Then (a + 1)(b + 1) = ab + a + b + 1, so the product of (each number + 1) never changes: it is 2 · 3 · 4 = 24 at the start, so the final number N satisfies N + 1 = 24 and N = 23. A program that plays all move orders gives 23 every time.

Try it

A move replaces a and b by a + b + ab. Starting from 1, 1, 1, what is the last number?

Answer. (2)(2)(2) = 8, so 7.

Try it

If a sum is invariant under a move, can the sum change after 10 moves?

Answer. No.

More worked examples: A second longer problem

Problem. The numbers 1, 2, …, 10 are written down. A move erases a and b and writes a + b + ab. What is the final number? Solution. The product of (number + 1) is invariant, so the final number plus 1 equals 2 · 3 · … · 11 = 11!, and the final number is 11! − 1 = 39916799.

Check. 11! = 39916800.

Problem p1. 41 people stand in a circle numbered 1 to 41. Starting at person 1, every second person is removed (2, 4, 6, …) going round and round until one is left. Who survives?

HintLook at how the answer changes from n to n + 1.
Answer19
Method: Formula

Write n = 2^m + L with 0 ≤ L < 2^m. Here 41 = 32 + 9, and the survivor is 2L + 1 = 19.

Method: Binary

In binary 41 is 101001. Moving the leading 1 to the end gives 010011, which is 19.

Problem p4. In the Tower of Hanoi with 7 discs, what is the least number of moves needed to transfer the whole tower to another peg?

HintMove the top n − 1 discs, then the largest disc, then the n − 1 discs again.
Answer127
Method: Recurrence

T(n) = 2T(n − 1) + 1 with T(1) = 1 gives 1, 3, 7, 15, …, so T(7) = 2^7 − 1 = 127.

Method: Binary counting

Each move corresponds to a step of a binary counter with 7 bits, which takes 2^7 − 1 = 127 steps to go from all zeros to all ones.

Problem p6. The numbers 1, 2, …, 5 are written on a board. A move replaces two numbers a and b by a + b + ab. After 4 moves one number remains. What is it?

HintFind a quantity that never changes.
Answer719
Method: Invariant

(a + 1)(b + 1) = a + b + ab + 1, so the product of all (number + 1) never changes. At the start it is (5 + 1)! = 720, so the final number is 719.

Method: Small case

With 1, 2 the result is 1 + 2 + 2 = 5 = 3! − 1, and with 1, 2, 3: combining 5 and 3 gives 5 + 3 + 15 = 23 = 4! − 1. The pattern gives 719.

Problem p9. Bubble sort repeatedly swaps adjacent out-of-order entries. How many swaps does it take to sort 3, 1, 4, 2, 5 into increasing order?

HintEach swap removes exactly one inversion.
Answer3
Method: Count inversions

A swap fixes exactly one pair that is out of order, so the number of swaps equals the number of inversions: 3.

Method: Simulate

Carrying out the sorting passes gives 3 swaps in total.

Problem p12. How many division steps does Euclid's algorithm need to find gcd(89, 55)?

HintWrite out the remainders.
Answer9
Method: Run it

The remainders are 89, 55, 34, 21, 13, 8, 5, 3, 2, 1, 0, ending at 0 after 9 steps.

Method: Fibonacci

Consecutive Fibonacci numbers are the worst case: each step moves down one Fibonacci number, and 89 is F_11, so there are 9 steps.

Problem p18. There are 100 lamps, all off. For each k from 1 to 100, a person toggles every k-th lamp (k, 2k, 3k, …). How many lamps are on at the end?

HintLamp m is toggled once for each divisor of m.
Answer10
Method: Divisors

A lamp ends on exactly when its number has an odd number of divisors, which happens only for perfect squares. There are ⌊√100⌋ = 10 squares up to 100.

Method: Pairing

Divisors pair as (d, m/d), so the count is even unless d = m/d for some d, i.e. m is a square: 10 squares.

Source: Sriram ch. 3
