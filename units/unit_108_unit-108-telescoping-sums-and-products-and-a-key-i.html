Reading

1. The telescoping idea

A sum telescopes when each term can be written as a difference f(k) − f(k + 1), so that the middle terms cancel and Σ_{k=1}^{n} [f(k) − f(k+1)] = f(1) − f(n+1). The art lies in finding f.

Worked example 1. 1/(k(k+1)) = 1/k − 1/(k+1). So Σ_{k=1}^{99} 1/(k(k+1)) = 1 − 1/100 = 99/100.

Worked example 2. 1/(√k + √(k+1)) = √(k+1) − √k (multiply top and bottom by √(k+1) − √k). Then Σ_{k=1}^{99} = √100 − √1 = 9.

Worked example 3. k · k! = (k + 1)! − k!. So Σ_{k=1}^{5} k · k! = 6! − 1! = 719; directly 1 + 4 + 18 + 96 + 600 = 719 ✓.

2. Telescoping products

A product telescopes when each factor is a ratio g(k+1)/g(k) or when factors factor into pieces that cancel with neighbours. The classic: 1 − 1/k² = (k − 1)(k + 1)/k², so Π_{k=2}^{n} (1 − 1/k²) = (n + 1)/(2n). For n = 10 this is 11/20 = 0.55 ✓ (checked by multiplying all nine factors).

Worked example. Π_{k=1}^{n} (1 + 1/k) = Π (k + 1)/k = n + 1. For n = 99 the product is 100.

Key identity for sums. Differences of consecutive values of a polynomial give polynomial sums; for example (k + 1)³ − k³ = 3k² + 3k + 1 produces the formula for Σk² when summed from 1 to n and solved for the unknown.

3. Finding the telescoping form

Partial fractions. 1/(k(k + 2)) = ½(1/k − 1/(k + 2)). The terms cancel with a gap of 2, so Σ_{k=1}^{n} leaves ½(1 + ½ − 1/(n+1) − 1/(n+2)).

Worked example. Σ_{k=1}^{98} 1/(k(k + 2)) = ½(1 + ½ − 1/99 − 1/100) = ½(3/2 − 199/9900) = ½ × 14,651/9,900 = 14,651/19,800, which is about 0.7400.

Factorial form. 1/(k(k + 1)(k + 2)) = ½[1/(k(k+1)) − 1/((k+1)(k+2))].

4. Mistakes, checks and how to practise

Common mistakes. Cancelling the wrong terms when the gap is larger than 1. Forgetting the constant factor (such as ½). Mixing up how many terms survive.

Checks. Test the closed form with n = 1 and n = 2.

Practice. Write out the first four and last four terms before simplifying.

Worked examples with Try-its: Telescoping sums

A sum telescopes when each term cancels part of the next. Since 1/(k(k + 2)) = ½(1/k − 1/(k + 2)), the sum from k = 1 to 10 is ½(1 + 1/2 − 1/11 − 1/12) = 175/264. Another classic: k · k! = (k + 1)! − k!, so 1·1! + 2·2! + … + 5·5! = 6! − 1 = 719.

Try it

Evaluate 1/(1·2) + 1/(2·3) + … + 1/(99·100).

Answer. 1 − 1/100 = 99/100.

Worked examples with Try-its: Telescoping products

∏ (1 − 1/k²) from k = 2 to n factors as ∏ (k − 1)(k + 1)/k² = (n + 1)/(2n), so for n = 10 the product is 11/20. A key identity: a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca).

Try it

Evaluate (1 − 1/4)(1 − 1/9)(1 − 1/16).

Answer. (3/4)(8/9)(15/16) = 5/8.

Worked examples with Try-its: A longer problem

Problem. Show that 1/√1 + 1/√2 + … + 1/√n > 2(√(n + 1) − 1). Solution. Since √(k + 1) − √k = 1/(√(k + 1) + √k) < 1/(2√k), so 1/√k > 2(√(k + 1) − √k) and Σ₁ⁿ 1/√k > 2(√(n + 1) − 1).

Reflection. Replace each term by a larger or smaller telescoping one to bound a sum.

More worked examples: Worked examples

Three consecutive factors. 1/(k(k + 1)(k + 2)) = ½[1/(k(k + 1)) − 1/((k + 1)(k + 2))], so the sum for k = 1 to n is ½[1/2 − 1/((n + 1)(n + 2))]; for n = 3 this is ½(1/2 − 1/20) = 9/40. Product. ∏(1 + 1/k) for k = 1 to 9 is (2/1)(3/2)…(10/9) = 10.

Try it

Evaluate 1/(1 · 3) + 1/(3 · 5) + 1/(5 · 7).

Answer. ½(1 − 1/7) = 3/7.

Try it

Evaluate (1 − 1/2)(1 − 1/3)(1 − 1/4)(1 − 1/5).

Answer. 1/5.

More worked examples: A second longer problem

Problem. Evaluate Σ_{k=1}^{99} 1/(√k + √(k + 1)). Solution. Rationalising, 1/(√k + √(k + 1)) = √(k + 1) − √k, so the sum telescopes to √100 − √1 = 9.

Check. The first two terms: (√2 − 1) + (√3 − √2) = √3 − 1.

Practice problems (25)

Problem p1. Find Σ_{k=1}^{50} 1/(k(k + 2)) as a fraction.

Hint1/(k(k + 2)) = (1/2)(1/k − 1/(k + 2)).
Answer3875/5304
Method: Telescoping

The sum is (1/2)(1 + 1/2 − 1/51 − 1/52). Now 1/51 + 1/52 = 103/2652 and 3/2 = 3978/2652, so the sum is (1/2)(3875/2652) = 3875/5304.

Method: Check

Numerically the sum is about 0.7306, matching 3875/5304.

Source: Andreescu & Gelca, 2.3-2.4

Problem p2. Find the product (1 − 1/2²)(1 − 1/3²)⋯(1 − 1/20²) as a fraction.

Hint1 − 1/k² = (k − 1)(k + 1)/k².
Answer21/40
Method: Telescoping

The product is (1/2)(3/2) · (2/3)(4/3) ⋯ which collapses to (1/2)(21/20) = 21/40.

Method: Formula

The product up to n is (n + 1)/(2n); with n = 20 this is 21/40.

Source: Andreescu & Gelca, 2.3-2.4

Problem p8. If a + b + c = 6 and ab + bc + ca = 11, find a³ + b³ + c³ − 3abc.

HintUse the identity.
Answer18
Method: Identity

a² + b² + c² = 36 − 22 = 14, so the expression is 6(14 − 11) = 18.

Method: Example

a, b, c = 1, 2, 3 satisfy the conditions and 1 + 8 + 27 − 18 = 18.

Problem p9. Evaluate 1/(1·2) + 1/(2·3) + … + 1/(99·100).

Hint1/(n(n+1)) = 1/n − 1/(n+1).
Answer99/100
Method: Telescoping

The sum is (1 − 1/2) + (1/2 − 1/3) + … + (1/99 − 1/100) = 1 − 1/100 = 99/100.

Method: Small cases

For n up to 1, 2, 3 the sums are 1/2, 2/3, 3/4, so for n up to 99 it is 99/100.
