1. Solving functional equations

A functional equation describes a function by a property it satisfies. The skills are substitution and pattern recognition. Example 1. If f(2x + 1) = x², put t = 2x + 1, so x = (t − 1)/2 and f(t) = ((t − 1)/2)²; hence f(5) = 4. Example 2. If f is linear with f(f(x)) = 4x + 3, write f(x) = ax + b: then a²x + ab + b = 4x + 3, so a² = 4 and b(a + 1) = 3: (a, b) = (2, 1) or (−2, −3) (solved by computer algebra as a check).

Example 3 (a system of two unknown values). If f(x) + 2f(1/x) = 3x for all x ≠ 0, replace x by 1/x to get f(1/x) + 2f(x) = 3/x. Solving the two equations as a linear system in f(x) and f(1/x): f(x) = 2/x − x. Check: f(2) + 2f(1/2) = (1 − 2) + 2(4 − 1/2) = −1 + 7 = 6 = 3 · 2 ✓.

Example 4 (recursion). If f(x + 1) = f(x) + 2x + 1 and f(0) = 0, then f(n) = n², since the increments 1, 3, 5, … sum to a square: f(100) = 10 000.

Try it

If f(x + y) = f(x) + f(y) for all integers and f(1) = 3, find f(10).

Answer. f(n) = 3n by repeated addition, so 30.

2. Standard types

Additive (Cauchy): f(x + y) = f(x) + f(y). On the integers (and rationals) this forces f(x) = cx with c = f(1). Multiplicative: f(x + y) = f(x)f(y) with f(1) = 2 gives f(n) = 2ⁿ, so f(5) = 32. Logarithmic: f(xy) = f(x) + f(y) with f(2) = 1 gives f(8) = 3. Periodic: if f(x + 3) = f(x) and f(1) = 5 then f(100) = f(1) = 5 since 100 ≡ 1 (mod 3).

Symmetric: f(x) + f(1 − x) = 1 gives f(1/2) = 1/2 by taking x = 1/2.

Strategy. (1) Try special values x = 0, 1, −1. (2) Try to prove injectivity or surjectivity. (3) Guess a family (linear, power, exponential) and check which parameters fit. (4) Always verify the final answer in the original equation.

Try it

If f(xy) = f(x) + f(y) and f(3) = 5, find f(81).

Answer. f(81) = f(3⁴) = 4 f(3) = 20.

3. A longer problem

Problem. Find all functions f with f(x) + 3f(−x) = 4x + 8 for all real x, and find f(2).

Solution. Replace x by −x: f(−x) + 3f(x) = −4x + 8. Multiply the first equation by 3: 3f(x) + 9f(−x) = 12x + 24. Subtract the second: 8f(−x) = 16x + 16, so f(−x) = 2x + 2 and f(x) = −2x + 2. Check: f(x) + 3f(−x) = (−2x + 2) + 3(2x + 2) = 4x + 8 ✓. So f(2) = −2.

Reflection. The substitution x → −x doubled the number of equations; then ordinary elimination finished the job.

4. Mistakes, checks and how to practise

Common mistakes. (1) Assuming f is linear without proof. (2) Not checking the answer in the original equation. (3) Substituting a value outside the domain. (4) Dividing by f(x) when it can be zero.

Checks. Verify with two or three numerical values.

How to practise. Collect the standard types. In Unlimited practice, rotate the functional-equation families.

More worked examples: Worked examples

Substitution trick. Solve f(x) + 2f(1/x) = x for x ≠ 0. Replace x by 1/x: f(1/x) + 2f(x) = 1/x. Multiply this by 2 and subtract the original: 3f(x) = 2/x − x, so f(x) = (2/x − x)/3. Check at x = 2: f(2) = −1/3, f(1/2) = 7/6, and −1/3 + 2 · 7/6 = 2 ✓. Cauchy's equation. If f(x + y) = f(x) + f(y) for all integers and f(1) = 3 then f(n) = 3n by induction, so f(5) = 15.

Try it

If f(x + 1) = f(x) + 2 and f(0) = 1, find f(10).

Answer. 21.

Try it

If f(xy) = f(x) + f(y) for positive reals and f(2) = 1, find f(8).

Answer. f(8) = 3f(2) = 3.

More worked examples: A second longer problem

Problem. Does a function f: ℝ → ℝ exist with f(x) + f(1 − x) = x for all x? Solution. Replace x by 1 − x: f(1 − x) + f(x) = 1 − x. The left sides are equal, so x = 1 − x for every x, which is false (for example at x = 0). No such function exists.

Reflection. Substituting x ↦ 1 − x can reveal that the conditions contradict each other; the same substitution with right side 1 gives f(x) = 1/2 as a valid solution when the sum is the constant 1.

Problem p1. If f(x) + 2f(1/x) = 3x for all x ≠ 0, find f(2) as a fraction.

HintAlso use x = 1/2.
Answer-1
Method: Two equations

x = 2: f(2) + 2f(1/2) = 6. x = 1/2: f(1/2) + 2f(2) = 3/2. Multiply the second by 2: 2f(1/2) + 4f(2) = 3. Subtract the first equation: 3f(2) = 3 − 6 = −3, so f(2) = −1.

Method: General solution

Solving the pair for all x gives f(x) = 2/x − x. At x = 2 this is 1 − 2 = −1.
