Reading

1. Fractional and negative exponents

You already know that aⁿ means 'multiply a by itself n times', and that aᵐ · aⁿ = aᵐ⁺ⁿ. The idea of this unit is to extend powers to exponents that are not positive whole numbers in such a way that this law keeps working. Suppose a^(1/2) exists and obeys the law: then a^(1/2) · a^(1/2) = a¹ = a, so a^(1/2) must be a number whose square is a: the square root. In the same way a^(1/3) · a^(1/3) · a^(1/3) = a, so a^(1/3) is the cube root. In general a^(1/n) = ⁿ√a.

For a general fraction, a^(m/n) = (ⁿ√a)ᵐ = ⁿ√(aᵐ): take the root and the power in either order. For example 8^(2/3) = (∛8)² = 2² = 4, and 100^(3/2) = (√100)³ = 10³ = 1000. A negative exponent means 'take the reciprocal': a⁻ⁿ = 1/aⁿ, so 16^(−3/4) = 1/16^(3/4) = 1/(⁴√16)³ = 1/2³ = 1/8, and (1/4)^(−3/2) = 4^(3/2) = 8. Exponent zero gives 1 for any non-zero a, because aⁿ/aⁿ = a⁰ = 1.

Why only positive bases? For a > 0 these powers are always defined and always positive. For a negative base there are problems: (−8)^(1/3) can be taken as −2 but (−4)^(1/2) has no real value, and the law (a^(1/2))² = a breaks. So when working with fractional exponents in this unit, assume the base is positive unless told otherwise.

Worked example 1. Compute 2^(1/2) · 2^(3/2): the exponents add, ½ + 3/2 = 2, so the result is 2² = 4. Worked example 2. Simplify (8/27)^(2/3): (∛(8/27))² = (2/3)² = 4/9. Worked example 3. 32^(−1/5) = 1/32^(1/5) = 1/2. Notice that taking the root first keeps the numbers small, which is the habit to build.

Try it

Evaluate 27^(2/3), 9^(−1/2) and 4^(3/2) · 8^(−1/3).

Answer. 27^(2/3) = (∛27)² = 9. 9^(−1/2) = 1/3. 4^(3/2) = 8 and 8^(−1/3) = 1/2, so the product is 4.

2. Laws of exponents with fractions

All the laws you know continue to hold for positive bases and any real exponents: aˣ · aʸ = aˣ⁺ʸ; aˣ / aʸ = aˣ⁻ʸ; (aˣ)ʸ = aˣʸ; (ab)ˣ = aˣbˣ; (a/b)ˣ = aˣ/bˣ. Combined with root notation these let you simplify any expression. For instance √a · ∛a = a^(1/2) · a^(1/3) = a^(5/6) = ⁶√(a⁵), and ⁴√(a³)/√a = a^(3/4 − 1/2) = a^(1/4).

Worked example (rationalising with powers). Simplify 6/∛2. Write ∛2 = 2^(1/3) and multiply top and bottom by 2^(2/3) so that the denominator becomes 2: 6 · 2^(2/3)/2 = 3 · 2^(2/3) = 3∛4. Check numerically: 6/1.2599 = 4.762 and 3 × 1.5874 = 4.762 ✓.

Worked example (equal bases). Solve 4^x = 8. Write both with base 2: 2^(2x) = 2³, so 2x = 3, x = 3/2. Solve 9^x = 27^(x − 1): 3^(2x) = 3^(3x − 3), so 2x = 3x − 3, x = 3. When the bases are powers of the same number, equate the exponents.

Which is bigger? To compare numbers like 2^(1/2) and 3^(1/3), raise both to a common power that clears the fractions, here 6: (2^(1/2))⁶ = 2³ = 8 and (3^(1/3))⁶ = 3² = 9, so 3^(1/3) is larger (1.442 against 1.414). Raising to a positive power preserves order for positive numbers, so this is legitimate.

Try it

Solve 8^x = 1/4.

Answer. 8 = 2³ and 1/4 = 2⁻², so 3x = −2 and x = −2/3.

3. The rules of inequalities

An inequality says one quantity is bigger than another: a > b means a − b is positive. The rules mirror those for equations with one crucial exception. (1) You may add or subtract the same number on both sides: a > b ⇒ a + c > b + c. (2) You may multiply or divide by a positive number. (3) If you multiply or divide by a negative number, the inequality reverses: 3 < 5 but −3 > −5. (4) You may add two inequalities pointing the same way: a > b and c > d give a + c > b + d. (5) You may not subtract or divide inequalities that way.

Reciprocals. For positive numbers, a > b implies 1/a < 1/b: 2 < 5 and 1/2 > 1/5. For numbers of opposite signs the rule is different: −2 < 5 but 1/(−2) is also less than 1/5; so always check signs. Squaring. If a > b ≥ 0 then a² > b². But if negatives are allowed this fails: −5 < 3 but 25 > 9. This is the most common source of errors: squaring is order-preserving only on non-negative numbers.

Worked example (linear). Solve 3 − 2x ≥ 11. Subtract 3: −2x ≥ 8. Divide by −2 and reverse: x ≤ −4. Check x = −5: 3 + 10 = 13 ≥ 11 ✓; check x = 0: 3 ≥ 11 is false ✓. Worked example (compound). Solve −3 < 2x + 1 ≤ 7: subtract 1: −4 < 2x ≤ 6; divide by 2: −2 < x ≤ 3.

Chains. To show x > z it is enough to show x > y and y > z. Finding a convenient middle number y is one of the most useful tricks: to show 7/15 < 8/17 observe 7/15 < 1/2 (since 14 < 15) and 8/17 < 1/2 as well, which does not help; try instead cross-multiplying positive fractions: 7 × 17 = 119 and 8 × 15 = 120, so 7/15 < 8/17.

Try it

Solve (x − 1)/3 > (x + 2)/5.

Answer. Multiply by 15: 5(x − 1) > 3(x + 2), so 5x − 5 > 3x + 6, 2x > 11, x > 5.5.

4. Proving inequalities: the difference method

To prove a ≥ b, show that a − b ≥ 0. Usually you manipulate a − b into a form that is visibly non-negative, most often a sum of squares. The central fact: x² ≥ 0 for every real x, with equality only when x = 0. Everything in the next two units grows from it.

Worked example 1. Prove a² + b² ≥ 2ab. The difference a² + b² − 2ab = (a − b)² ≥ 0. Equality holds exactly when a = b. Example 2. Prove a² + b² + c² ≥ ab + bc + ca. The difference equals ½[(a − b)² + (b − c)² + (c − a)²] ≥ 0, with equality only when a = b = c. (Expand to see: ½[2a² + 2b² + 2c² − 2ab − 2bc − 2ca] ✓.) Example 3. For positive a and b, a/b + b/a ≥ 2, because a/b + b/a − 2 = (a − b)²/(ab) ≥ 0.

Worked example 4 (a numerical comparison). Which is larger, √2 + √3 or √10? Both are positive, so compare their squares: (√2 + √3)² = 5 + 2√6 and (√10)² = 10. Compare 2√6 with 5: squaring gives 24 and 25, so 2√6 < 5, hence √2 + √3 < √10. (Numerically 3.146 < 3.162 ✓.) The rule: squaring is legitimate when both sides are non-negative.

Strategy. (1) Move everything to one side. (2) Look for a perfect square or a sum of squares. (3) State when equality occurs. (4) If the expression does not obviously factor, try completing the square. Always say where equality holds; olympiad problems often ask for it.

Try it

Prove that x² + 1 ≥ 2x for all real x, and say when equality holds.

Answer. x² + 1 − 2x = (x − 1)² ≥ 0. Equality exactly when x = 1.

5. Comparing powers and roots

Comparing numbers such as 2¹⁰⁰ and 3⁵⁰ is a typical task: reduce to the same exponent. 2¹⁰⁰ = (2²)⁵⁰ = 4⁵⁰ > 3⁵⁰. Comparing 5^(1/5) and 4^(1/4): raise both to the 20th power, which is a common multiple of the denominators, giving 5⁴ = 625 and 4⁵ = 1024, so 4^(1/4) is larger. In general the sequence n^(1/n) increases up to n = 3 and then decreases: 1, 1.414, 1.442, 1.414, 1.380, …

Worked example. Which is larger, 3²⁰⁰ or 2³⁰⁰? Write 3²⁰⁰ = (3²)¹⁰⁰ = 9¹⁰⁰ and 2³⁰⁰ = (2³)¹⁰⁰ = 8¹⁰⁰. Since 9 > 8, 3²⁰⁰ is larger. The trick is to find the highest common factor of the exponents (here 100) and compare the bases after removing it.

Estimates. A useful bound: √(n + 1) − √n = 1/(√(n + 1) + √n) < 1/(2√n). For n = 100 the left side is √101 − 10 ≈ 0.04988 and the right side is 0.05 ✓. Such estimates are used to show that sums like 1 + 1/√2 + … + 1/√n grow without bound, or to bracket values between two whole numbers.

Worked example (bracketing). Show that 10 < √98 + √2 < 12. Since √98 = 7√2, the sum is 8√2 ≈ 11.31 ✓ (and 8√2 > 10 since 128 > 100; 8√2 < 12 since 128 < 144). Squaring is again the justification.

Try it

Compare 7^(1/7) with 3^(1/3) using a common power, then say which is larger.

Answer. Raise both to the 21st power: 7³ = 343 and 3⁷ = 2187, so 3^(1/3) is larger.

6. Equations with fractional powers and absolute values

Equations containing fractional exponents are solved by undoing the power: raise both sides to the reciprocal exponent, taking care with positivity. Worked example 1. Solve x^(3/2) = 27 for x > 0. Raise both sides to the power 2/3: x = 27^(2/3) = (∛27)² = 9. Check: 9^(3/2) = (√9)³ = 27 ✓. Worked example 2 (a hidden quadratic). Solve x^(1/2) − 3x^(1/4) + 2 = 0. Put u = x^(1/4), so x^(1/2) = u²: u² − 3u + 2 = 0, giving u = 1 or u = 2, hence x = 1 or x = 2⁴ = 16. Check x = 16: 4 − 3 × 2 + 2 = 0 ✓ and x = 1: 1 − 3 + 2 = 0 ✓. Worked example 3 (exponent equations). Solve 2^(x + 1) + 2^x = 24. Factor 2^x: 2^x(2 + 1) = 24, so 2^x = 8 and x = 3.

Absolute value inequalities. The absolute value |a| is the distance of a from 0 on the number line. Then |x − 3| < 2 means 'x is within 2 of 3', i.e. 1 < x < 5. And |2x + 1| ≥ 5 means 2x + 1 ≥ 5 or 2x + 1 ≤ −5, so x ≥ 2 or x ≤ −3 (a 'greater than' condition splits into two outer pieces, a 'less than' condition gives one piece between). Check x = 2: |5| = 5 ≥ 5 ✓; x = −3: |−5| = 5 ✓; x = 0: |1| = 1 is not ≥ 5 ✓.

Interval notation. The solution 1 < x < 5 can be written (1, 5) with round brackets for excluded end-points, and −2 ≤ x ≤ 3 as [−2, 3] with square brackets for included ones. The two outer pieces x ≤ −3 or x ≥ 2 are written (−∞, −3] ∪ [2, ∞), where ∪ means 'together with'.

Try it

Solve |x + 1| ≤ 3 and 9^x = 3^(x + 2).

Answer. |x + 1| ≤ 3 means −4 ≤ x ≤ 2. For the second: 3^(2x) = 3^(x + 2), so 2x = x + 2 and x = 2.

7. A longer problem

Problem. Show that for positive numbers x, y the inequality (x + y)(1/x + 1/y) ≥ 4 holds, and find when equality occurs. Then use it to show that a number and its reciprocal always add to at least 2.

Solution. Expand: (x + y)(1/x + 1/y) = 1 + y/x + x/y + 1 = 2 + (x/y + y/x). From the earlier result x/y + y/x ≥ 2 (difference method), the whole is at least 4, with equality exactly when x = y. For the second part apply a/b + b/a ≥ 2 with a = x and b = 1: x + 1/x ≥ 2 for x > 0, equality at x = 1. Check with x = 3: 3 + 1/3 = 3.33 ≥ 2 ✓, and with x = 1/2: 0.5 + 2 = 2.5 ≥ 2 ✓.

Reflection. The key was to turn a product of sums into a sum of simple terms and recognise a pair a/b + b/a that is known to be at least 2. Throughout, positivity was essential: for x < 0 the inequality x + 1/x ≥ 2 is false (take x = −1: the sum is −2).

8. Mistakes, checks and how to practise

Common mistakes. (1) Forgetting to reverse the inequality when multiplying by a negative number. (2) Squaring both sides when a side can be negative. (3) Multiplying an inequality by an expression whose sign is unknown. (4) Subtracting inequalities. (5) Saying that a ≥ b is proved when you have only shown it for a few numbers. (6) Treating a^(1/2) as ±√a: the symbol means the non-negative root.

Checks. Test your inequality with a number from each region, and with the equality case. When a proof by 'difference ≥ 0' claims equality at a = b, check that equality really holds at that point.

How to practise. Take any inequality and ask, 'what is the difference, and is it a sum of squares?' Then try to break it with a counterexample before proving it: an inequality that fails for x = 0 or negative x needs extra conditions.
