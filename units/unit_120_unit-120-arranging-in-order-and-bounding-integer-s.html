Reading

1. Arranging in order

When a problem is symmetric in several variables, you may assume an order such as a ≤ b ≤ c, a trick sometimes called without loss of generality (WLOG). This reduces the number of cases dramatically, since you handle only one arrangement of each solution, and then count permutations afterwards.

Worked example. Find all positive integers with 1/a + 1/b + 1/c = 1. With a ≤ b ≤ c, we have 3/a ≥ 1, so a ≤ 3, and a ≥ 2 (a = 1 is too big). If a = 2 then 1/b + 1/c = 1/2 with b ≥ 3, so 2/b ≥ 1/2 and b ≤ 4: b = 3 gives c = 6; b = 4 gives c = 4. If a = 3, then 1/b + 1/c = 2/3 with b ≥ 3, so 2/b ≥ 2/3 and b = 3, c = 3. The solutions are (2, 3, 6), (2, 4, 4), (3, 3, 3) (confirmed by brute force).

2. Bounding integer solutions

If the unknowns are positive integers, an equation may force each variable below some bound; then you check the finitely many cases. Typical bounds come from the ordering: the smallest variable is at most a certain value because the sum or product of the larger ones is at least as large.

Worked example. Solve x + y + z = xyz in positive integers with x ≤ y ≤ z. Then xyz = x + y + z ≤ 3z, so xy ≤ 3. Hence (x, y) is (1, 1), (1, 2) or (1, 3). For (1, 1): 2 + z = z, impossible. For (1, 2): 3 + z = 2z, z = 3. For (1, 3): 4 + z = 3z, z = 2, but z ≥ y fails. So the only solution up to order is (1, 2, 3).

Example. How many ordered triples satisfy it? 1 + 2 + 3 = 6 = 1 · 2 · 3, and the six orderings give 6 ordered triples.

3. Methods in practice

1. Decide on the ordering. 2. Use the ordering to bound the smallest variable. 3. Substitute each possible value and solve the reduced equation for the remaining variables, again bounding the next smallest. 4. Check each candidate in the original equation. 5. Count permutations if the question asks for ordered solutions.

Worked example. Positive integers with a + b = ab: rewrite as (a − 1)(b − 1) = 1, so a = b = 2 is the only solution. The trick (a − 1)(b − 1) = ab − a − b + 1 factors many two-variable equations.

Inequality bounding. If a ≤ b ≤ c and abc = 2(a + b + c) then abc ≤ 6c, so ab ≤ 6: the cases (1, 1), …, (2, 3) are the only ones to check.

4. Mistakes, checks and how to practise

Common mistakes. Forgetting to count permutations. Assuming strict inequalities when ties are allowed (a = b is a legal case). Not rechecking the final candidates.

Checks. Substitute every solution into the original equation.

Practice. Always write the bound explicitly (for instance 'so a ≤ 3').

Worked examples with Try-its: Ordering the unknowns

When an equation is symmetric, assume a ≤ b ≤ c. To solve 1/a + 1/b + 1/c = 1 in positive integers: since the largest reciprocal 1/a must be at least 1/3, a ≤ 3, and a ≥ 2. Trying a = 2 and a = 3 gives exactly (2, 3, 6), (2, 4, 4) and (3, 3, 3). Finally permute the results if order matters.

Try it

Solve a + b + c = abc in positive integers with a ≤ b ≤ c.

Answer. Since abc = a + b + c ≤ 3c we get ab ≤ 3, so a = 1 and b ≤ 3, leading to (1, 2, 3).

Worked examples with Try-its: Bounding

To find all integer solutions, show the unknowns must be small and then check. For xy = x + y + 3 rewrite (x − 1)(y − 1) = 4 and list the factor pairs. Bounding by the largest variable is the standard trick for symmetric equations.

Try it

Find positive integer solutions of xy = x + y + 3.

Answer. (x − 1)(y − 1) = 4: (2, 5), (3, 3), (5, 2).

Worked examples with Try-its: A longer problem

Problem. Find all positive integer solutions of 1/x + 1/y = 1/6. Solution. (x − 6)(y − 6) = 36, so (x, y) = (7, 42), (8, 24), (9, 18), (10, 15), (12, 12) and the swaps: 9 ordered solutions.

Reflection. Clear denominators and factor.

More worked examples: Worked examples

Reciprocals. Solving 1/x + 1/y = 1/4 with x ≤ y: (x − 4)(y − 4) = 16, so (x − 4, y − 4) = (1, 16), (2, 8), (4, 4) giving (x, y) = (5, 20), (6, 12), (8, 8). Ordering. To find positive integers a ≤ b ≤ c with abc = a + b + c we showed a = 1, b = 2, c = 3.

Try it

Find all positive integer pairs x ≤ y with 1/x + 1/y = 1/2.

Answer. (x − 2)(y − 2) = 4: (3, 6) and (4, 4).

Try it

Find positive integers with x + y = xy.

Answer. (x − 1)(y − 1) = 1, so x = y = 2.

More worked examples: A second longer problem

Problem. How many ordered pairs of positive integers (a, b) satisfy a² − b² = 60? Solution. (a − b)(a + b) = 60 with both factors even: (2, 30) and (6, 10), giving (a, b) = (16, 14) and (8, 2). Two pairs.

Check. 256 − 196 = 60 and 64 − 4 = 60 ✓.

Problem p1. How many ordered pairs of positive integers (a, b) satisfy 1/a + 1/b = 1/3?

Hint(a − 3)(b − 3) = 9.
Answer3
Method: Factor

(a − 3)(b − 3) = 9 with both factors positive: (1, 9), (3, 3), (9, 1), giving (4, 12), (6, 6), (12, 4): 3 pairs.

Method: Bound

Both a and b exceed 3 and a ≤ 6 when a ≤ b, so check a = 4, 5, 6.

Source: Andreescu & Gelca, 3.1

Problem p2. How many solutions in positive integers with a ≤ b ≤ c are there to 1/a + 1/b + 1/c = 1?

Hinta ≤ 3 since the smallest reciprocal is at least 1/3.
Answer3
Method: Cases

a = 2 gives 1/b + 1/c = 1/2, so (b, c) = (3, 6) or (4, 4). a = 3 gives 1/b + 1/c = 2/3, so b = c = 3. So (2, 3, 6), (2, 4, 4), (3, 3, 3): 3 solutions.

Method: Bound

a = 1 is impossible since then 1/b + 1/c = 0, and a ≥ 4 would make the sum at most 3/4.

Source: Andreescu & Gelca, 3.1

Problem p3. How many ordered triples of positive integers (a, b, c) satisfy a + b + c = abc?

HintAssume a ≤ b ≤ c and bound a.
Answer6
Method: Ordered solution

With a ≤ b ≤ c: abc = a + b + c ≤ 3c so ab ≤ 3. This gives (1, 1, c) impossible (c + 2 = c), (1, 2, 3) works and (1, 3, ...) fails. The only sorted solution is (1, 2, 3), which has 6 orderings.

Method: Check

1 + 2 + 3 = 6 = 1 · 2 · 3.

Source: Andreescu & Gelca, 3.1

Problem p4. Among 2^100, 3^60 and 5^40, which is largest? Give 1 for 2^100, 2 for 3^60 and 3 for 5^40.

HintCompare logarithms or write each as a 20th power.
Answer1
Method: Common power

2¹⁰⁰ = (2⁵)²⁰ = 32²⁰, 3⁶⁰ = (3³)²⁰ = 27²⁰ and 5⁴⁰ = (5²)²⁰ = 25²⁰. So 2¹⁰⁰ is largest.

Method: Logs

100 ln 2 ≈ 69.3, 60 ln 3 ≈ 65.9, 40 ln 5 ≈ 64.4.

Source: Andreescu & Gelca, 3.1

Problem p8. How many right triangles with positive integer sides have perimeter 24 (order of the legs ignored)?

HintList the Pythagorean triples.
Answer1
Method: List

The triple (6, 8, 10) has perimeter 24 and (3, 4, 5) scaled by 2. No other triple works, so 1.

Method: Bound

The hypotenuse is less than 12 and more than 24/(2 + √2) ≈ 7, so check c = 8…11.

Problem p9. How many triples of positive integers x ≤ y ≤ z satisfy x + y + z = 12?

HintPartitions of 12 into 3 parts.
Answer12
Method: Cases

x = 1: (1, 1, 10), …, (1, 5, 6) gives 5; x = 2: (2, 2, 8) to (2, 5, 5) gives 4; x = 3: (3, 3, 6), (3, 4, 5) gives 2; x = 4: (4, 4, 4) gives 1. Total 12.

Method: Formula

The number of partitions of n into 3 parts is the nearest integer to n²/12 = 12.

Problem p10. How many triples of positive integers x ≤ y ≤ z satisfy 1/x + 1/y + 1/z = 1?

Hintx is at most 3.
Answer3
Method: Bound

Since x is smallest, 3/x ≥ 1 so x ≤ 3; x = 1 is impossible. x = 2 gives 1/y + 1/z = 1/2, with (3, 6) and (4, 4); x = 3 gives (3, 3, 3). Total 3.

Method: Check

1/2 + 1/3 + 1/6 = 1/2 + 1/4 + 1/4 = 1/3 + 1/3 + 1/3 = 1.
