Reading

1. Kinds of numbers

The natural numbers 1, 2, 3, …; the integers (including 0 and negatives); the rationals (fractions of integers); the reals (all points on the number line, including irrationals such as √2 and π). A number is rational exactly when its decimal expansion terminates or eventually repeats. Terminating decimals come from fractions whose denominator in lowest terms has only the prime factors 2 and 5: of the denominators below 30 these are 2, 4, 5, 8, 10, 16, 20, 25.

Irrational numbers. √2 is irrational (Unit 29 gave the descent proof). The sum of a rational and an irrational number is irrational; the sum of two irrationals can be rational (√2 + (−√2) = 0). Between any two real numbers there are infinitely many rationals and irrationals.

Try it

Is 0.375 rational? Write it as a fraction.

Answer. Yes: 375/1000 = 3/8.

2. Repeating decimals

Dividing 1 by 7 gives 0.142857 142857…, a repeating block of six digits. In general 1/n has a repeating block whose length is the least k with 10ᵏ ≡ 1 (mod n) (when n is coprime to 10): 1 for n = 3, 2 for n = 11, 6 for n = 7 and 13, 3 for n = 37, 16 for n = 17 (all found by computer).

Converting to a fraction. For 0.4545…, multiply by 100: 100N − N = 45, so N = 45/99 = 5/11. For 0.1666…, the repeating part starts after one digit: 10N = 1.666…, 100N − 10N = 15, N = 15/90 = 1/6. For 0.12343434… compute as (1234 − 12)/9900 = 1222/9900 = 611/4950; the general rule: (all digits up to the end of the first repeat − non-repeating digits) over (as many 9s as the repeat, followed by as many 0s as the non-repeating digits).

The surprising 0.999… = 1. N = 0.999… gives 10N − N = 9, so N = 1. There is no number between 0.999… and 1.

Try it

Write 0.2(7) = 0.2777… as a fraction.

Answer. (27 − 2)/90 = 25/90 = 5/18.

3. Operations, order and estimation

Order of operations: brackets, exponents, multiplication and division left to right, addition and subtraction left to right. Fractions: a/b + c/d = (ad + bc)/bd; compare fractions by cross-multiplying. 7/8 − 3/8 = 1/2.

Counting integers in a range. How many integers n satisfy √50 < n < √500? √50 ≈ 7.07 and √500 ≈ 22.36, so n = 8, …, 22: 15 integers. To avoid errors, square the inequality: 50 < n² < 500.

Estimation. Bound unfamiliar numbers between known squares or powers: 2¹⁰ = 1024 ≈ 10³ gives 2¹⁰⁰ ≈ 10³⁰.

Try it

How many integers lie strictly between √20 and √200?

Answer. √20 ≈ 4.47, √200 ≈ 14.14: 5, …, 14, so 10.

4. A longer problem

Problem. Show that 0.(142857) × 7 = 0.(999999…) = 1, find the decimal of 3/7, and write 1.2(36) as a fraction.

Solution. 1/7 = 0.142857… times 7 gives 0.999… = 1, consistent with 1/7 · 7 = 1. 3/7 = 3 · 0.142857… = 0.428571… (the same block rotated). For 1.2(36): the repeating part 36 starts after one digit; value = 1 + (236 − 2)/990 = 1 + 234/990 = 1 + 13/55 = 68/55.

Reflection. Multiples of 1/7 are rotations of the same six-digit block, because 7 is a full-period prime (10 has order 6 mod 7).

5. Mistakes, checks and how to practise

Common mistakes. (1) Writing 0.4545… as 45/100. (2) Using the wrong number of 9s and 0s in the conversion. (3) Believing that every non-terminating decimal is irrational. (4) Forgetting to reduce the fraction.

Checks. Divide the fraction to see whether you get the decimal you started with.

How to practise. Convert ten repeating decimals by hand. In Unlimited practice, rotate the decimal and fraction families.

More worked examples: Worked examples

Repeating decimals. 0.363636… = 36/99 = 4/11. For a decimal with a non-repeating part use subtraction: x = 0.12333…, 1000x − 100x = 123 − 12 = 111, so x = 111/900 = 37/300. Also 0.1666… = (16 − 1)/90 = 1/6 and 0.999… = 1. The repeating block of 1/7 is 142857, so 3.142857142857… = 22/7.

Order of operations. 2 + 3 · 4² = 2 + 48 = 50 (powers first, then multiplication, then addition). Estimating. 49.8 × 20.1 ≈ 50 × 20 = 1000. Rational numbers have terminating or repeating decimals; irrational numbers such as √2 and π do not.

Write 0.454545… as a fraction in lowest terms.

Answer. 45/99 = 5/11.

Try it

Answer. No: it neither terminates nor repeats.

More worked examples: A second longer problem

Problem. Show that 0.999… = 1. Solution. Let x = 0.999…. Then 10x = 9.999…, and subtracting gives 9x = 9, so x = 1. This agrees with 1/3 + 2/3 = 0.333… + 0.666… = 1.

Reflection. 0.999… and 1 are two decimal names for the same number.

Problem p1. Write 0.272727… as a fraction in lowest terms.

HintMultiply by 100 and subtract.
Answer3/11
Method: Subtract

x = 0.2727…, 100x = 27.2727…, so 99x = 27 and x = 3/11.

HintSquare (1 + i) first.
Answer16
Method: Repeated squaring

(1 + i)² = 2i; (2i)² = −4; (−4)² = 16.

Problem p8. Define a ∗ b = a + b + ab. Find the inverse of 2: the number b with 2 ∗ b equal to the identity element. Give b as a fraction.

HintFind the identity e first: a ∗ e = a.
Answer-2/3
Method: Identity then inverse

a + e + ae = a gives e(1 + a) = 0, so e = 0. Then 2 + b + 2b = 0 gives 3b = −2 and b = −2/3.

Method: Product form

a ∗ b + 1 = (a + 1)(b + 1), so the identity makes (a + 1)(b + 1) = 1, giving b + 1 = 1/3 and b = −2/3.
