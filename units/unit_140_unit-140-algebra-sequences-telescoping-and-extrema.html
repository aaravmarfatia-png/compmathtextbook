1. Telescoping and recurrences

A sum telescopes when each term is a difference g(k + 1) − g(k). Examples: 1/(k(k + 2)) = ½(1/k − 1/(k + 2)), k·k! = (k + 1)! − k!, and 1/(√k + √(k + 1)) = √(k + 1) − √k. For a recurrence a_(n+1) = 2aₙ + 1 with a₁ = 1 the fixed point is −1, so aₙ + 1 doubles each step and aₙ = 2ⁿ − 1.

Inequality minima. For x > 0, x + k/x ≥ 2√k with equality at x = √k; x² + 16/x ≥ 12 at x = 2 by splitting 16/x into 8/x + 8/x and applying 3-term AM-GM.

Try it

1/(1·2) + 1/(2·3) + … + 1/(9·10)?

Answer. 9/10.

Try it

Minimum of x + 25/x?

Answer. 10.

2. Floors, gcds and Fibonacci

⌊√k⌋ equals j for j² ≤ k < (j + 1)², i.e. on 2j + 1 consecutive values. The sum ⌊√1⌋ + … + ⌊√15⌋ is 1·3 + 2·5 + 3·7 = 34 (k = 1..3, 4..8, 9..15). Fibonacci numbers obey gcd(F_m, F_n) = F_gcd(m,n): gcd(F₁₂, F₁₈) = F₆ = 8.

Try it

⌊√1⌋ + … + ⌊√8⌋?

Answer. 1·3 + 2·5 = 13.

Try it

gcd(F₁₀, F₁₅)?

Answer. F₅ = 5.

3. A worked problem

Problem. Compute Σ_{k=1}^{99} 1/(√k + √(k + 1)). Solution. Each term equals √(k + 1) − √k, so the sum telescopes to √100 − √1 = 9.

Check. The first terms are √2 − 1, √3 − √2, √4 − √3 — only the first and last survive ✓.

Problem p1. a₁ = 1 and a_(n+1) = 2·aₙ + 1. Find a_8.

HintSubtract the fixed point -1 to get a geometric sequence.
Answer255
Method: Fixed point

With fixed point -1, aₙ − -1 is multiplied by 2 each step, so a_8 = (1 − -1)·2^7 + -1 = 255.

Method: Iterate

Apply the rule 7 times starting from 1: a_8 = 255.

Source: Technique from the IMO Compendium §2.1, Gelca & Andreescu 3.1.6 (original problem)

Problem p5. Compute 1/(1·3) + 1/(2·4) + 1/(3·5) + … + 1/(9·11). (fraction)

HintWrite 1/(k(k+2)) = ½(1/k − 1/(k+2)).
Answer36/55
Method: Telescoping

The sum is ½(1 + ½ − 1/10 − 1/11) = 36/55.

Method: Pattern

Compute the first few partial sums 1/3, 3/8, 11/30, … and use the closed form 3/4 − ½(1/(n+1) + 1/(n+2)): 36/55.

Problem p9. Compute 1·1! + 2·2! + … + 5·5!.

HintUse k·k! = (k + 1)! − k!.
Answer719
Method: Telescoping

The sum is (5 + 1)! − 1 = 719.

Method: Induction

The pattern (n + 1)! − 1 holds for n = 1, 2, and each step adds (n + 1)(n + 1)! giving 719 at n = 5.

Source: Technique from the IMO Compendium §2.1, Gelca & Andreescu 3.1.6 (original problem)

Problem p18. What is the minimum value of x + 9/x for x > 0?

HintAM-GM on x and 9/x.
Answer6
Method: AM-GM

x + 9/x ≥ 2√9 = 6, with equality at x = 3.

Method: Calculus

The derivative 1 − 9/x² vanishes at x = 3 where the value is 6.

HintSplit 16/x into two equal parts and use AM-GM on three terms.
Answer12
Method: AM-GM

x² + 16/(2x) + 16/(2x) ≥ 3·∛(x²·16·16/(4x²)) = 12, with equality at x = 2.

Method: Calculus

The derivative 2x − 16/x² vanishes at x = 2, giving 12.
