Reading

1. Exponential Diophantine equations

An equation where the unknowns appear in exponents, like 2ˣ + 1 = 3ʸ, is usually solved by trying small values, then using congruences (mod 3, 4, 8, or the modulus that makes one side periodic) to rule out everything else.

Worked example. Solve 2ˣ + 1 = 3ʸ in positive integers. Small values give (1, 1) and (3, 2): 2 + 1 = 3 and 8 + 1 = 9. A brute-force search up to x = 29, y = 19 finds no other solution. Proof sketch: mod 3 forces x odd. Write 3ʸ − 1 = 2ˣ. If y is odd, 3ʸ − 1 ≡ 2 mod 4, so x = 1 and y = 1. If y is even, y = 2m, then (3ᵐ − 1)(3ᵐ + 1) = 2ˣ, two powers of 2 differing by 2, namely 2 and 4, so 3ᵐ = 3, m = 1, y = 2, x = 3.

2. Number-theoretic functions

τ(n) counts divisors, σ(n) sums them, φ(n) counts integers up to n coprime to n. If n = p₁^{a₁} … p_k^{a_k}, then τ = Π(a_i + 1), σ = Π (p_i^{a_i+1} − 1)/(p_i − 1), φ = n Π(1 − 1/p_i).

Worked example. n = 36 = 2² × 3². τ = 3 × 3 = 9; σ = 7 × 13 = 91; φ = 36 × ½ × ⅔ = 12. All three checked by direct counting.

Properties. They are multiplicative: f(mn) = f(m)f(n) when gcd(m, n) = 1. n is a perfect square iff τ(n) is odd, since divisors pair up as d and n/d except when d = √n.

3. Pell's equation

The equation x² − Dy² = 1 (D not a square) has infinitely many solutions. All come from the smallest one (x₁, y₁) by (x + y√D) = (x₁ + y₁√D)ⁿ.

Worked example. For D = 2 the smallest solution is (3, 2). Squaring (3 + 2√2): 17 + 12√2, giving (17, 12); cubing: 99 + 70√2, giving (99, 70). Check: 99² − 2 × 70² = 9801 − 9800 = 1 ✓.

Recurrence. x_{n+1} = 6x_n − x_{n−1}: 1, 3, 17, 99, … (6 × 17 − 3 = 99 ✓).

Use. Pell's equation yields numbers that are both triangular and square: 1, 36, 1225, …

4. Mistakes, checks and how to practise

Common mistakes. Declaring that small cases show the pattern continues. Using φ(n) formulas for non-coprime factors. Forgetting solutions with y = 0 or negative signs.

Checks. Substitute and compute directly.

Practice. For every exponential equation, list small solutions first, then pick moduli.

Worked examples with Try-its: Exponential Diophantine equations

Equations with the unknown in an exponent are solved by factoring, bounding and using residues. 2ᵃ + 1 = 3ᵇ has solutions (a, b) = (1, 1) and (3, 2) (a search up to a = 19 finds only these). 3ᵃ − 2ᵇ = 1 has (1, 1) and (2, 3). The usual method: reduce mod a small number to show no solutions beyond a certain size, then check the small cases by hand.

Try it

Find all positive integer solutions of 2ˣ = 3ʸ + 1 with y ≤ 2.

Answer. y = 1 gives 4 = 2², so x = 2; y = 2 gives 10, not a power of 2. The only solution is (x, y) = (2, 1).

Worked examples with Try-its: Arithmetic functions

For n = 36 = 2² · 3²: the number of divisors d(n) = (2 + 1)(2 + 1) = 9, Euler's φ(36) = 36 · (1/2)(2/3) = 12, and for n = 12 the sum of divisors σ(12) = 1 + 2 + 3 + 4 + 6 + 12 = 28. A number is a perfect square exactly when d(n) is odd.

Try it

Compute d(60), σ(10) and φ(10).

Answer. d(60) = 12, σ(10) = 18, φ(10) = 4.

Worked examples with Try-its: Pell equations

The equation x² − 2y² = 1 has solutions (3, 2), (17, 12), (99, 70), … generated by (3 + 2√2)ᵏ. Each new solution comes from the previous one by (x, y) ↦ (3x + 4y, 2x + 3y); for example (3, 2) ↦ (17, 12). These solutions are also the convergents of the continued fraction of √2 (see the continued-fractions unit).

Try it

Starting from (17, 12), find the next solution of x² − 2y² = 1.

Answer. (3 · 17 + 4 · 12, 2 · 17 + 3 · 12) = (99, 70).

More worked examples: Worked examples

Euler's totient. φ(n) = 8 exactly for n = 15, 16, 20, 24, 30. Pell equation. x² − 3y² = 1 has solutions (2, 1), (7, 4), (26, 15), …; each comes from the previous by (x, y) ↦ (2x + 3y, x + 2y), since (2 + √3)(x + y√3) = (2x + 3y) + (x + 2y)√3. For example (7, 4) ↦ (26, 15).

Try it

Find φ(21) and the sum of divisors of 21.

Answer. φ(21) = 12 and σ(21) = 1 + 3 + 7 + 21 = 32.

Try it

Solve 2ˣ · 3ʸ = 72 in non-negative integers.

Answer. 72 = 2³ · 3², so (x, y) = (3, 2).

More worked examples: A second longer problem

Problem. Find all positive integers n with φ(n) = 6. Solution. The values are n = 7, 9, 14, 18. Reasoning: if p is a prime factor with p − 1 dividing 6 then p is 2, 3, 7; testing combinations gives exactly these four.

Check. φ(7) = 6, φ(9) = 6, φ(14) = 6, φ(18) = 6.

Problem p1. How many pairs of positive integers (x, y) satisfy 2ˣ + 1 = 3ʸ?

HintCompare small values.
Answer2
Method: Search

(1, 1): 3 = 3 and (3, 2): 9 = 9. For larger x the equation fails (mod 8 and mod 3 arguments rule out the rest), so there are 2 pairs.

Method: Check

2⁵ + 1 = 33 is not a power of 3.

HintTry y = 1, 2, 3, 4.
Answer13

Hint720 = 2⁴ · 3² · 5.
Answer30

Answer7
Method: Factor

Problem p8. For how many primes p are p, p + 2 and p + 4 all prime?

HintOne of three such numbers is divisible by 3.
Answer1
Method: Mod 3

The numbers p, p + 2, p + 4 cover all residues mod 3, so one is a multiple of 3, which must equal 3, giving p = 3 (3, 5, 7). Only 1 prime.

Method: Check

Next candidates like 5, 7, 9 or 11, 13, 15 fail.

Problem x20. Find φ(50), the number of integers from 1 to 50 that are coprime to 50.

HintUse the product formula over the prime factors.
Answer20
Method: Multiplicative formula

50 = 2 · 5^2, so φ = 1 · 20 = 20.

Start with 50 and remove multiples of each prime, add back overlaps: 50 −25 −10 +5 = 20.
