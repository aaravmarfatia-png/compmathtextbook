Reading

1. The extremal principle in action

The extremal principle looks at the largest, smallest, first or last element of a finite collection, which is special and therefore often easier to control. Example 1 (equal sum and product). Find positive integers with sum equal to product. For three numbers a ≤ b ≤ c, abc = a + b + c ≤ 3c, so ab ≤ 3, giving (a, b) = (1, 1), (1, 2), (1, 3). Only (1, 2, 3) works (a search up to 7 confirms it is the only triple); for four numbers the only solution is (1, 1, 2, 4).

Example 2 (parity of midpoints). Among any five points with integer coordinates, two have a midpoint with integer coordinates. This is a pigeonhole argument, but the extremal flavour is in choosing the right invariant: there are only four parity classes (even/odd, even/odd) for the pair of coordinates, so two of the five points share a class, and their midpoint is integral. Random tests agree.

Example 3 (longest path). In a graph where every vertex has degree at least 2, there is a cycle. Take a longest path v₁, …, v_k; v₁ has another neighbour besides v₂, which must lie on the path (otherwise the path could be extended), and that gives a cycle.

Try it

Show that in any finite set of at least two real numbers there are two whose difference is the smallest among all pairwise differences, and explain why this smallest gap exists.

Answer. A finite set has finitely many pairwise differences, so one of them is smallest; this uses finiteness, which is the reason extremal arguments need finite sets.

2. Choosing the extremal object

Typical choices: the smallest counterexample (to prove a statement for all n, assume it fails and take the smallest n for which it fails); the longest path; the point farthest from a line; the triangle of largest area among triangles with vertices in a given set (it contains all the other points in a triangle twice as big); the leftmost point.

The area trick. If a set of points lies in the plane and no triangle formed by three of them has area greater than 1, then all the points fit in a triangle of area 4. Take the triangle ABC of maximum area (at most 1) and draw through each vertex a line parallel to the opposite side; every point lies within the larger triangle of area 4 formed by those lines.

Tips. State clearly which quantity you maximise or minimise, and prove that a maximiser exists (finite set, or a closed bounded region). Then derive a contradiction from the assumption that the extremal object lacks the property you want.

Try it

Show that among 7 distinct positive integers whose sum is 28 the set must be {1, …, 7}.

Answer. The smallest possible sum of 7 distinct positive integers is 1 + … + 7 = 28, with equality only for {1, …, 7}.

3. A longer problem

Problem. At a round table sit n people, each with a distinct integer. A person is called a 'peak' if they hold a larger number than both neighbours. Show that there is at least one peak.

Solution. Take the person with the largest number. Both neighbours have smaller numbers (the numbers are distinct), so this person is a peak. If numbers can repeat, the argument needs the maximum to be strictly larger than its neighbours, which can fail (all numbers equal): so the statement needs the distinctness.

Reflection. The proof is a single line once the extremal choice is made. Always check where each hypothesis (here: distinctness) is used.

4. Mistakes, checks and how to practise

Common mistakes. (1) Applying the principle to an infinite set where the extremum may not exist. (2) Forgetting to show that the extremal object has the property you claim. (3) Not using all the hypotheses.

Checks. Look at small cases to see which element plays the extremal role.

How to practise. For each problem list the possible extremal quantities. In Unlimited practice, rotate the extremal families.

More worked examples: Worked examples

Longest path. In a graph where every vertex has degree at least 2, take a longest path v₁, …, vₖ. The endpoint v₁ has at least two neighbours, and all of them must lie on the path (else the path could be extended), so one of them is vᵢ with i ≥ 3, giving a cycle v₁ … vᵢ v₁. Tournaments. In a tournament (every pair of players has a winner) there is always a path visiting every player once, each beating the next: this was checked by computer for all tournaments with up to 5 players, and the standard proof inserts players into a path one at a time.

Try it

In a graph all of whose degrees are at least 2, why must a cycle exist?

Answer. Take a longest path; its first vertex has a second neighbour on the path, which closes a cycle.

Try it

In a 3-player tournament A beats B, B beats C and C beats A. Find an order of all three in which each beats the next.

Answer. A, B, C (A beats B and B beats C).

More worked examples: A second longer problem

Problem. Show that no finite set of at least two distinct real numbers has the property that every element is the average of two other elements. Solution. Take the largest element M. It would be the average of two other elements, both different from M and therefore smaller than M, so their average is below M. This contradicts the choice of M.

Reflection. Choosing the largest (or smallest) object first gives a strict inequality to play with.

Problem p1. What is the smallest possible sum of 10 different positive integers?

HintTake the 10 smallest.
Answer55
Method: Extreme case

Any 10 distinct positive integers, sorted, are at least 1, 2, …, 10 term by term, so the sum is at least 55.

Method: Formula

10·11/2 = 55.

Source: Engel, Problem-Solving Strategies, ch. 3

Problem p2. Positive integers add up to 12. What is the largest possible product?

HintUse many 3s.
Answer81
Method: Use 3s

3 + 3 + 3 + 3 = 12 gives 81. Replacing two 3s by 2 + 4 or other splits gives less, and 1s are wasteful.

Method: Dynamic programming

Building up the best product for each total from 1 to 12 gives 81.

Source: Engel, Problem-Solving Strategies, ch. 3

Problem p3. A rectangle has perimeter 36. What is its largest possible area?

HintBalance the sides.
Answer81
Method: Square

Sides a and 18 − a: area a(18 − a) = 81 − (a − 9)² ≤ 81, with equality at a = 9.

Method: AM–GM

√(ab) ≤ (a + b)/2 = 9, so ab ≤ 81.

Source: Engel, Problem-Solving Strategies, ch. 3

Problem p4. What is the longest chain of numbers from 1 to 50 in which each divides the next (a₁ | a₂ | …)?

HintDouble each time.
Answer6
Method: Doubling

1, 2, 4, 8, 16, 32 has 6 terms. Each step multiplies by at least 2 and 2⁶ = 64 > 50, so no chain has 7 terms.

Method: Computer check

A search over divisibility chains confirms the longest has 6 terms.

Source: Engel, Problem-Solving Strategies, ch. 3

Problem p5. What is the largest subset of {1, 2, …, 20} containing no two consecutive numbers?

HintTake every other number.
Answer10
Method: Pairs

Group the numbers into the pairs (1,2), (3,4), …, (19,20); a subset with no consecutive numbers has at most one from each pair, so at most 10. The odd numbers achieve 10.

Method: Computer check

A search over all subsets confirms 10.

Source: Engel, Problem-Solving Strategies, ch. 3

Problem p6. What is the largest subset of {1, …, 20} in which no number divides another?

HintTake the upper half.
Answer10
Method: Pigeonhole on odd parts

Write each number as 2ᵏ·m with m odd. There are 10 odd values of m, and two numbers with the same m divide each other, so at most 10 numbers. The set {11, …, 20} achieves 10.

Method: Computer check

Searching all subsets confirms 10.

Source: Engel, Problem-Solving Strategies, ch. 3

Problem p7. Four real numbers add up to 12. What is the smallest possible value of the sum of their squares?

HintEqual numbers minimise it.
Answer36
Method: Complete squares

Σxᵢ² = Σ(xᵢ − 3)² + 6Σxᵢ − 36 = Σ(xᵢ − 3)² + 36 ≥ 36, with equality when all xᵢ = 3.

Method: QM–AM

√(Σx²/4) ≥ (Σx)/4 = 3, so Σx² ≥ 36.

Source: Engel, Problem-Solving Strategies, ch. 3

Problem p8. What is the smallest n such that n! ends in at least three zeros?

HintCount factors of 5.
Answer15
Method: Legendre

n! has ⌊n/5⌋ + ⌊n/25⌋ + … zeros: n = 14 gives 2, n = 15 gives 3.

Method: Check

15! = 1307674368000 ends in three zeros; 14! = 87178291200 ends in two.

Problem x13. What is the largest number of acute angles a convex polygon can have?

HintExterior angles sum to 360°.
Answer3
Method: Exterior angles

An acute interior angle has an exterior angle above 90°, and the exterior angles sum to 360°, so at most 3 are above 90°.

Method: Example

A triangle has 3 acute angles.

Source: Engel, Problem-Solving Strategies, ch. 3

Possible with three acute angles and three large obtuse ones.

Problem x18. 40 objects are placed into 7 boxes. What is the largest number n for which some box must contain at least n objects?

HintPigeonhole principle.
Answer6
Method: Pigeonhole

⌈40/7⌉ = 6.

Method: Contradiction

If every box had at most 5 objects, there would be at most 7 · 5 = 35 < 40 objects in all.

Problem x20. Find the nim-sum (XOR) of the piles 3, 7, 11.

HintWrite each pile in binary.
Answer15
Method: Binary columns

In binary the piles are 0011, 0111, 1011; adding each column mod 2 gives 1111 = 15.

Method: Step by step

XOR them one at a time: 3, 4, 15.

Problem x21. How many edges does the complete graph K_30 have?

HintEvery pair of vertices is joined.
Answer435
Method: Pairs

C(30, 2) = 435.

Method: Handshake lemma

Each of the 30 vertices has degree 29, so the edges number 30 · 29/2 = 435.
