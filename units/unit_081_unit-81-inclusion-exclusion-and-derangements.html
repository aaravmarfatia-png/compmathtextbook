Reading

1. Inclusion–exclusion

For finite sets A₁, …, Aₙ, the number of elements in at least one set is |A₁| + … + |Aₙ| − (sizes of pairwise intersections) + (sizes of triple intersections) − …. For two sets |A ∪ B| = |A| + |B| − |A ∩ B|; for three, add back the triple intersection.

Worked example 1. How many integers from 1 to 100 are divisible by none of 2, 3, 5? By inclusion–exclusion: 100 − (50 + 33 + 20) + (16 + 10 + 6) − 3 = 26.

Worked example 2. How many integers from 1 to 1,000 are divisible by 3 or 5 but not 15? Divisible by 3: 333; by 5: 200; by 15: 66. Divisible by 3 or 5: 333 + 200 − 66 = 467; remove those divisible by 15: 467 − 66 = 401.

Worked example 3: surjections. The number of ways to map 5 labelled objects onto 3 labelled boxes with no box empty is 3⁵ − 3 · 2⁵ + 3 · 1⁵ = 243 − 96 + 3 = 150.

2. Derangements

A derangement is a permutation of n objects with no fixed point. By inclusion–exclusion, Dₙ = n!(1 − 1/1! + 1/2! − … + (−1)ⁿ/n!). D₃ = 6(1 − 1 + 1/2 − 1/6) = 2, D₄ = 24(1 − 1 + 1/2 − 1/6 + 1/24) = 9 and D₅ = 44. The fraction of permutations that are derangements tends to 1/e ≈ 0.3679.

Worked example. Four letters are put into four addressed envelopes at random. The probability that none is in the correct envelope is D₄/4! = 9/24 = 3/8.

Recurrence. Dₙ = (n − 1)(Dₙ₋₁ + Dₙ₋₂) with D₁ = 0, D₂ = 1: D₃ = 2(1 + 0) = 2, D₄ = 3(2 + 1) = 9, D₅ = 4(9 + 2) = 44, D₆ = 5(44 + 9) = 265.

3. Counting solutions with upper bounds

The number of non-negative solutions of x + y + z = 10 is C(12, 2) = 66. If each variable must be at most 5, subtract the cases where some variable is at least 6: for x ≥ 6, set x′ = x − 6 and count x′ + y + z = 4: C(6, 2) = 15. By symmetry three such cases, and no two can happen together (12 > 10). So 66 − 45 = 21.

Worked example 2. How many ways to distribute 10 identical sweets among 3 children with each getting at least 1 and at most 5? Subtract 1 each: x + y + z = 7 with each ≤ 4: total C(9, 2) = 36; bad: x ≥ 5 → x′ + y + z = 2: C(4, 2) = 6, three cases, 18, overlaps impossible: 36 − 18 = 18.

Euler's totient. The count of integers up to n coprime to n comes from inclusion–exclusion over the prime divisors: φ(30) = 30 − 15 − 10 − 6 + 5 + 3 + 2 − 1 = 8.

4. Mistakes, checks and how to practise

Common mistakes. Wrong signs. Forgetting higher-order intersections. Counting the bad cases without checking whether overlaps exist. Treating labelled and unlabelled objects the same.

Checks. Test on a small case you can list.

Practice. Write the sets and intersections explicitly.

Worked examples with Try-its: The principle

|A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |A ∩ C| − |B ∩ C| + |A ∩ B ∩ C|. How many integers from 1 to 100 are divisible by 2, 3 or 5? 50 + 33 + 20 − 16 − 10 − 6 + 3 = 74. The complement (coprime to 30) is 26 numbers. Euler's φ(30) = 30 · (1/2)(2/3)(4/5) = 8.

Try it

How many integers from 1 to 60 are divisible by neither 2 nor 3?

Answer. 60 − 30 − 20 + 10 = 20.

Worked examples with Try-its: Derangements and surjections

A derangement is a permutation with no fixed point. By inclusion-exclusion Dₙ = n!(1 − 1/1! + 1/2! − … ± 1/n!), giving D₄ = 9 and D₅ = 44 and the recurrence Dₙ = (n − 1)(Dₙ₋₁ + Dₙ₋₂). The number of onto functions from a 4-element set to a 3-element set is 3⁴ − 3 · 2⁴ + 3 · 1⁴ = 36.

Try it

In how many ways can 4 letters go into 4 addressed envelopes so that none is in its own envelope?

Answer. 9.

Worked examples with Try-its: A longer problem

Problem. How many 5-letter words can be made with the letters A, B, C so that all three letters appear? Solution. 3⁵ − 3 · 2⁵ + 3 = 243 − 96 + 3 = 150.

Reflection. It is the surjection formula again: count all words, subtract those missing one letter, add back those missing two.

More worked examples: Worked examples

Coprime count. The integers from 1 to 120 not divisible by 2, 3 or 5 number 120 · (1/2)(2/3)(4/5) = 32. Derangements. D₂ = 1, D₃ = 2, D₄ = 9, D₅ = 44, D₆ = 265. Hats. With 5 hats returned at random, the probability that nobody gets their own is 44/120 = 11/30.

Try it

How many integers from 1 to 30 are divisible by 2 or 3?

Answer. 15 + 10 − 5 = 20.

Try it

In how many ways can 3 letters be put into 3 envelopes with none correct?

Answer. 2.

More worked examples: A second longer problem

Problem. How many permutations of 5 objects have exactly 1 fixed point? Solution. Choose the fixed point (5 ways) and derange the other 4 (D₄ = 9 ways): 45.

Check. The numbers of permutations with 0, 1, 2, 3, 5 fixed points are 44, 45, 20, 10, 1 and the total with 4 fixed points is 0: 44 + 45 + 20 + 10 + 0 + 1 = 120 ✓.

Answer150
