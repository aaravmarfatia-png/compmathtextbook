Reading

1. The basic maps in coordinates

Translation by (h, k): (x, y) → (x + h, y + k). Reflection in the x-axis: (x, y) → (x, −y); in the y-axis: (−x, y); in the line y = x: (y, x). Rotation about the origin by 90° counter-clockwise: (x, y) → (−y, x); by 180°: (−x, −y). Dilation with centre the origin and factor k: (x, y) → (kx, ky). To transform about another centre C, translate C to the origin, apply the map, translate back.

Worked example 1. Reflect (3, 1) in the line y = x + 2. Shift down by 2 so that the line becomes y = x: the point (3, 1) becomes (3, −1); reflecting in y = x gives (−1, 3); shifting back up gives (−1, 5). Check: the midpoint of (3, 1) and (−1, 5) is (1, 3), which lies on y = x + 2 ✓, and the segment has slope −1, perpendicular to the line ✓.

Worked example 2. Rotate (2, 1) by 90° counter-clockwise about (1, 1). Relative to the centre the point is (1, 0); rotating gives (0, 1); adding back (1, 1) gives (1, 2).

2. Compositions

Two reflections in parallel lines at distance d compose to a translation by 2d perpendicular to the lines. Two reflections in lines meeting at angle θ compose to a rotation by 2θ about the intersection. Reflection followed by translation along the mirror line is a glide reflection.

Worked example. Reflect in x = 1 and then in x = 4: x → 2 − x → 8 − (2 − x) = x + 6. The result is a translation by 6 = 2 × 3 ✓.

Orientation. Reflections reverse orientation, rotations and translations preserve it. The composition of an even number of reflections preserves it.

3. Using reflection for shortest paths

To find the shortest path from A to B that touches a line ℓ, reflect B in ℓ to B′; the shortest path is the straight segment AB′. This works because the path A → P → B has the same length as A → P → B′ for any P on ℓ.

Worked example. A = (0, 3), B = (6, 1), the path must touch the x-axis. Reflect B to B′ = (6, −1). The distance is √(6² + 4²) = √52 = 2√13 ≈ 7.21. The touching point is where AB′ meets the axis: x = 4.5.

Check. At (4.5, 0): √(4.5² + 9) + √(1.5² + 1) = 5.408 + 1.803 = 7.211 ✓.

4. Mistakes, checks and how to practise

Common mistakes. Rotating about the origin when the centre is elsewhere. Mixing up clockwise and counter-clockwise. Reflecting the wrong point in a shortest-path problem (reflect only one of the two points).

Checks. Distances from the centre or the mirror must be preserved.

Practice. Do every transformation as: translate, apply, translate back.

Worked examples with Try-its: Reflections and rotations

Reflection in the x-axis sends (x, y) to (x, −y); in the y-axis to (−x, y); in the line y = x to (y, x); in y = x + c to (y − c, x + c). The point (3, 1) reflects in y = x + 2 to (−1, 5): the midpoint (1, 3) lies on the line. Rotation by 90° anticlockwise about the origin sends (x, y) to (−y, x); by 180° about (a, b) it sends (x, y) to (2a − x, 2b − y).

Try it

Reflect (4, −1) in the line y = x.

Answer. (−1, 4).

Worked examples with Try-its: Shortest paths and compositions

To find the shortest path from A = (1, 2) to B = (5, 3) touching the x-axis, reflect B in the axis to B′ = (5, −3); the path length is |AB′| = √(16 + 25) = √41. Two reflections in parallel lines distance d apart compose to a translation of length 2d; two reflections in lines meeting at angle φ compose to a rotation by 2φ about the intersection point.

Try it

Reflections in the lines x = 1 and x = 4 are applied in turn to (0, 0). Where does it end?

Answer. First (2, 0), then (6, 0): a translation by 6.

Worked examples with Try-its: A longer problem

Problem. Find the image of the point (2, 5) after rotating 90° anticlockwise about (1, 1). Solution. Shift: (1, 4); rotate: (−4, 1); shift back: (−3, 2).

Reflection. Move the centre to the origin, transform, then move it back.

More worked examples: Worked examples

Rotation about a point. Rotating (2, 3) by 90° anticlockwise about (1, 1): shift to (1, 2), rotate to (−2, 1), shift back to (−1, 2). Point reflection. The 180° rotation about (4, −1) sends (2, 3) to (2 · 4 − 2, 2 · (−1) − 3) = (6, −5). Reflection in y = −x. This sends (a, b) to (−b, −a), so (2, 5) goes to (−5, −2).

Try it

Reflect (3, 7) in the x-axis and then the y-axis. Where does it end?

Answer. (−3, −7).

Try it

Rotate (4, 0) by 90° anticlockwise about the origin.

Answer. (0, 4).

More worked examples: A second longer problem

Problem. A light ray travels from A = (0, 4) to the x-axis, reflects, and reaches B = (6, 2). Where does it hit the axis? Solution. Reflect B to B′ = (6, −2). The line from A to B′ has slope (−2 − 4)/6 = −1 and meets y = 0 at x = 4. The ray touches the axis at (4, 0); the path length is |AB′| = √(36 + 36) = 6√2.

Check. |A(4, 0)| + |(4, 0)B| = √32 + √8 = 4√2 + 2√2 = 6√2 ✓.

Problem p1. Reflect (3, 5) in the line y = x. The image is (a, b). Find a + b.

HintSwap the coordinates.
Answer8
Method: Rule

The image is (5, 3), so a + b = 8.

Method: Midpoint

The midpoint (4, 4) of the two points lies on y = x.

Problem p2. Reflect (2, −3) in the x-axis and then translate by (1, 4). The result is (a, b). Find a + b.

HintReflect first, then add.
Answer10
Method: Steps

(2, −3) becomes (2, 3), then (3, 7), so a + b = 10.

Method: Order

Translating first and reflecting after would give a different point, (3, −1).

Problem p3. Rotate (1, 0) by 180° about (2, 1). The image is (a, b). Find a + b.

HintThe centre is the midpoint.
Answer5
Method: Rule

(2·2 − 1, 2·1 − 0) = (3, 2), so a + b = 5.

Method: Midpoint

The midpoint of (1, 0) and (3, 2) is (2, 1), the centre.

Problem p4. Reflect (4, 1) in the line y = 2x. The image is (a, b). Find a + b as a fraction.

HintReflect = 2 · projection − the point.
Answer11/5
Method: Projection

The projection of (4, 1) on the direction (1, 2) is ((4 + 2)/5)(1, 2) = (6/5, 12/5). The image is 2(6/5, 12/5) − (4, 1) = (−8/5, 19/5), so a + b = 11/5.

Method: Check

The midpoint (6/5, 12/5) lies on y = 2x, and the segment direction (−28/5, 14/5) is perpendicular to (1, 2).

Source: Coxeter & Greitzer ch. 4; AoPS Volume 1 ch. 19

Problem p5. A point is reflected in the line x = 1 and then in the line x = 4. By how much is it translated (the distance moved to the right)?

2 · 3 = 6.

x = 0 reflects to 2 and then to 6: a shift of 6.

Problem p7. How many symmetries (rotations and reflections) does a regular hexagon have?

Hint2n.
Answer12
Method: Count

6 rotations and 6 reflections: 12.

Method: Reasoning

A symmetry is determined by where it sends one vertex (6 choices) and one adjacent vertex (2 choices).

Problem p8. How many symmetries does a rectangle that is not a square have?

HintIdentity, rotation by 180°, two reflections.
Answer4
Method: List

Identity, a 180° rotation and reflections in the two midlines: 4.

Method: Why not diagonals

The diagonals are not axes of symmetry because the sides are unequal.
