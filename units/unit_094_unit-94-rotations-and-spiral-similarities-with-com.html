1. Rotations and spiral similarities as functions

Every spiral similarity (a rotation followed by a scaling about the same point) of the plane is a function z ↦ az + b with complex a ≠ 0. The ratio of the scaling is |a| and the rotation angle is arg a. If a ≠ 1 there is exactly one fixed point s with s = as + b, i.e. s = b/(1 − a), and then z ↦ s + a(z − s). A pure rotation has |a| = 1.

Worked example 1. The map z ↦ (1 + i)z + 2 sends 0 to 2 and 1 to 3 + i. Its fixed point is s = 2/(1 − (1 + i)) = 2/(−i) = 2i, and indeed (1 + i)(2i) + 2 = 2i − 2 + 2 = 2i ✓. The map rotates by 45° and scales by √2 about 2i.

Worked example 2. Rotate z by 90° about the point c: c + i(z − c). The image of 3 about c = 1 is 1 + i(2) = 1 + 2i.

2. Finding the centre from two pairs of points

Suppose a spiral similarity sends the point P to P′ and Q to Q′ (as complex numbers). Then a = (Q′ − P′)/(Q − P) and b = P′ − aP. The centre s satisfies s = b/(1 − a).

Worked example. The spiral similarity sends 0 ↦ 2 and 1 ↦ 3 + i. Here P = 0, P′ = 2, Q = 1, Q′ = 3 + i, so a = (3 + i − 2)/(1 − 0) = 1 + i and b = 2 − 0 = 2, matching the first example, with centre 2i.

Composition. The composition of two spiral similarities z ↦ a₁z + b₁ and z ↦ a₂z + b₂ is z ↦ a₂a₁z + a₂b₁ + b₂, again a spiral similarity (or a translation if a₁a₂ = 1).

3. Using spiral similarity in geometry

Squares on the sides. Erect squares outward on the sides of a triangle. In complex numbers, the centre of the square on the side from P to Q (outward) is (P + Q)/2 + i(Q − P)/2 for one orientation. For P = 0, Q = 4: the centre is 2 + 2i, and the other vertices are 4i and 4 + 4i.

Napoleon's theorem. Erect equilateral triangles outward on the sides of any triangle; their centres form an equilateral triangle. For example on the side from 0 to 2 (drawn below the axis) the apex is 1 − i√3 and the centre of that triangle is (0 + 2 + 1 − i√3)/3 = 1 − i√3/3.

Rotating a triangle. If two segments AB and AC are equal and perpendicular, then C − A = ±i(B − A). So the 'rotation of B about A by 90°' is C. This turns many perpendicularity and length statements into one equation.

4. Mistakes, checks and how to practise

Common mistakes. Rotating about the origin when the centre is elsewhere. Forgetting to translate back. Sign errors for clockwise versus anticlockwise. Mixing up the order of composition.

Checks. Check that the fixed point is mapped to itself.

Practice. Always find the fixed point first.

Worked examples with Try-its: Rotations as multiplication

Multiplying z by i rotates it 90° anticlockwise about the origin; multiplying by e^{iθ} rotates by θ. To rotate z about a centre c, use c + e^{iθ}(z − c). Rotating 4 + 3i by 90° about 1 + i gives (1 + i) + i(3 + 2i) = (1 + i) + (3i − 2) = −1 + 4i.

Try it

Rotate 2 + 0i by 120° about the origin.

Answer. 2e^{2πi/3} = −1 + i√3.

Worked examples with Try-its: Equilateral triangles and spiral similarity

The third vertex of an equilateral triangle on 0 and 2 is 2e^{iπ/3} = 1 + i√3. A spiral similarity z ↦ az + b combines a rotation (the argument of a) with a scaling (the modulus of a). Two triangles that are directly similar can be mapped to each other by one such map.

Try it

Where does z ↦ iz + 1 send 2?

Answer. 1 + 2i.

Worked examples with Try-its: A longer problem

Problem. Triangle ABC has A = 0, B = 4 and C = 3i. An equilateral triangle ABP is built on AB on the same side as C. Find CP. Solution. P = 4e^{iπ/3} = 2 + 2√3 i, so CP = |2 + (2√3 − 3)i| = √(4 + 21 − 12√3) = √(25 − 12√3) ≈ 2.05.

Reflection. Put A at the origin so that rotations are simple multiplications.

More worked examples: Worked examples

Multiplying by 1 + i rotates 45° and scales by √2. Rotating 2 + 3i by 90° about 1 + i gives (1 + i) + i(1 + 2i) = −1 + 2i. The map z ↦ 2iz + 1 has the fixed point z = 1/(1 − 2i) = (1 + 2i)/5; it is a spiral similarity with ratio 2 and angle 90° about that point.

Try it

Rotate 3 by 60° about the origin.

Answer. 3e^{iπ/3} = 3/2 + (3√3/2)i.

Try it

Find the fixed point of z ↦ 3z − 4.

Answer. z = 2.

More worked examples: A second longer problem

Problem. Find the rotation z ↦ az + b with |a| = 1 that sends 1 to i and 2 to 2i. Solution. 1 ↦ i gives a + b = i, and 2 ↦ 2i gives 2a + b = 2i, so a = i and b = 0, the rotation by 90° about the origin.

Check. i · 1 = i and i · 2 = 2i ✓.

Problem p1. Rotate the point (3, 1) by 90° counterclockwise about the origin. The image is (x, y). Find x + y.

HintMultiply by i.
Answer2
Method: Complex

i(3 + i) = 3i − 1 = −1 + 3i, so x + y = 2.

Method: Rule

A 90° rotation sends (x, y) to (−y, x): (−1, 3).

Source: Chen ch. 11 and AoPS Volume 2 ch. 9

Problem p2. Rotate (4, 1) by 90° counterclockwise about the point (1, 1). Find x + y of the image.

HintTranslate so the centre is the origin.
Answer5
Method: Translate

(4, 1) − (1, 1) = (3, 0), rotating gives (0, 3), and adding back (1, 1) gives (1, 4): x + y = 5.

Method: Complex

1 + i + i(3) = 1 + 4i.

Source: Chen ch. 11 and AoPS Volume 2 ch. 9

Problem p9. Find the imaginary part of (1 + i)(2 + i)(3 + i).

HintMultiply two at a time.
Answer10
Method: Multiply

(1 + i)(2 + i) = 1 + 3i and (1 + 3i)(3 + i) = 3 + i + 9i − 3 = 10i, so the imaginary part is 10.

Method: Argument

The arguments arctan 1 + arctan(1/2) + arctan(1/3) add to 90°, so the product is purely imaginary.
