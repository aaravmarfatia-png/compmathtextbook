1. Euclid's algorithm and continued fractions

The Euclidean algorithm finds gcd(a, b) by repeated division: gcd(1071, 462): 1071 = 2 · 462 + 147; 462 = 3 · 147 + 21; 147 = 7 · 21, so the gcd is 21 and the quotients are 2, 3, 7. The same quotients form the continued fraction 1071/462 = [2; 3, 7] = 2 + 1/(3 + 1/7). Similarly 43/19 = [2; 3, 1, 4], and 355/113 = [3; 7, 16] (famously close to π).

Convergents. Truncating the continued fraction gives the best rational approximations: for π ≈ [3; 7, 15, 1, …] the convergents 3, 22/7, 333/106, 355/113 are successively better. For √2 = [1; 2, 2, 2, …] the convergents are 1, 3/2, 7/5, 17/12, 41/29, …, each within 1/q² of √2; their numerators and denominators solve x² − 2y² = ±1 (17² − 2 · 12² = 1, 41² − 2 · 29² = −1), connecting to Pell's equation. For φ = [1; 1, 1, 1, …] the convergents are ratios of consecutive Fibonacci numbers.

Try it

Write 17/5 as a continued fraction.

Answer. 17 = 3 · 5 + 2, 5 = 2 · 2 + 1, 2 = 2 · 1: [3; 2, 2].

2. Using the algorithm for Diophantine equations

Back-substitution through the Euclidean steps solves ax + by = gcd(a, b). For 43x − 19y = 1: the continued fraction [2; 3, 1, 4] has convergents 2, 7/3, 9/4, 43/19, and the last two give 43 · 4 − 19 · 9 = 1, so x = 4, y = 9 is a solution (checked). In general consecutive convergents p/q and p′/q′ satisfy pq′ − p′q = ±1.

Evaluating a continued fraction. Work from the bottom: [2; 3, 1, 4] = 2 + 1/(3 + 1/(1 + 1/4)) = 2 + 1/(3 + 4/5) = 2 + 5/19 = 43/19 ✓.

Try it

Solve 17x − 5y = 1 using the continued fraction of 17/5.

Answer. [3; 2, 2] has convergents 3, 7/2, 17/5: 17 · 2 − 5 · 7 = −1, so x = −2, y = −7 solves 17x − 5y = 1 (and x = 3, y = 10 gives 51 − 50 = 1).

3. A longer problem

Problem. Find the continued fraction of √3 = 1.7320508… and its first four convergents; relate them to x² − 3y² = 1.

Solution. √3 = [1; 1, 2, 1, 2, 1, 2, …]. Convergents: 1, 2, 5/3, 7/4, 19/11, 26/15. Pairs (x, y) with x² − 3y² = 1 appear as 2/1, 7/4, 26/15: 4 − 3 = 1, 49 − 48 = 1, 676 − 675 = 1 ✓, the usual Pell solutions.

Reflection. Periodic continued fractions of quadratic irrationals connect directly to Pell equations.

4. Mistakes, checks and how to practise

Common mistakes. (1) Stopping the Euclidean algorithm one step early. (2) Evaluating from the top instead of the bottom. (3) Forgetting sign conventions for ± in the convergent identity.

Checks. Evaluate the continued fraction back to the original fraction.

How to practise. Work a dozen Euclidean algorithms by hand. In Unlimited practice, rotate the Euclid and continued-fraction families.

More worked examples: Worked examples

Continued fractions. 13/8 = 1 + 5/8 = 1 + 1/(8/5) and continuing gives [1; 1, 1, 1, 2] (the Euclidean quotients). The gcd of 1071 and 462 is 21 and the quotients are 2, 3, 7. A fraction's continued fraction ends where the Euclidean algorithm ends, so rational numbers have finite continued fractions.

Try it

Find the continued fraction of 7/3.

Answer. [2; 3].

Try it

Evaluate [1; 2, 3].

Answer. 1 + 1/(2 + 1/3) = 1 + 3/7 = 10/7.

More worked examples: A second longer problem

Problem. Find the smallest positive integers x, y with 13x − 8y = 1. Solution. The convergents of 13/8 = [1; 1, 1, 1, 2] are 1, 2, 3/2, 5/3 and 13/8, and the last two give 13 · 3 − 8 · 5 = −1, so the sign is wrong. Instead reduce mod 8: 13 ≡ 5 and 5 · 5 = 25 ≡ 1, so x = 5, and then y = (13 · 5 − 1)/8 = 8.

Check. 13 · 5 − 8 · 8 = 1 ✓.

HintWork from the inside out.
Answer43
Method: Inside out

3 + 1/4 = 13/4, then 1/(13/4) = 4/13, so the value is 30/13 and 30 + 13 = 43.

Method: Check

30/13 ≈ 2.31 = 2 + 0.31, and 4/13 ≈ 0.31.

Problem p7. How many division steps does Euclid's algorithm take on (233, 144)?

HintEach step replaces (a, b) by (b, a mod b) until the remainder is 0.
Answer11
Method: Run

233 = 1·144 + 89, 144 = 1·89 + 55, 89 = 1·55 + 34, 55 = 1·34 + 21, 34 = 1·21 + 13, 21 = 1·13 + 8, 13 = 1·8 + 5, 8 = 1·5 + 3, 5 = 1·3 + 2, 3 = 1·2 + 1, 2 = 2·1: 11 steps.

Method: Why

Consecutive Fibonacci numbers give the slowest case, one step per index.

Problem x18. Evaluate 1/(1·2) + 1/(2·3) + … + 1/(119·120).

Hint1/(k(k + 1)) = 1/k − 1/(k + 1).
Answer119/120
Method: Telescoping

Each term is 1/k − 1/(k + 1); everything cancels except 1 − 1/120 = 119/120.

Method: Small cases

Up to n = 1, 2, 3 the sums are 1/2, 2/3, 3/4, so up to n = 119 the sum is 119/120.

HintCompute term by term, or find a closed form.
Answer161
Method: Step by step

The terms are 1, 5, 17, 53, 161, so a_5 = 161.
