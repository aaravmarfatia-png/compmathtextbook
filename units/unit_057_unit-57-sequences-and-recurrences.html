1. Arithmetic and geometric sequences

In an arithmetic sequence consecutive terms differ by a constant d: aₙ = a₁ + (n − 1)d and the sum of the first n terms is n(a₁ + aₙ)/2. For a₁ = 5, d = 3: a₂₀ = 62 and S₂₀ = 20 · 67/2 = 670. In a geometric sequence consecutive terms have a constant ratio r: aₙ = a₁rⁿ⁻¹ and Sₙ = a₁(rⁿ − 1)/(r − 1). For 3, 6, 12, … the sum of 10 terms is 3(2¹⁰ − 1) = 3069. If |r| < 1 the infinite sum is a₁/(1 − r).

Recognising them. Three numbers a, b, c are in arithmetic progression iff 2b = a + c, in geometric progression iff b² = ac. If the sum of three numbers in arithmetic progression is 21, the middle one is 7.

Try it

Find the sum 2 + 5 + 8 + … + 62.

Answer. Terms: 21; sum = 21 · 64/2 = 672.

2. Recurrences

A recurrence defines each term from earlier ones. Linear first order: xₙ₊₁ = 2xₙ + 1 with x₁ = 1 gives 1, 3, 7, 15, … and xₙ = 2ⁿ − 1 (add 1 to both sides: xₙ₊₁ + 1 = 2(xₙ + 1)). Second order: aₙ = 5aₙ₋₁ − 6aₙ₋₂ with a₀ = 2, a₁ = 5: the characteristic equation r² = 5r − 6 has roots 2 and 3, so aₙ = A · 2ⁿ + B · 3ⁿ, and fitting a₀, a₁ gives A = B = 1: aₙ = 2ⁿ + 3ⁿ (confirmed for n up to 9).

Fibonacci and Binet. Fₙ = (φⁿ − ψⁿ)/√5 with φ = (1 + √5)/2 and ψ = (1 − √5)/2; F₂₀ = 6765 (checked numerically). Closed forms come from the roots of the characteristic equation; repeated roots give n · rⁿ terms.

Periodic recurrences. aₙ₊₁ = 1/(1 − aₙ) with a₁ = 2 gives 2, −1, 1/2, 2, −1, 1/2, …, period 3; since 2023 ≡ 1 (mod 3), a₂₀₂₃ = 2.

Try it

Find a closed form for aₙ₊₁ = 3aₙ + 2, a₁ = 1.

Answer. aₙ + 1 triples each step: aₙ + 1 = 2 · 3ⁿ⁻¹, so aₙ = 2 · 3ⁿ⁻¹ − 1.

3. A longer problem

Problem. The sequence satisfies a₁ = 1, a₂ = 3 and aₙ = aₙ₋₁ + 2aₙ₋₂. Find a closed form and a₁₀.

Solution. r² = r + 2 has roots 2 and −1, so aₙ = A · 2ⁿ + B(−1)ⁿ. a₁: 2A − B = 1; a₂: 4A + B = 3; adding, 6A = 4, A = 2/3, B = 1/3. So aₙ = (2ⁿ⁺¹ + (−1)ⁿ)/3. Check: a₃ = a₂ + 2a₁ = 5 and (16 − 1)/3 = 5 ✓. a₁₀ = (2048 + 1)/3 = 683.

Reflection. Verify the closed form with the first two or three terms before trusting it.

4. Mistakes, checks and how to practise

Common mistakes. (1) Off-by-one errors in aₙ = a₁ + (n − 1)d. (2) Using the wrong number of terms in a sum. (3) Forgetting to use initial values. (4) Applying the infinite sum formula when |r| ≥ 1.

Checks. Compute the first three terms from the recurrence and from the closed form.

How to practise. Write out the first five terms. In Unlimited practice, rotate the sequence and recurrence families.

More worked examples: Worked examples

Fibonacci identity. With F₁ = F₂ = 1, the sum of the first n squares is FₙFₙ₊₁: for n = 5 we get 1 + 1 + 4 + 9 + 25 = 40 = 5 · 8. Odd numbers. The first n odd numbers add up to n² (1 + 3 + 5 + 7 + 9 = 25). Geometric. A sequence with first term 3 and ratio 2 has sum of the first 6 terms 3(2⁶ − 1) = 189.

Try it

Find the sum of the first 20 terms of 5, 8, 11, …

Answer. (2 · 5 + 19 · 3) · 20/2 = 670.

Try it

The sequence has a₁ = 2, a₂ = 3 and aₙ = aₙ₋₁ + aₙ₋₂. Find a₆.

Answer. 2, 3, 5, 8, 13, 21, so a₆ = 21.

More worked examples: A second longer problem

Problem. A sequence has a₁ = 1 and aₙ₊₁ = aₙ + n. Find aₙ. Solution. aₙ = 1 + (1 + 2 + … + (n − 1)) = 1 + n(n − 1)/2. The first terms are 1, 2, 4, 7, 11.

Check. a₅ = 1 + 5 · 4/2 = 11 ✓.

Problem x25. Evaluate 1/(1·2) + 1/(2·3) + … + 1/(99·100).

Hint1/(k(k + 1)) = 1/k − 1/(k + 1).
Answer99/100

Each term is 1/k − 1/(k + 1); everything cancels except 1 − 1/100 = 99/100.

Up to n = 1, 2, 3 the sums are 1/2, 2/3, 3/4, so up to n = 99 the sum is 99/100.
