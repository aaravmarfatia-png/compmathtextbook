Reading

1. The graph of a quadratic function

The function y = ax² + bx + c (with a ≠ 0) has a graph called a parabola. If a > 0 it opens upward like a cup and has a lowest point; if a < 0 it opens downward and has a highest point. That extreme point is the vertex, and the vertical line through it is the axis of symmetry: the two halves of the curve are mirror images. The larger |a| is, the narrower the parabola.

Key points. The y-intercept (where x = 0) is c. The x-intercepts are the roots of ax² + bx + c = 0, if they exist. The vertex lies exactly half-way between the roots when there are two, and in every case its x-coordinate is x = −b/(2a). For y = x² − 4x + 3: the roots are 1 and 3 (x² − 4x + 3 = (x − 1)(x − 3)), the vertex is at x = 4/2 = 2 and the value there is 4 − 8 + 3 = −1. So the vertex is (2, −1), and the parabola crosses the y-axis at 3.

Why the vertex formula holds. If the roots are r and s, symmetry puts the axis half-way between them at x = (r + s)/2, and Vieta's formula says r + s = −b/a, so the axis is at x = −b/(2a). Even when there are no real roots the same formula holds, because the parabola is symmetric regardless.

Reading a graph from the discriminant. D = b² − 4ac > 0 means the parabola crosses the x-axis twice; D = 0 means it just touches (the vertex is on the axis); D < 0 means it misses the axis entirely: it lies wholly above (if a > 0) or wholly below (if a < 0).

Try it

Find the vertex and the intercepts of y = x² − 6x + 5.

Answer. Vertex at x = 3, y = 9 − 18 + 5 = −4, so (3, −4). y-intercept 5. Roots: (x − 1)(x − 5) = 0, so x = 1 and x = 5.

2. Completing the square: vertex form

Completing the square (Unit 8) rewrites any quadratic as a(x − h)² + k, called vertex form, where the vertex is exactly (h, k). Take y = 2x² + 8x + 5. Factor 2 from the first two terms: 2(x² + 4x) + 5. Inside the bracket add and subtract 4: 2(x² + 4x + 4 − 4) + 5 = 2(x + 2)² − 8 + 5 = 2(x + 2)² − 3. So the vertex is (−2, −3). Check: at x = −2, y = 8 − 16 + 5 = −3 ✓, and the formula −b/(2a) = −8/4 = −2 ✓.

Vertex form instantly tells you the smallest or largest value: since (x + 2)² ≥ 0, the expression 2(x + 2)² − 3 is at least −3, with equality at x = −2. This 'no square is negative' idea is the heart of every maximum–minimum problem for quadratics.

Transformations. Starting from y = x², the graph of y = (x − h)² + k is the same parabola shifted h units to the right and k units up. Multiplying by a stretches vertically (and a negative a flips it upside down). So y = −(x − 3)² + 4 is an upside-down parabola with its highest point at (3, 4) and value at most 4.

Worked example (finding the equation). A parabola has vertex (1, 2) and passes through (3, 10). Using vertex form y = a(x − 1)² + 2, plug in (3, 10): 10 = a × 4 + 2, so a = 2 and y = 2(x − 1)² + 2 = 2x² − 4x + 4. Check: at x = 3: 18 − 12 + 4 = 10 ✓.

Try it

Write y = x² + 6x + 11 in vertex form and state its minimum value.

Answer. y = (x + 3)² + 2, so the minimum value is 2, at x = −3.

3. Maximum and minimum problems

Many real problems reduce to finding the top or bottom of a parabola. The recipe: (1) introduce a variable x for the thing you control, (2) write the quantity to optimise as a quadratic in x, (3) find the vertex, (4) check that the x there is allowed by the problem.

Worked example 1 (fencing). A farmer has 60 m of fence and uses a straight wall as one side of a rectangular pen. If the two sides perpendicular to the wall have length x, the side parallel to the wall is 60 − 2x, so the area is A = x(60 − 2x) = −2x² + 60x. The vertex is at x = 60/4 = 15, giving A = 15 × 30 = 450 m². The pen should be 15 m by 30 m. Without the wall the best rectangle with perimeter 60 is a 15 m square, area 225.

Worked example 2 (selling price). A shop sells 100 items a week at 10 euros each. For every euro the price is raised, 5 fewer items are sold. With x euros of increase, revenue R = (10 + x)(100 − 5x) = −5x² + 50x + 1000. The vertex is at x = 5, so the best price is 15 euros, selling 75 items, revenue 1125 euros (check: 15 × 75 = 1125 ✓). Compare with the starting 1000 euros.

Worked example 3 (integers). The product of two numbers whose sum is 12 is largest when they are equal, 6 × 6 = 36, because x(12 − x) = 36 − (x − 6)² ≤ 36. If the two numbers must be whole and different, the best is 5 and 7 with product 35, which shows how the vertex can fall outside the allowed set.

Try it

Two numbers add to 20. What is the smallest possible value of the sum of their squares?

Answer. x² + (20 − x)² = 2x² − 40x + 400 = 2(x − 10)² + 200, so the minimum is 200, at x = 10.

4. Quadratic inequalities

To solve ax² + bx + c > 0 (or <, ≥, ≤) first find the roots, because the sign of a quadratic can change only at its roots. Between consecutive roots the sign is constant, so test one point in each region. For x² − 5x + 6 < 0: the roots are 2 and 3. Test x = 0: 6 > 0, not negative. Test x = 2.5: 6.25 − 12.5 + 6 = −0.25 < 0 ✓. Test x = 4: 16 − 20 + 6 = 2 > 0. So the solution is 2 < x < 3.

A shortcut uses the picture: if a > 0 the parabola is a cup, so the quadratic is negative between the roots and positive outside. Thus (x − 1)(x − 4) ≥ 0 means x ≤ 1 or x ≥ 4 (outside the roots, including them because of ≥), while (x − 1)(x − 4) ≤ 0 means 1 ≤ x ≤ 4. If a < 0 everything flips, so first multiply by −1 and reverse the inequality sign.

When there are no roots. If D < 0 the quadratic never changes sign: x² + 2x + 5 = (x + 1)² + 4 is always positive, so x² + 2x + 5 > 0 holds for every x and x² + 2x + 5 < 0 for none. Parameter problems. For which b is x² + bx + 9 > 0 for all x? We need D = b² − 36 < 0, so −6 < b < 6. (If b = 6 the quadratic is (x + 3)², which touches zero at x = −3, so strict inequality fails.)

Try it

Solve x² − 2x − 8 ≤ 0.

Answer. Roots 4 and −2 (x² − 2x − 8 = (x − 4)(x + 2)); a cup is non-positive between the roots, so −2 ≤ x ≤ 4.

5. A parabola and a line

To find where a line meets a parabola, set the two expressions equal; the result is a quadratic whose roots are the x-coordinates of the intersection points. For y = x² − 2x and y = x + 4: x² − 2x = x + 4 gives x² − 3x − 4 = 0, so (x − 4)(x + 1) = 0 and x = 4 or x = −1. The points are (4, 8) and (−1, 3). Check: 16 − 8 = 8 = 4 + 4 ✓ and 1 + 2 = 3 = −1 + 4 ✓.

The discriminant counts intersections: D > 0 gives two points, D = 0 a single point where the line is tangent to the parabola, and D < 0 none. Example: for which value of c is the line y = 2x + c tangent to y = x²? Setting x² = 2x + c gives x² − 2x − c = 0, with D = 4 + 4c = 0, so c = −1. The line y = 2x − 1 touches the parabola at x = 1 (the double root), at the point (1, 1).

The distance between two roots. The roots are (−b ± √D)/(2a), so the distance between them is √D/|a|. For x² − 3x − 4 = 0 this is √25/1 = 5, which equals |4 − (−1)| ✓. This is a quick way to find chord lengths on a parabola.

Try it

For which values of m does the line y = mx − 4 touch the parabola y = x² at exactly one point?

Answer. x² = mx − 4 gives x² − mx + 4 = 0, D = m² − 16 = 0, so m = 4 or m = −4.

6. Where are the roots? Signs, sums and products

You can often answer questions about the roots of ax² + bx + c = 0 without finding them, using three facts: the discriminant D tells whether they are real; the sum −b/a tells you about their average; the product c/a tells you whether they have the same sign. Two roots of opposite signs happens exactly when the product is negative (c/a < 0), and then D is automatically positive. For x² + 3x − 10 the product is −10 < 0, and indeed the roots are 2 and −5. Two positive roots need D ≥ 0, a positive sum and a positive product.

Worked example 1. For which m does x² − mx + 4 = 0 have two positive roots (equal roots allowed)? Conditions: D = m² − 16 ≥ 0, sum m > 0, product 4 > 0 (automatic). So m ≥ 4. For m = 5 the roots are 1 and 4 ✓; for m = 3 there are no real roots, and for m = −5 the roots are −1 and −4, both negative.

Worked example 2 (shifting the question). For which m are both roots of x² − 4x + m = 0 greater than 1? Shift the variable: put x = y + 1, so 'greater than 1' becomes 'positive y'. Then (y + 1)² − 4(y + 1) + m = y² − 2y + (m − 3) = 0. Both roots positive needs D = 4 − 4(m − 3) ≥ 0 so m ≤ 4, and the product m − 3 > 0 so m > 3 (the sum 2 is positive already). Hence 3 < m ≤ 4. Spot checks: m = 3.5 gives roots 2 ± √0.5 ≈ 1.29 and 2.71, both above 1 ✓; m = 3 gives roots 1 and 3, and 1 is not greater than 1, so m = 3 is rightly excluded.

Reading signs from a picture. If a parabola opens upward then a > 0. The y-intercept is c. The vertex is at x = −b/(2a), so if the vertex is to the right of the y-axis then b and a have opposite signs. With a bit of practice you can sketch the three-parameter family quickly and decide the signs of a, b, c, and D from a graph.

Try it

For which m does x² + mx + 9 = 0 have two negative roots?

Answer. Need D = m² − 36 ≥ 0, sum −m < 0 so m > 0, product 9 > 0. So m ≥ 6.

7. Parabolas in context: motion and geometry

Projectile. A stone is thrown upward from the top of a 25 m cliff; its height after t seconds is h = −5t² + 20t + 25. The vertex is at t = 2, where h = −20 + 40 + 25 = 45 m, the greatest height. It reaches the ground when h = 0: t² − 4t − 5 = 0, so (t − 5)(t + 1) = 0 and t = 5 (the root t = −1 is before the throw and is rejected). Check h(5) = −125 + 100 + 25 = 0 ✓. The stone is again at the cliff height 25 m when −5t² + 20t = 0, t = 4: symmetric with t = 0 about the axis t = 2.

A rectangle inside a triangle. A triangle has base 12 and height 8. A rectangle stands on the base with its top corners on the sides. If the rectangle has height y, similar triangles show its width is 12(1 − y/8), so its area is A = 12y − 1.5y². The vertex is at y = 4, giving A = 48 − 24 = 24, which is exactly half of the triangle's area 48. This 'half the triangle' result holds for every triangle, whatever its shape.

Minimising a diagonal. The legs of a right triangle add up to 14. The squared hypotenuse is x² + (14 − x)² = 2(x − 7)² + 98 ≥ 98, with equality when the legs are equal (7 and 7). So the shortest possible hypotenuse is √98 = 7√2 ≈ 9.9. Whenever a quantity is a sum of squares of linear expressions, it is a quadratic and the minimum is at its vertex.

Try it

A rectangle has perimeter 40. What is the largest possible area?

Answer. Sides x and 20 − x: A = x(20 − x) = 100 − (x − 10)². Maximum 100 at x = 10 (a square).

8. A longer problem

Problem. The parabola y = ax² + bx + c passes through (0, 5), has its vertex on the line x = 2, and its minimum value is 1. Find a, b, c, and then solve y < 5.

Solution. The vertex is (2, 1), so y = a(x − 2)² + 1. At x = 0: 4a + 1 = 5, so a = 1 and y = (x − 2)² + 1 = x² − 4x + 5. So a = 1, b = −4, c = 5. The inequality x² − 4x + 5 < 5 simplifies to x² − 4x < 0, i.e. x(x − 4) < 0, which holds for 0 < x < 4. Notice that the parabola is above the x-axis everywhere since its minimum is 1 > 0, and that the answer interval 0 < x < 4 is centred on the axis x = 2 as symmetry demands.

Why this is a good example. Three different ideas were used: vertex form to impose conditions, solving for a single unknown from a point, and a quadratic inequality solved by the roots-and-sign rule. Each condition given in the problem used up exactly one unknown, which is how to count: three unknowns a, b, c need three pieces of information.

9. Mistakes, checks and how to practise

Common mistakes. (1) Using x = b/(2a) instead of −b/(2a). (2) Forgetting to reverse an inequality when multiplying by a negative number. (3) Writing the solution of a quadratic inequality as one interval when it is two pieces (outside the roots). (4) Giving the vertex x-value when the question asks for the maximum value. (5) Ignoring the domain: a pen with side 0 or negative length makes no sense.

Checks. Sketch the parabola with its roots and vertex before solving an inequality. Substitute a test point. For optimisation problems check the extreme value against two nearby values.

How to practise. For ten different quadratics write all four forms: standard, factored, vertex and graph sketch. The Unlimited practice family 'Vertex of a parabola' drills the formula and the completed square.

Problem q1. Solve 2x² − 7x + 3 = 0. Give the roots from smallest to largest, separated by a comma.

Hinta = 2, b = −7, c = 3. Compute D = b² − 4ac first.
Answer1/2, 3
Method: The formula

D = (−7)² − 4·2·3 = 49 − 24 = 25, so √D = 5. x = (7 ± 5)/4, i.e. 12/4 = 3 or 2/4 = 1/2.

Method: Factoring

Look for two numbers multiplying to a·c = 6 and adding to b = −7: they are −1 and −6. Split the middle: 2x² − 6x − x + 3 = 2x(x − 3) − (x − 3) = (2x − 1)(x − 3). Each bracket zero gives x = 1/2 or x = 3.

Method: Complete the square

Divide by 2: x² − 3.5x + 1.5 = 0. Half of 3.5 is 1.75, and 1.75² = 3.0625. (x − 1.75)² = 3.0625 − 1.5 = 1.5625 = 1.25². So x = 1.75 ± 1.25 = 3 or 0.5.

Problem 253. If the roots of 2x² − 7x + 3 = 0 are 3 and 1/2, find the roots of the flipped equation 3x² − 7x + 2 = 0. Smallest first, comma between.

HintDivide the original equation by x² and put y = 1/x.
Answer1/3, 2
Method: Reciprocals (the book's idea)

Divide 2x² − 7x + 3 = 0 by x²: 2 − 7/x + 3/x² = 0, i.e. 3y² − 7y + 2 = 0 with y = 1/x. So the new roots are the reciprocals 1/3 and 1/(1/2) = 2.

Method: Solve directly

D = 49 − 24 = 25, x = (7 ± 5)/6 = 2 or 1/3.

Method: Vieta

The roots multiply to c/a = 2/3 and add to 7/3. 2 · 1/3 = 2/3 ✓ and 2 + 1/3 = 7/3 ✓.

Problem 254. Use the second formula x = 2c/(−b ∓ √D) on 2x² − 7x + 3 = 0. What two numbers do you get? Smallest first.

HintD = 25, −b = 7.
Answer1/2, 3
Method: Second formula

2c = 6. With the minus sign: 6/(7 − 5) = 3. With the plus sign: 6/(7 + 5) = 1/2. Same roots as the ordinary formula.

Method: Why they agree

Multiply (−b + √D)(−b − √D) = b² − D = 4ac. So (−b + √D)/(2a) = 4ac / (2a(−b − √D)) = 2c/(−b − √D): the same number written two ways. Numerically for our equation: (7 + 5)/4 = 3 and 6/(7 − 5) = 3 ✓.

Problem 264. A rectangle has area 64. What is the smallest possible perimeter?

HintUse the square result: for a fixed perimeter the square has the largest area.
Answer32
Method: Square

The minimum is attained by the square: side 8, perimeter 32. Why: if some rectangle with area 64 had perimeter less than 32, a square with that smaller perimeter would have area less than 64 (side < 8), but a square has the largest area of all rectangles with that perimeter, so the rectangle's area would also be less than 64, a contradiction.

Method: Quadratic

Sides x and 64/x, perimeter 2(x + 64/x). From x + 64/x = c we get x² − cx + 64 = 0 which needs c² ≥ 256, c ≥ 16. So perimeter ≥ 32.

Problem q25. Two numbers add up to 8. What is the smallest possible value of the sum of their squares?

Hintx² + (8 − x)².
Answer32
Method: Quadratic

x² + (8 − x)² = 2x² − 16x + 64, a bowl with vertex at x = 4, value 32 − 64 + 64 = 32.

Method: Shift from the middle

Numbers 4 + t and 4 − t: squares sum to 32 + 2t² ≥ 32.
